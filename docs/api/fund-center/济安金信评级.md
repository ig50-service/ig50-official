## 功能描述

根据【基金分类参数】（见下方"【基金分类参数】说明"）获取不同分类下的基金的济安金信评级，根据综合评级倒序

## 更新机制

- **更新频率**：每天20:30
- **完成耗时**：约60分钟

## 数据格式

```
[{},...]
```

## 字段说明

基金代码，如：000001（华夏成长混合）, 基金名称，如：华夏成长混合, 更新时间yyyyMMdd, 综合评级（单位：星，共5星）, 盈利能力评级（单位：星，共5星）, 业绩稳定性评级（单位：星，共5星）, 抗风险力评级（单位：星，共5星）, 择时能力评级（单位：星，共5星）, 超额收益能力评级（单位：星，共5星）, 整体费用评级（单位：星，共5星）
