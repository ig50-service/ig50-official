## 功能描述

基金重仓个股排名，根据基金覆盖面倒序。支持"年份_季度"查询，年份可选（1999~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如"2021_1"，表示查询2021年一季度数据

## 更新机制

- **完成耗时**：约60分钟

## 字段说明

代码, 完整代码, 名称, 基金覆盖面(只), 持股总数(万股), 持股总市值(万元), 上期持股总市值(万元), 占该股流通市值比例(%), 报告年份，如2021, 报告季度，1:一季报，2：中报，3：三季报，4：年报, 报告年份季度含义，如“2021年一季报”
