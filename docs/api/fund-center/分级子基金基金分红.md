| 项目 | 内容 |
|------|------|
| 数据名称 | 基金数据中心-基金分红-分级子基金-分级子基金基金分红 |

## 功能描述

根据【基金分类参数】获取不同分类下的分级子基金的基金分红，根据最新派息日倒序

## 更新机制

- **更新频率**：每天20:30
- **完成耗时**：约60分钟

## 数据格式

```
[{},...]
```

## 字段说明

基金代码，如：000001（华夏成长混合）, 基金名称，如：华夏成长混合, 最新除息日, 最新派息日, 最新单位分红, 成立日期, 期间分红次数, 期间累计分红
