## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 基金数据中心-基金评级-招商证券评级-招商证券评级 |
| 所属市场 | 基金数据中心 |
| 本地路径 | `数据存放目录/all/jjsjzx/jjpj/{基金分类参数}` |

## 功能描述

根据【基金分类参数】（见下方"【基金分类参数】说明"）获取不同分类下的基金的招商证券评级，根据本期评级倒序

## 更新机制

- **更新频率**：每天20:30
- **完成耗时**：约60分钟

## 数据格式

```
[{},...]
```

## 字段说明

基金代码，如：000001（华夏成长混合）, 基金名称，如：华夏成长混合, 更新时间yyyyMMdd, 最新净值, 本期星级（单位：星，共5星）, 本期流动性星级（单位：星，共5星）, 本期时间加权Jensen, 上期星级（单位：星，共5星）, 上期流动性星级（单位：星，共5星）, 上期时间加权Jensen, 近一个月收益率（%）, 近一季度收益率（%）, 今年以来收益率（%）, 近一年收益率（%）, 近两年收益率（%）, 近三年收益率（%）, 标准差, Beta, 夏普, 特雷诺, 詹森, 基金经理, 基金管理人
