| 项目 | 内容 |
|------|------|
| 数据名称 | 基金数据中心-基金规模-封闭式基金-封闭式基金基金规模 |

| 本地路径 | `数据存放目录/all/jjsjzx/jjgm/{基金分类参数}` |

## 功能描述

根据【基金分类参数】获取不同分类下的封闭式基金的基金规模，根据总募集规模（万份）倒序

## 更新机制

- **更新频率**：每天20:30
- **完成耗时**：约60分钟

## 数据格式

```
[{},...]
```

## 字段说明

基金代码，如：000001（华夏成长混合）, 基金名称，如：华夏成长混合, 单位净值（元）, 总募集规模（万份）, 最近总份额（万份）, 成立日期, 基金经理
