## 功能描述

根据【基金分类参数】获取不同分类下的基金的海通证券评级，根据近一年收益率倒序

## 更新机制

- **更新频率**：每天20:30
- **完成耗时**：约60分钟

[{},...]

## 字段说明

基金代码，如：000001（华夏成长混合）, 基金名称，如：华夏成长混合, 基金类型, 更新时间yyyyMMdd, 基金公司名称, 最新星级, 星级变动, 近一年收益率（%）, 近一年排名, 近两年收益率（%）, 近两年排名, 近三年收益率（%）, 近三年排名
