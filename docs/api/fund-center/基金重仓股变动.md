## 功能描述

基金重仓个股与往季变动情况排名，根据覆盖面变化倒序。支持"年份_季度"查询，年份可选（1999~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如"2021_1"，表示查询2021年一季度数据

## 更新机制

- **更新频率**：每天20:30
- **完成耗时**：约60分钟

```
[{},...]
```

## 字段说明

代码, 完整代码, 名称, 上一个季度覆盖面(只), 本季度覆盖面(只), 覆盖面变化(只), 上一个季度持股数（万股）, 本季度持股数（万股）, 持股数变化（万股）, 占流通股比例变化(%), 报告年份，如2021, 报告季度，1:一季报，2：中报，3：三季报，4：年报, 报告年份季度含义，如“2021年一季报”
