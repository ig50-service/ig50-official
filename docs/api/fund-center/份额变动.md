## 功能描述

分级基金份额变动统计（可根据参数查询近一日、近一周、近一月、近三月的数据），根据期末流通份额倒序

## 更新机制

- **更新频率**：每天20:30
- **完成耗时**：约60分钟

## 数据格式

```
[{},...]
```

## 字段说明

基金代码，如：000001（华夏成长混合）, 基金名称，如：华夏成长混合, 设立日期yyyy-MM-dd, 上市日期yyyy-MM-dd, 投资类型, 上市起初份额(万份), 期初流通份额(万份), 期末流通份额(万份), 期间流通份额变动值(万份), 期间流通份额变动率(%), 更新日期yyyy-MM-dd
