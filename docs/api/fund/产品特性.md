## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| slrq | string | 设立日期（yyyy-MM-dd） |
| tzlx1 | string | 投资类型一 |
| tzlx2 | string | 投资类型二 |
| gzzs | string | 跟踪指数 |
| syfpms | string | 收益分配模式 |
| yzms | string | 运作模式 |
| qxlx | string | 期限类型 |
| cxq | string | 存续期 |
| dqr | string | 到期日 |
| gxrq | string | 更新日期（yyyy-MM-dd） |
