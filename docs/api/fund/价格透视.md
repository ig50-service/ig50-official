# 价格透视

> 基金 / 基金行情 / 分级基金 / 价格透视

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 价格透视 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/fjjj/jgts` |

## 功能描述

分级基金价格评估指标。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| lx | string | 基金类型 |
| jgzf | number | 价格涨幅（%） |
| jzzzl | number | 净值增长率（%） |
| jjfezzl | number | 基础份额净值增长率（%） |
| zyjlbdz | number | 折溢价率变动值（%） |
| zyjl | number | 折溢价率（%） |
| fegg | number | 份额杠杆 |
| jzgg | number | 净值杠杆 |
| jggg | number | 价格杠杆 |
| dwjz | number | 单位净值（元） |
| jcfedwjz | number | 基础份额单位净值（元） |
| bgrq | string | 变更日期（yyyy-MM-dd） |
