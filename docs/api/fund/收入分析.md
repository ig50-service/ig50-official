# 收入分析

> 基金 / 基金档案 / 财务与规模 / 收入分析

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 收入分析 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/cwbb/srfx/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历年的收入组成分析，按报告期降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 报告期 |
| srhj | string | 收入合计 |
| gpsr | string | 股票收入 |
| gpsrzb | string | 股票收入占比 |
| zqsr | string | 债券收入 |
| zqsrzb | string | 债券收入占比 |
| gxsr | string | 股息收入 |
| gxsrzb | string | 股息收入占比 |

