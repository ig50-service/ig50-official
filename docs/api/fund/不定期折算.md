# 不定期折算

> 基金 / 基金行情 / 分级基金 / 不定期折算

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 不定期折算 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/fjjj/zsxx/bdqzs` |

## 功能描述

分级基金不定期折算信息。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| sf | string | 是否有不定期折算 |
| ezsd | number | 下行折算点 |
| tzlx | string | 投资类型 |
| xxdf | number | 下行需B份额净值跌幅（%） |
| xxmdf | number | 下折需母基金净值跌幅（%） |
| xxzsfs | string | 下行折算方式 |
| szsd | number | 上行折算点 |
| sxmdf | number | 上折需母基金涨幅（%） |
| sxzsfs | string | 上行折算方式 |
| gxrq | string | 更新日期（yyyy-MM-dd） |

## 示例

```json
[{"dm":"J16340","mc":"兴全合润分级混合","sf":"是","ezsd":0.5,"tzlx":"偏股混合型(股票上限9","xxdf":67.19,"xxmdf":0,"xxzsfs":"折为基础份额重新拆分","szsd":0,"sxmdf":0,"sxzsfs":"","gxrq":"2020-12-31"}]
```
