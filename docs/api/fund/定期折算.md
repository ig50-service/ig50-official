# 定期折算

> 基金 / 基金行情 / 分级基金 / 定期折算

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 定期折算 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/fjjj/zsxx/dqzs` |

## 功能描述

分级基金定期折算信息。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| clrq | string | 成立日期（yyyy-MM-dd） |
| dzdx | string | 定折对象 |
| dzfs | string | 定折方式 |
| dzzq | string | 定折周期 |
| dzgz | string | 定折规则 |
| szkr | string | 上次定折日 |
| ezkr | string | 下次定折日 |
| dzts | number | 下次定折剩余天数 |
| gxrq | string | 更新日期（yyyy-MM-dd） |

## 示例

```json
[{"dm":"161812","mc":"银华深证100分级","clrq":"2010-05-07","dzdx":"A/基础份额","dzfs":"A份额净值归1","dzzq":"1年","dzgz":"按会计年度","szkr":"2020-01-02","ezkr":"2021-01-02","dzts":1,"gxrq":"2020-12-30"}]
```
