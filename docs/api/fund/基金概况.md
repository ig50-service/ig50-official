# 基金概况

> 基金 / 基金档案 / 基本资料 / 基金概况

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 基金概况 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/info/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到基金的基本介绍。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
{}
```
