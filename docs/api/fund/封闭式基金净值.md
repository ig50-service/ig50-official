# 封闭式基金净值

> 基金 / 基金行情 / 净值与回报 / 封闭式基金净值

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 封闭式基金净值 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjhq/jjjzfbs/{基金代码}` |

## 功能描述

获取单只基金净值。根据《所有基金列表》中类型为封闭式基金（tp=2）的代码作为参数传入。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约1小时。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| dwjz | number | 单位净值 |
| ljjz | number | 累计净值 |
| zzl | number | 增长率（%） |
| zyjl | number | 折溢价率（%） |
| jzrq | string | 净值日期 |
| clrq | string | 成立日期 |
| dqrq | string | 到期日期 |
| glr | string | 基金管理人 |
| jjlx | string | 基金类型 |

## 示例

```json
{"dm":"165705","mc":"诺德双翼债券(LOF)","dwjz":0.9470,"ljjz":1.1730,"zzl":0.1057,"zyjl":0,"jzrq":"2023-02-16","clrq":"2012-02-16","dqrq":"","glr":"赵滔滔","jjlx":"债券型基金"}
```
