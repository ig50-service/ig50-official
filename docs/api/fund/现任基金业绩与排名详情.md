# 现任基金业绩与排名详情

> 基金 / 基金档案 / 基本资料 / 现任基金业绩与排名详情

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 现任基金业绩与排名详情 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/jjjl/curr/{基金经理代码}` |

## 功能描述

根据《在任基金经理列表》得到的基金经理代码获取基金经理现在管理的基金收益情况。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码 |
| mc | string | 基金名称 |
| lx | string | 基金类型 |
| j3m | string | 近三月 |
| j3mpm | string | 近三月同类排名 |
| j6m | string | 近六月 |
| j6mpm | string | 近六月同类排名 |
| j1y | string | 近一年 |
| j1ypm | string | 近一年同类排名 |
| j2y | string | 近两年 |
| j2ypm | string | 近两年同类排名 |
| jnl | string | 今年来 |
| jnlpm | string | 今年来同类排名 |
