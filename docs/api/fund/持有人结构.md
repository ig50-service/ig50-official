# 持有人结构

> 基金 / 基金档案 / 财务与规模 / 持有人结构

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 持有人结构 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/gmfe/cyrjg/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历年的持有人结构变化，按公告日期降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 公告日期 |
| jgbl | string | 机构持有比例 |
| grbl | string | 个人持有比例 |
| nbbl | string | 内部持有比例 |
| zfe | string | 总份额（亿份） |

## 示例

```json
[{"t":"2025-12-31","jgbl":"0.50%","grbl":"99.50%","nbbl":"0.00%","zfe":"27.12"},{"t":"2025-06-30","jgbl":"0.55%","grbl":"99.45%","nbbl":"0.00%","zfe":"29.93"}]
```
