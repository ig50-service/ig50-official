# 基金分红

> 基金 / 基金档案 / 基金业绩 / 基金分红

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 基金分红 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjhq/jjfh/{基金代码}` |

## 功能描述

获取单只基金分红。根据《所有基金列表》的代码作为参数传入。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约1小时。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| zxcxr | string | 最新除息日 |
| zxpxr | string | 最新派息日 |
| zxdwfh | number | 最新单位分红 |
| clrq | string | 成立日期 |
| qjfhcs | number | 期间分红次数 |
| qjljfh | number | 期间累计分红 |

## 示例

```json
{"dm":"010529","mc":"广发中债1-5年国开债指数A","zxcxr":"2021-07-14","zxpxr":"2021-07-16","zxdwfh":0.0008,"clrq":"2021-03-16","qjfhcs":1,"qjljfh":0.0008}
```
