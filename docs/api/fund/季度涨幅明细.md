## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 季度涨幅明细 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/jzhb/jjjdzfmx/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的季度涨幅明细，按年份降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| y | string | 年份 |
| zf1 | string | 1季度涨幅 |
| zf2 | string | 2季度涨幅 |
| zf3 | string | 3季度涨幅 |
| zf4 | string | 4季度涨幅 |
