# 海通证券评级

> 基金 / 基金统计 / 评级与机构 / 海通证券评级

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 海通证券评级 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/jjpj/{基金分类参数}` |

## 功能描述

根据【基金分类参数】获取不同分类下的基金的海通证券评级，根据近一年收益率倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| lx | string | 基金类型 |
| gxt | string | 更新时间（yyyyMMdd） |
| gs | string | 基金公司名称 |
| xj | number | 最新星级 |
| xjc | number | 星级变动 |
| syl1 | number | 近一年收益率（%） |
| pm1 | string | 近一年排名 |
| syl2 | number | 近两年收益率（%） |
| pm2 | string | 近两年排名 |
| syl3 | number | 近三年收益率（%） |
| pm3 | string | 近三年排名 |

## 示例

```json
[{"dm":"004997","mc":"广发高端制造A","lx":"主动股票开放型","gxt":"20210129","gs":"广发","xj":5,"xjc":null,"syl1":138.7638,"pm1":1,"syl2":301.6490,"pm2":1,"syl3":169.8498,"pm3":12}]
```
