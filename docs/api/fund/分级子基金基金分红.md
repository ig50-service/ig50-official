# 分级子基金基金分红

> 基金 / 基金统计 / 分红与规模排名 / 分级子基金基金分红

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 分级子基金基金分红 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/jjfh/{基金分类参数}` |

## 功能描述

根据【基金分类参数】获取不同分类下的分级子基金的基金分红，根据最新派息日倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| zxcxr | string | 最新除息日 |
| zxpxr | string | 最新派息日 |
| zxdwfh | number | 最新单位分红 |
| clrq | string | 成立日期 |
| qjfhcs | number | 期间分红次数 |
| qjljfh | number | 期间累计分红 |

## 示例

```json
[{"dm":"010529","mc":"广发中债1-5年国开债指数A","zxcxr":"2021-07-14","zxpxr":"2021-07-16","zxdwfh":0.0008,"clrq":"2021-03-16","qjfhcs":1,"qjljfh":0.0008}]
```
