# 招商证券评级

> 基金 / 基金统计 / 评级与机构 / 招商证券评级

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 招商证券评级 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/jjpj/{基金分类参数}` |

## 功能描述

根据【基金分类参数】（见下方"【基金分类参数】说明"）获取不同分类下的基金的招商证券评级，根据本期评级倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| gxt | string | 更新时间（yyyyMMdd） |
| net | number | 最新净值 |
| pj | number | 本期星级（单位：星，共5星） |
| ld | number | 本期流动性星级（单位：星，共5星） |
| jq | number | 本期时间加权Jensen |
| lpj | number | 上期星级（单位：星，共5星） |
| lld | number | 上期流动性星级（单位：星，共5星） |
| ljq | number | 上期时间加权Jensen |
| syl1m | number | 近一个月收益率（%） |
| syl3m | number | 近一季度收益率（%） |
| sylt1y | number | 今年以来收益率（%） |
| syl1y | number | 近一年收益率（%） |
| syl2y | number | 近两年收益率（%） |
| syl3y | number | 近三年收益率（%） |
| bzc | number | 标准差 |
| beta | number | Beta |
| sp | number | 夏普 |
| tln | number | 特雷诺 |
| zs | number | 詹森 |
| jl | string | 基金经理 |
| glr | string | 基金管理人 |
