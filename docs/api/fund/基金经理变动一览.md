# 基金经理变动一览

> 基金 / 基金档案 / 基本资料 / 基金经理变动一览

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 基金经理变动一览 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/jjjlbd/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历届基金经理变动情况，按任职起始日期降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| qsq | string | 起始期 |
| jzq | string | 截止期 |
| jls | string | 基金经理（格式：[{"name":"姓名","code":"代码"},...]） |
| rzqj | string | 任职期间 |
| rzhb | string | 任职回报 |
