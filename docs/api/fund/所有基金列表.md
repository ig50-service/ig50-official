# 所有基金列表

> 基金 / 基金档案 / 基金列表 / 所有基金列表

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 所有基金列表 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/base/jjdm` |

## 功能描述

获取所有基金（包括开放式基金，封闭式基金、分级子基金）的代码和名称，主要用于"基金档案"、"基金行情"、"基金业绩"、"基金分红"、"基金规模"等接口的参数传入，请根据具体数据接口的描述引导使用。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001） |
| mc | string | 基金名称（如：华夏成长混合） |
| tp | number | 基金类型（1：开放式基金，2：封闭式基金，3：分级子基金） |

## 示例

```json
[{"mc":"东方汇理香港均衡M人民币累算","dm":"968189","tp":1},{"mc":"国联融誉双华6个月持有债券A","dm":"018260","tp":1},{"mc":"东方汇理香港均衡M人民币(对冲)分派","dm":"968188","tp":1},{"mc":"东方汇理香港均衡M人民币(对冲)累算","dm":"968187","tp":1}]
```
