# 代销机构

> 基金 / 基金统计 / 评级与机构 / 代销机构

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 代销机构 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/dxjg/{参数}` |

## 功能描述

根据【参数】（见下方"【参数】说明"）获取代销机构中的银行、证券公司、独立资金销售机构，根据近三月超额收益率倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 机构代码 |
| mc | string | 机构名称 |
| lxr | string | 联系人 |
| bd | string | 电话 |
| num | number | 代销数（只） |

## 示例

```json
[{"dm":"10000020","mc":"招商银行股份有限公司","lxr":"缪建民","ph":"0755-83198888,852-31188888","num":6580}]
```
