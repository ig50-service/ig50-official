# 银河证券评级

> 基金 / 基金统计 / 评级与机构 / 银河证券评级

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 银河证券评级 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/jjpj/{基金分类参数}` |

## 功能描述

根据【基金分类参数】获取不同分类下的基金的银河证券评级，根据近一年增长率倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| gxt | string | 更新时间（yyyyMMdd） |
| zzl1w | number | 近一周增长率（%） |
| zzlpm1w | number | 近一周增长率排名 |
| zzl1m | number | 近一个月增长率（%） |
| zzlpm1m | number | 近一个月增长率排名 |
| zzl3m | number | 近三个月增长率（%） |
| zzlpm3m | number | 近三个月增长率排名 |
| zzl6m | number | 近半年增长率（%） |
| zzlpm6m | number | 近半年增长率排名 |
| zzl1y | number | 近一年增长率（%） |
| zzlpm1y | number | 近一年增长率排名 |
| zzl2y | number | 近两年增长率（%） |
| zzlpm2y | number | 近两年增长率排名 |
| zzl3y | number | 近三年增长率（%） |
| zzlpm3y | number | 近三年增长率排名 |
| zzl4y | number | 近四年增长率（%） |
| zzlpm4y | number | 近四年增长率排名 |
| zzl5y | number | 近五年增长率（%） |
| zzlpm5y | number | 近五年增长率排名 |
| x1 | number | 近一年评星（满分五星） |
| x2 | number | 近两年评星（满分五星） |
| x3 | number | 近三年评星（满分五星） |
| x4 | number | 近四年评星（满分五星） |
| x5 | number | 近五年评星（满分五星） |
