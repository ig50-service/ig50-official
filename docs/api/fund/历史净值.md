# 历史净值

> 基金 / 基金行情 / 净值与回报 / 历史净值

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历史净值 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/jzhb/jjlsjz/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历史净值，按净值日期降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码 |
| mc | string | 基金名称 |
| t | string | 净值日期 |
| dwjz | string | 单位净值 |
| ljjz | string | 累计净值 |
| zzl | string | 日增长率 |
| sgzt | string | 申购状态 |
| shzt | string | 赎回状态 |
| fhsp | string | 分红送配 |
