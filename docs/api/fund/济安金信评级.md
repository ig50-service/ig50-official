# 济安金信评级

> 基金 / 基金统计 / 评级与机构 / 济安金信评级

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 济安金信评级 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/jjpj/{基金分类参数}` |

## 功能描述

根据【基金分类参数】（见下方"【基金分类参数】说明"）获取不同分类下的基金的济安金信评级，根据综合评级倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| gxt | string | 更新时间（yyyyMMdd） |
| zhx | number | 综合评级（单位：星，共5星） |
| ylx | number | 盈利能力评级（单位：星，共5星） |
| yjx | number | 业绩稳定性评级（单位：星，共5星） |
| fxx | number | 抗风险力评级（单位：星，共5星） |
| zsx | number | 择时能力评级（单位：星，共5星） |
| cex | number | 超额收益能力评级（单位：星，共5星） |
| cox | number | 整体费用评级（单位：星，共5星） |

## 示例

```json
[{"dm":"000602","mc":"富国安益货币A","gxt":"2021-06-30","zhx":5,"ylx":5,"yjx":5,"fxx":0,"zsx":0,"gzx":0,"cex":0,"cox":5}]
```
