## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 管理过的基金一览 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/jjjl/his/{基金经理代码}` |

## 功能描述

根据《在任基金经理列表》得到的基金经理代码获取基金经理管理过的基金收益情况。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码 |
| mc | string | 基金名称 |
| lx | string | 基金类型 |
| gm | string | 规模（亿元） |
| rzsj | string | 任职时间 |
| rzts | string | 任职天数 |
| rzhb | string | 任职回报 |
