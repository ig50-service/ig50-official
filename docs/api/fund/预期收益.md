# 预期收益

> 基金 / 基金行情 / 分级基金 / 预期收益

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 预期收益 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/fjjj/yqsy` |

## 功能描述

分级基金预期收益。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| clrq | string | 成立日期（yyyy-MM-dd） |
| sfss | string | 是否上市 |
| yqsy | number | 预期收益（%） |
| ydsy | number | 约定收益（%） |
| qxlx | string | 期限类型 |
| zyjl | number | 折溢价率（%） |
| ydsygz | string | 约定收益率规则 |
| ggzz | string | 挂钩准则 |
| syllx | string | 收益率类型 |
| gxzq | string | 更新周期 |
| gxgz | string | 更新规则 |
| sylms | string | 收益率模式 |
| gxrq | string | 更新日期（yyyy-MM-dd） |
