# 费用分析

> 基金 / 基金档案 / 财务与规模 / 费用分析

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 费用分析 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/cwbb/fyfx/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历年的费用组成分析，按报告期降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 报告期 |
| fyhj | string | 用合计 |
| glrbc | string | 管理人报酬 |
| glrbczb | string | 管理人报酬占比 |
| tgf | string | 托管费 |
| tgfzb | string | 托管费占比 |
| jyf | string | 交易费 |
| jyfzb | string | 交易费占比 |
| xsfwf | string | 销售服务费 |
| xsfwfzb | string | 销售服务费占比 |
