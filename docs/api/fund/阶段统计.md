# 阶段统计

> 基金 / 基金行情 / 净值与回报 / 阶段统计

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 阶段统计 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/jzhb/jjjdtj/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到不同维度（参看下方的“统计维度说明”）的阶段统计。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
{"key":{},...}
```

| j1y | string | 近1年 |
| j2y | string | 近2年 |
| j3y | string | 近3年 |
| j5y | string | 近5年 |
| cll | string | 成立来 |
