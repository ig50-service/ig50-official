# 分红送配

> 基金 / 基金行情 / 净值与回报 / 分红送配

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 分红送配 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/jzhb/jjfhsp/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历史分红送配，按权益登记日降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码 |
| mc | string | 基金名称 |
| nf | string | 年份 |
| djr | string | 权益登记日 |
| cxr | string | 除息日 |
| mffh | string | 每份分红 |
| ffr | string | 分红发放日 |

## 示例

```json
[{"dm":"000001","mc":"华夏成长混合A","nf":"2025年","djr":"2025-09-22","cxr":"2025-09-22","mffh":"每份派现金0.0100元","ffr":"2025-09-23"},{"dm":"000001","mc":"华夏成长混合A","nf":"2023年","djr":"2023-01-12","cxr":"2023-01-12","mffh":"每份派现金0.0018元","ffr":"2023-01-13"}]
```
