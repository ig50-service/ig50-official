## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 成交情况 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/fjjj/ldx/cjqk` |

## 功能描述

分级基金成交情况。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| ssrq | string | 上市日期（yyyy-MM-dd） |
| zzfs | string | 运作方式 |
| rhsl | number | 日换手率（%） |
| cjl | number | 成交量（万份） |
| rcjl | number | 日成交量（万份） |
| cjje | number | 成交金额（万元） |
| rjcjje | number | 日均成交金额（万元） |
| gxrq | string | 更新日期（yyyy-MM-dd） |

## 示例

```json
[{"dm":"150201","mc":"招商券商分级B","ssrq":"2014-11-28","yzfs":"一开两封","rhsl":16.71,"cjl":21479.95,"rcjl":21479.95,"cjje":29901.56,"rjcjje":29901.56,"gxrq":"2020-12-30"}]
```
