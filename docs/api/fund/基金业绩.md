> 基金 / 基金档案 / 基金业绩 / 基金业绩

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 基金业绩 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjhq/jjyj/{基金代码}` |

## 功能描述

获取单只基金业绩。根据《所有基金列表》的代码作为参数传入。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约1小时。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| dwjz | number | 单位净值 |
| ljjz | number | 累计净值 |
| jsgy | number | 近三个月（%） |
| jlgy | number | 近六个月（%） |
| jyn | number | 近一年（%） |
| jnyl | number | 今年以来（%） |
| clyl | number | 成立以来（%） |

## 示例

```json
{"dm":"168203","mc":"中融钢铁指数","dwjz":1.318,"ljjz":1.318,"jsgy":11.0362,"jlgy":null,"jyn":52.5628,"jnyl":141.7204,"clyl":-43.5022}
```
