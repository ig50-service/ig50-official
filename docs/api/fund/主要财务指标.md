# 主要财务指标

> 基金 / 基金档案 / 财务与规模 / 主要财务指标

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 主要财务指标 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/cwbb/zycwzb/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历年的主要财务指标，按报告期降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 报告期 |
| bcys | string | 本期已实现收益（元） |
| bclr | string | 本期利润（元） |
| jqlr | string | 加权平均基金份额本期利润 |
| jqlrl | string | 本期加权平均净值利润率 |
| jqzzl | string | 本期基金份额净值增长率 |
| qmfplr | string | 期末可供分配利润（元） |
| qmfelr | string | 期末可供分配基金份额利润 |
| qmzcjz | string | 期末基金资产净值 |
| qmfejz | string | 期末基金份额净值 |
| ljzzl | string | 基金份额累计净值增长率 |
