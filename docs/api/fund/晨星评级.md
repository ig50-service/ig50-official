# 晨星评级

> 基金 / 基金统计 / 评级与机构 / 晨星评级

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 晨星评级 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/jjpj/{基金分类参数}` |

## 功能描述

根据【基金分类参数】获取不同分类下的基金的晨星评级，根据单位净值倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| lx | string | 基金类型 |
| gxt | string | 更新时间 |
| nav | number | 单位净值（元） |
| bd3y | number | 最近三年波动幅度（%） |
| bd3ypj | string | 最近三年波动幅度风险评价（高、中、低） |
| fxxs3y | number | 最近三年风险系数 |
| fxxs3ypj | string | 最近三年风险系数风险评价（高、中、低） |
| xp2y | number | 最近两年夏普比率 |
| xppj | string | 最近两年夏普比率评价（高、中、低） |
| pj2y | number | 近两年评级（单位：星，共5星） |
| pj5y | number | 近五年评级（单位：星，共5星） |
| hbl1m | number | 回报率（%，最近一个月） |
| hbl6m | number | 回报率（%，最近半年） |
| hbl1y | number | 回报率（%，最近一年） |
| hbl2y | number | 回报率（%，最近二年） |
| hblytd | number | 回报率（%，今年以来） |
| hbl1w | number | 回报率（%，最近一周） |
| hbl3m | number | 回报率（%，最近三个月） |
| hbl3y | number | 回报率（%，最近三年） |
| hbl5y | number | 回报率（%，最近五年） |
| hblall | number | 回报率（%，成立以来） |
| fxpf1m | number | 风险评分（近一个月，参考） |
| fxpf1y | number | 风险评分（近一年，参考） |
| fxpf2y | number | 风险评分（近二年，参考） |
| fxpfjn | number | 风险评分（今年以来，参考） |
| fxpf3y | number | 风险评分（最近三年，参考） |
| fxpf5y | number | 风险评分（最近五年，参考） |
