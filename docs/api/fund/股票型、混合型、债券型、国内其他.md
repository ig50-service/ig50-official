# 股票型、混合型、债券型、国内其他

> 基金 / 基金统计 / 业绩与净值排名 / 股票型、混合型、债券型、国内其他

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 股票型、混合型、债券型、国内其他 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/cesy/{基金分类参数}` |

## 功能描述

根据【基金分类参数】（见下方"【基金分类参数】说明"）获取不同分类下的基金的超额收益，根据近三月超额收益率倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| gxt | string | 更新时间（yyyyMMdd） |
| bjjz | string | 业绩比较基准 |
| syl1m | number | 近一月收益率（%） |
| cesyl1m | number | 近一月超额收益率（%） |
| syl3m | number | 近三月收益率（%） |
| cesyl3m | number | 近三月超额收益率（%） |
| syl6m | number | 近六月收益率（%） |
| cesyl6m | number | 近六月超额收益率（%） |
| syl1y | number | 近一年收益率（%） |
| cesyl1y | number | 近一年超额收益率（%） |
| syl2y | number | 近两年收益率（%） |
| cesyl2y | number | 近两年超额收益率（%） |
| syl3y | number | 近三年收益率（%） |
| cesyl3y | number | 近三年超额收益率（%） |

```json
[{"dm":"004851","mc":"广发医疗保健","gxt":"20190628","bjjz":"中证医药卫生*80% + 中证全债*20%","syl1m":7.53,"cesyl1m":5.2243,"syl3m":10.29,"cesyl3m":17.2591,"syl6m":45.53,"cesyl6m":30.9569,"syl1y":2.26,"cesyl1y":16.0184,"syl2y":0,"cesyl2y":0,"syl3y":0,"cesyl3y":0}]
```
