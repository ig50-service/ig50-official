## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 在任基金经理简介 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/jjjl/info/{基金经理代码}` |

## 功能描述

根据《在任基金经理列表》得到的基金经理代码获取基金经理简介。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| mz | string | 基金经理名字 |
| jlid | string | 基金经理代码 |
| ljrz | string | 累计任职时间 |
| rzqs | string | 任职起始日期 |
| xrjjgs | string | 现任基金公司 |
| xrjjgm | string | 现任基金资产总规模 |
| zjhb | string | 任职期间最佳基金回报 |
| jj | string | 简介 |
