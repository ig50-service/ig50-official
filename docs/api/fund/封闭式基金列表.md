## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 封闭式基金列表 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/base/fbsjj` |

## 功能描述

获取封闭式基金的代码和名称，用于下方接口的参数传入。

## 更新机制

- **更新频率**：每天16:00。
- **完成耗时**：约1分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：sz180801） |
| mc | string | 基金名称（如：首钢绿能） |

## 示例

```json
[{"mc":"中关村","dm":"sh508099"},{"mc":"XD京东仓","dm":"sh508098"},{"mc":"建邺REIT","dm":"sh508097"},{"mc":"京能国际","dm":"sh508096"},{"mc":"金隅智造","dm":"sh508092"}]
```
