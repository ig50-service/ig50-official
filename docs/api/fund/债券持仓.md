# 债券持仓

> 基金 / 基金档案 / 持仓与组合 / 债券持仓

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 债券持仓 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/tzzh/zqcc/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历年投资债券持仓，按截止时间降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jd | string | 季度 |
| t | string | 截止时间 |
| dm | string | 债券代码 |
| mc | string | 债券名称 |
| jzbl | string | 占净值比例 |
| ccsz | string | 持仓市值（万元） |

## 示例

```json
[{"jd":"2026年1季度","t":"2026-03-31","dm":"019827","mc":"26国债01","jzbl":"2.40%","ccsz":"6,336.69"},{"jd":"2026年1季度","t":"2026-03-31","dm":"260401","mc":"26农发01","jzbl":"2.28%","ccsz":"6,025.16"}]
```
