# 份额类型

> 基金 / 基金行情 / 分级基金 / 份额类型

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 份额类型 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/fjjj/jcxx/fexl` |

## 功能描述

分级基金的份额类型统计。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| asymbol | string | A份额代码（如：502024（鹏华国证钢铁A）） |
| aname | string | A份额简称（如：鹏华国证钢铁A） |
| bsymbol | string | B份额代码（如：502025（鹏华国证）） |
| bname | string | B份额简称（如：鹏华国证） |
| fepb | string | 份额配比（A:B） |
| nfepb | string | 当前份额配比（A:B） |
| slrq | string | 设立日期（yyyy-MM-dd） |
| company | string | 基金公司 |
| manager | string | 基金经理 |
| gxrq | string | 更新日期（yyyy-MM-dd） |
