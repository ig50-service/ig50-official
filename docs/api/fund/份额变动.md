# 份额变动

> 基金 / 基金行情 / 分级基金 / 份额变动

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 份额变动 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/fjjj/ldx/febd/{参数}` |

## 功能描述

分级基金份额变动统计（可根据参数查询近一日、近一周、近一月、近三月的数据），根据期末流通份额倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| slrq | string | 设立日期（yyyy-MM-dd） |
| ssrq | string | 上市日期（yyyy-MM-dd） |
| tzlx | string | 投资类型 |
| qcfe | number | 上市起初份额（万份） |
| qcltfe | number | 期初流通份额（万份） |
| qmltfe | number | 期末流通份额（万份） |
| ltfebd | number | 期间流通份额变动值（万份） |
| ltfebdl | number | 期间流通份额变动率（%） |
| gxrq | string | 更新日期（yyyy-MM-dd） |

## 示例

```json
[{"dm":"150022","mc":"申万菱信深成收益","slrq":"2010-10-22","ssrq":"2010-11-08","tzlx":"标准指数股票型基金","qcfe":0.00,"qcltfe":142386.16,"qmltfe":138096.19,"ltfebd":-4289.97,"ltfebdl":-3.01,"gxrq":"2020-12-30"}]
```
