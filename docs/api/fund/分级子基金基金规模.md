# 分级子基金基金规模

> 基金 / 基金统计 / 分红与规模排名 / 分级子基金基金规模

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 分级子基金基金规模 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/all/jjsjzx/jjgm/{基金分类参数}` |

## 功能描述

根据【基金分类参数】获取不同分类下的分级子基金的基金规模，根据总募集规模（万份）倒序。

## 更新机制

- **更新频率**：每天20:30。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 基金代码（如：000001（华夏成长混合）） |
| mc | string | 基金名称（如：华夏成长混合） |
| dwjz | number | 单位净值（元） |
| zmjgm | number | 总募集规模（万份） |
| zjzfe | number | 最近总份额（万份） |
| clrq | string | 成立日期 |
| jjjl | string | 基金经理 |

## 示例

```json
[{"dm":"510300","mc":"华泰柏瑞沪深300ETF","dwjz":5.2095,"zmjgm":3296860,"zjzfe":9186790000,"clrq":"2012-05-04 00:00:00","jjjl":"柳军"}]
```
