# 规模变动

> 基金 / 基金档案 / 财务与规模 / 规模变动

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 规模变动 |
| 所属市场 | 基金 |
| 本地路径 | `数据存放目录/time/jjf10/gmfe/gmbd/{基金代码}` |

## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历年的规模变动，按日期降序。

## 更新机制

- **更新频率**：每周六早上6点更新。
- **完成耗时**：耗时约7小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 日期 |
| qjsg | string | 期间申购（亿份） |
| qjsh | string | 期间赎回（亿份） |
| qmzfe | string | 期末总份额（亿份） |
| qmjzc | string | 期末净资产（亿元） |
| zcbdl | string | 净资产变动率 |

## 示例

```json
[{"t":"2026-03-31","qjsg":"1.25","qjsh":"2.44","qmzfe":"25.92","qmjzc":"26.44","zcbdl":"-9.96%"},{"t":"2025-12-31","qjsg":"0.86","qjsh":"1.77","qmzfe":"27.12","qmjzc":"29.37","zcbdl":"-7.02%"}]
```
