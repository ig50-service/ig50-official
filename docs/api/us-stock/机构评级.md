# 机构评级

> 美股 / 美股基础信息 / 公司详情 / 机构评级

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 机构评级 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/rating/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取机构评级，按发布日期倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| fbrq | string | 发布日期（yyyy-MM-dd） |
| jgdm | string | 机构代码 |
| jgmc | string | 机构名称 |
| zxpj | string | 最新评级（BUY/买入/增持/推荐等） |
| zhpj | string | 综合评级均值 |
| tlpjs | number | 同类评级机构数量 |
| mbj | number | 目标价（美元） |

