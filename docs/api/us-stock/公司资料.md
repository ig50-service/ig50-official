# 公司资料

> 美股 / 美股基础信息 / 公司详情 / 公司资料

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 公司资料 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/orgprofile/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取公司资料。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| gsmc | string | 公司名称 |
| ywmc | string | 英文名称 |
| sshy | string | 所属行业 |
| clrq | string | 公司成立日期（yyyy） |
| dsz | string | 主席 |
| zcd | string | 注册地 |
| bgdz | string | 办公地址 |
| lxdh | string | 联系电话 |
| cz | string | 传真 |
| dzyj | string | 电子邮件 |
| gswz | string | 公司网址 |
| gsjs | string | 公司介绍 |
| ygrs | number | 员工人数（人） |
