# 实时行情数据（3秒落盘）

> 美股 / 美股交易数据 / 行情数据 / 实时行情数据（3秒落盘）

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 实时行情数据（3秒落盘） |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/real/us_{代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取实时交易数据（数据延迟15分钟）。

## 更新机制

- **更新频率**：交易时间段（美东时间）每10秒。
- **完成耗时**：约5秒。

{}
