# 当天逐笔交易

> 美股 / 美股交易数据 / 行情数据 / 当天逐笔交易

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 当天逐笔交易 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/real/trace/onebyone/us_{代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取当天逐笔交易数据，按时间降序（数据延迟40分钟）。

## 更新机制

- **更新频率**：交易时间段每2分钟。
- **完成耗时**：约10秒。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| d | string | 数据更新时间（yyyy-MM-ddHH:mm:ss） |
| t | string | 成交时间（HH:mm:dd） |
| v | number | 成交量（股） |
| p | number | 成交价 |

## 示例

```json
[{"t":"15:29","p":486.4,"v":100,"d":"2026-08-04 16:10:30"},{"t":"15:29","p":486.4,"v":100,"d":"2026-08-04 16:10:30"},{"t":"15:29","p":486.4,"v":800,"d":"2026-08-04 16:10:30"}]
```
