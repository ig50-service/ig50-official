# 高管持股

> 美股 / 美股基础信息 / 股本股东 / 高管持股

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 高管持股 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/leaderhold/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取高管持股，按交易日期倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jyrq | string | 交易日期（yyyy-MM-dd） |
| jyr | string | 交易人 |
| cglx | string | 持股类型（如"转让（非公开市场）"/"售出"等） |
| jylx | string | 交易类型 |
| zw | string | 职位 |
| jygs | number | 交易股数（股） |
| jyjg | number | 交易价格（美元） |
| sygf | number | 剩余持股（股） |
