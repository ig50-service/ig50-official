# 机构持股

> 美股 / 美股基础信息 / 股本股东 / 机构持股

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 机构持股 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/orghold/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取机构持股汇总，按报告期倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| jgjs | number | 机构家数 |
| czzs | number | 持股总数（股） |
| czbl | number | 持股比例（%） |
| xjjg | number | 新进机构 |
| zcjg | number | 增持机构 |
| jcjg | number | 减持机构 |
