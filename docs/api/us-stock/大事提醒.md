# 大事提醒

> 美股 / 美股基础信息 / 公司大事 / 大事提醒

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 大事提醒 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/gsds/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取大事提醒，按公告日期倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| sjlx | string | 事件类型（如"大行评级"/"分红送转"/"年报披露"等） |
| xslx | string | 细说类型 |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| sjnr | string | 事件内容 |
| sjnr2 | string | 补充内容 |
