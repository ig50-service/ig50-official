# 分红派息

> 美股 / 美股基础信息 / 公司大事 / 分红派息

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 分红派息 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/dividend/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取分红派息，按除权除息日倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| jzghr | string | 截止过户日（股权登记日，yyyy-MM-dd） |
| xjffr | string | 现金发放日（派息日，yyyy-MM-dd） |
| cqxcr | string | 除权除息日（yyyy-MM-dd） |
| fhfs | string | 分红方式（如"Cash"现金分红） |
| fasm | string | 方案说明 |
| fpzq | string | 分配周期 |
