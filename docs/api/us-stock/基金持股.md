# 基金持股

> 美股 / 美股基础信息 / 股本股东 / 基金持股

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 基金持股 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/fundhold/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取基金持股，按报告期倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| jgmc | string | 基金名称 |
| cygs | number | 持有股数（股） |
| czbl | number | 持股比例（%） |
| bdgs | number | 变动股数（股）（负数表示减持） |
| bdbl | number | 变动比例（%）（负数表示减持） |

