# 当天分时成交

> 美股 / 美股交易数据 / 行情数据 / 当天分时成交

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 当天分时成交 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/real/trace/timedeal/us_{代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取当天分时成交数据（盘中以分钟为单位统计的成交总量以及平均价格），按时间升序（数据延迟15分钟）。

## 更新机制

- **更新频率**：交易时间段每2分钟。
- **完成耗时**：约10秒。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| d | string | 数据更新时间（yyyy-MM-ddHH:mm:ss） |
| t | string | 分时时间（HH:mm） |
| v | number | 成交量（股） |
| p | number | 成交价 |
| avg | number | 均价 |

## 示例

```json
[{"t":"15:57","p":490.200,"avg":488.288,"v":94351,"d":"2026-08-03 22:18:38"},{"t":"15:58","p":490.400,"avg":488.299,"v":193650,"d":"2026-08-03 22:18:38"},{"t":"15:59","p":490.400,"avg":488.372,"v":1343235,"d":"2026-08-03 22:18:38"}]
```
