## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 美股列表 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/base/gpus` |

## 功能描述

获取美股股票代码和名称，用于后续接口的参数传入。美股股票（不含指数），约1.3万只。

## 更新机制

- **更新频率**：美东时间每天0点。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 股票代码（如：TSLA） |
| mc | string | 股票名称（如：特斯拉） |
| isIndex | number | 是否是指数，0：否，1：是（预留字段） |

## 示例

```json
[{"dm":"A","mc":"安捷伦科技","jys":"us","isIndex":0,"wholeDm":"us_A"},{"dm":"AA","mc":"美国铝业","jys":"us","isIndex":0,"wholeDm":"us_AA"}]
```
