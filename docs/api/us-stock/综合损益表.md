# 综合损益表

> 美股 / 美股基础信息 / 财务分析 / 综合损益表

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 综合损益表 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/income/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取综合损益表，按报告日期倒序、科目代码升序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| date | string | 报告日期（yyyy-MM-dd） |
| dcode | string | 日期类型代码（001年报/006单季报Q3/007单季报Q4等） |
| code | string | 科目代码 |
| name | string | 科目名称 |
| amount | number | 金额（美元） |

## 示例

```json
[{"date":"2026-06-30","dcode":"001","code":"004017004","name":"摊薄每股收益-普通股","amount":17.950},{"date":"2026-06-30","dcode":"007","code":"004019001","name":"本公司拥有人占全面收益总额","amount":35710000000.000},{"date":"2026-06-30","dcode":"007","code":"004007999","name":"营业费用","amount":19879000000.000}]
```
