## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 卖空明细 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/short/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取卖空明细，按结算日倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jsrq | string | 结算日（yyyy-MM-dd） |
| wpckg | number | 未平仓做空（股） |
| pjcjl | number | 区间平均成交量（股） |
| hbts | number | 回补天数 |
| zdf | number | 当日涨跌幅（%） |
| zkzb | number | 做空头寸占比 |
| spj | number | 结算日收盘价（美元） |
