# 历史K线（数据范围：短分时4万根，日线及以上所有）

> 美股 / 美股交易数据 / K线数据 / 历史K线（数据范围：短分时4万根，日线及以上所有）

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历史K线（数据范围：短分时4万根，日线及以上所有） |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/history/trade/us_{代码}/{级别}` |

## 功能描述

根据《美股列表》得到的股票代码和分时级别获取历史交易数据，交易时间升序（数据延迟15分钟）。

## 更新机制

- **更新频率**：分钟级别盘中（美东时间）每10秒更新，日线及以上级别每天16:30（美东时间）更新。
- **完成耗时**：日线及以上级别耗时约30分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| d | string | 交易时间（美东时间，短分时级别格式为yyyy-MM-ddHH:mm:ss，日线及以上级别为yyyy-MM-dd） |
| o | number | 开盘价（美元） |
| h | number | 最高价（美元） |
| l | number | 最低价（美元） |
| c | number | 收盘价（美元） |
| v | number | 成交量（股） |
| e | number | 成交额（美元） |
| zf | number | 振幅（%） |
| hs | number | 换手率（%） |
| zd | number | 涨跌幅（%） |
| zde | number | 涨跌额（美元） |
| ud | string | 更新时间（美东时间，短分时级别格式为yyyy-MM-ddHH:mm:ss） |
