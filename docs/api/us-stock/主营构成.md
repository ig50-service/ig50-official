# 主营构成

> 美股 / 美股基础信息 / 公司详情 / 主营构成

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 主营构成 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/maincompose/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取主营构成，按报告日期倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| riq | string | 报告日（yyyy-MM-dd） |
| rqmc | string | 报告期名称 |
| lx | string | 类型（product按产品分类/region按地区分类） |
| mc | string | 名称（产品名或地区名） |
| zysr | number | 主营业务收入（美元） |
| zycb | number | 主营业务成本（美元） |
| mllr | number | 毛利润（美元） |
| zb | number | 占比 |
| mllv | number | 毛利率 |
| sfhj | number | 是否合计行（0非合计/1合计） |
