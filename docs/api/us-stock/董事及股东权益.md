# 董事及股东权益

> 美股 / 美股基础信息 / 股本股东 / 董事及股东权益

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 董事及股东权益 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/holder/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取董事及股东权益，按报告期倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| cgr | string | 持股人 |
| qylx | string | 权益类型（如"董事"/"股东"） |
| gflx | string | 股份类型 |
| bgrlx | string | 报告人类型 |
| qygf | number | 权益股份（股） |
| qyzb | number | 权益占比（%） |
| bdbl | number | 变动比例（%） |
