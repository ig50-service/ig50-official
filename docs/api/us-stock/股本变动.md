# 股本变动

> 美股 / 美股基础信息 / 股本股东 / 股本变动

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 股本变动 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/equitychange/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取股本变动，按变动日期倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bdrq | string | 变动日期（yyyy-MM-dd） |
| ptgf | number | 已发行普通股（股） |
| yxgf | number | 已发行优先股（股） |
| bdyy | string | 变动原因（如"定期报告"/"股份拆细"等） |

## 示例

