# 拆股并股

> 美股 / 美股基础信息 / 股本股东 / 拆股并股

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 拆股并股 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/stocksplit/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取拆股并股，按除权日倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| fams | string | 方案说明 |
| cqrq | string | 除权日（yyyy-MM-dd） |
