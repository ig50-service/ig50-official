# 资产负债表

> 美股 / 美股基础信息 / 财务分析 / 资产负债表

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 资产负债表 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/balance/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取资产负债表，按报告日期倒序、科目代码升序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| date | string | 报告日期（yyyy-MM-dd） |
| dcode | string | 日期类型代码（001年报/006单季报Q3/007单季报Q4等） |
| code | string | 科目代码 |
| name | string | 科目名称 |
| amount | number | 金额（美元） |

## 示例

```json
[{"date":"2026-06-30","dcode":"001","code":"004001004","name":"应收账款","amount":80876000000.000},{"date":"2026-06-30","dcode":"001","code":"004003999","name":"非流动资产合计","amount":550666000000.000},{"date":"2026-06-30","dcode":"001","code":"004013004","name":"留存收益","amount":328265000000.000}]
```
