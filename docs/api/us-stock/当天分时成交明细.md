# 当天分时成交明细

> 美股 / 美股交易数据 / 行情数据 / 当天分时成交明细

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 当天分时成交明细 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/real/time/trace/onebyone/us_{代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取当天3秒为粒度聚合的成交数据，按成交时间升序（数据延迟40分钟）。

## 更新机制

- **更新频率**：交易时间段每2分钟。
- **完成耗时**：约10秒。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 成交时间（HH:mm，美东时间） |
| p | number | 成交价（美元） |
| ts | number | 交易方向（0：中性盘，1：买入，2：卖出） |
| v | number | 成交量（股） |
| d | string | 数据更新时间（yyyy-MM-ddHH:mm:ss） |

## 示例

```json
[{"t":"03:59","p":370.71,"ts":0,"v":5917,"d":"2026-09-08 02:08:13"},{"t":"04:00","p":370.57,"ts":2,"v":24079,"d":"2026-09-08 02:08:13"},{"t":"04:00","p":370.7,"ts":1,"v":18277,"d":"2026-09-08 02:08:13"}]
```
