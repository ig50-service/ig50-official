# 证券资料

> 美股 / 美股基础信息 / 公司详情 / 证券资料

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 证券资料 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/secinfo/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取证券资料。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jys | string | 上市场所 |
| ssrq | string | 上市日期（yyyy-MM-dd） |
| njr | string | 年结日（MM-dd） |
| isin | string | ISIN国际证券识别编码 |
| fxj | number | 发行价格（美元） |
| fxl | number | 发行量（股） |
| mfmz | string | 每股面值 |
| adszhb | number | ADS折算比 |

## 示例

```json
{"jys":"NASDAQ","ssrq":"1986-03-13","njr":"06-30","isin":"US5949181045","fxj":0.000,"fxl":0,"mfmz":"0.00000625 USD","adszhb":0.00}
```
