## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 主要指标 |
| 所属市场 | 美股 |
| 本地路径 | `数据存放目录/time/us/f10/finmainindex/{股票代码}` |

## 功能描述

根据《美股列表》得到的股票代码获取主要指标，按报告日期倒序。

## 更新机制

- **更新频率**：每天美东时间18:00，耗时约10个小时。
- **完成耗时**：-
