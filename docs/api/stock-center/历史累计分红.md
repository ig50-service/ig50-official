# 历史累计分红

> 沪深数据中心 / 数据中心 / 投资参考 / 历史累计分红

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历史累计分红 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/fh` |

## 功能描述

各支股票历史累计分红统计。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 证券代码 |
| mc | string | 股票名称 |
| pdate | string | 上市日期（yyyy-MM-dd） |
| totalgx | number | 累计股息（%） |
| pergx | number | 年均股息（%） |
| count | number | 分红次数 |
| totalrz | number | 融资总额（亿） |
| rzcount | number | 融资次数 |

## 示例

```json
[{"dm":"000541","mc":"佛山照明","pdate":"1993-11-23","totalgx":174.90,"pergx":6.48,"count":48,"totalrz":0.0000,"rzcount":0}]
```
