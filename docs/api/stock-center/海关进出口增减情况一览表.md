| 项目 | 内容 |

## 功能描述

获取海关进出口增减情况一览表，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| ck | number | 当月出口额（千美元） |
| jk | number | 当月进口额（千美元） |
| cktb | number | 当月出口额同比增长（%） |
| jktb | number | 当月进口额同比增长（%） |
| ckhb | number | 当月出口额环比增长（%） |
| jkhb | number | 当月进口额环比增长（%） |
| cklj | number | 累计出口额（千美元） |
| jklj | number | 累计进口额（千美元） |
| ckljtb | number | 累计出口额同比增长（%） |
| jkljtb | number | 累计进口额同比增长（%） |
