# 外汇和黄金储备

> 沪深数据中心 / 宏观数据 / 宏观经济 / 外汇和黄金储备

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 外汇和黄金储备 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/hjwh` |

## 功能描述

获取外汇和黄金储备，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| wh | number | 国家外汇储备（亿美元） |
| whtb | number | 外汇储备同比（%） |
| whhb | number | 外汇储备环比（%） |
| hj | number | 黄金储备（亿美元） |
| hjtb | number | 黄金储备同比（%） |
| hjhb | number | 黄金储备环比（%） |

## 示例

```json
[{"tjsj":"2026-08-01","tjyf":"2026年08月份","wh":34383.250,"whtb":3.50,"whhb":0.57,"hj":3500.800,"hjtb":37.91,"hjhb":14.27},{"tjsj":"2026-07-01","tjyf":"2026年07月份","wh":34187.760,"whtb":3.84,"whhb":0.07,"hj":3063.540,"hjtb":25.56,"hjhb":0.87}]
```
