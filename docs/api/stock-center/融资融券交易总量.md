# 融资融券交易总量

> 沪深数据中心 / 数据中心 / 投资参考 / 融资融券交易总量

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 融资融券交易总量 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/rzrqtt` |

## 功能描述

上一个交易日（当前交易日的数据要到第二天才出）的两市融资融券概览。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 日期（yyyy-MM-dd） |
| market | string | 市场（"沪市"/"深市"） |
| rzye | number | 本日融资余额（元） |
| rzmr | number | 本日融资买入额（元） |
| rzch | number | 本日融资偿还额（元） |
| rzyl | number | 本日融券余量金额（元） |

## 示例

```json
[{"t":"2021-01-11","market":"沪市","rzye":695046971352,"rzmr":53026319883,"rzch":52385502345,"rzyl":0},{"t":"2021-01-11","market":"深市","rzye":663502549537,"rzmr":61055749461,"rzch":0,"rzyl":53906376131}]
```
