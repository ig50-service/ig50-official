## 更新机制

- **更新频率**：每天15:30
- **完成耗时**：约10分钟

## 数据格式

```
[{},..]
```

## 字段说明

日期yyyy-MM-dd, 市场："沪市"和"深市", 本日融资余额(元), 本日融资买入额(元), 本日融资偿还额(元), 本日融券余量金额(元)
