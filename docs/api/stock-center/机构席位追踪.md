## 功能描述

## 更新机制

- **更新频率**：每天15:30
- **完成耗时**：约10分钟

## 数据格式

```
[{},...]
```

## 字段说明

股票代码, 股票名称, 累积买入额(万), 买入次数, 累积卖出额(万), 卖出次数, 净额(万)
