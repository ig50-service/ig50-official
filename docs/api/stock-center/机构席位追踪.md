# 机构席位追踪

> 沪深数据中心 / 数据中心 / 龙虎榜 / 机构席位追踪

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 机构席位追踪 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/jgzz/{近n日}` |

## 功能描述

近n日个股机构交易追踪，其中近n日中的n可以是5、10、30、60。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 股票代码 |
| mc | string | 股票名称 |
| be | number | 累积买入额（万元） |
| bcount | number | 买入次数 |
| se | number | 累积卖出额（万元） |
| scount | number | 卖出次数 |
| ende | number | 净额（万元） |

## 示例

```json
[{"dm":"002714","mc":"牧原股份","be":63709.3,"bcount":3,"se":1620.3,"scount":0,"ende":62089}]
```
