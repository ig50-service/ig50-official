# 现金流量

> 沪深数据中心 / 数据中心 / 财务分析 / 现金流量

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 现金流量 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/finxjll/{年份_季度}` |

## 功能描述

个股现金流量汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| mc | string | 名称 |
| xjlxxbl | number | 经营现金净流量对销售收入比率（%） |
| xjlhbl | number | 资产的经营现金流量回报率（%） |
| xjljlrbl | number | 经营现金净流量与净利润的比率（%） |
| xjlfzbl | number | 经营现金净流量对负债比率（%） |
| xjllbl | number | 现金流量比率（%） |
| y | number | 报告年份（如2021） |
| q | number | 报告季度（1:一季报，2：中报，3：三季报，4：年报） |
| yq | string | 报告年份季度含义（如“2021年一季报”） |

## 示例

```json
[{"dm":"600705","mc":"中航资本","xjlxxbl":0.9716,"xjlhbl":0.0264,"xjljlrbl":1.9042,"xjlfzbl":0.0317,"xjllbl":4.5858,"y":2021,"q":1,"yq":"2021年一季报"}]
```
