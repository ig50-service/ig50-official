## 功能描述

沪股通（港→沪）历史数据，按日期倒序

## 更新机制

- **更新频率**：每天20:00
- **完成耗时**：约10分钟

## 数据格式

```
[{}]
```

## 字段说明

日期, 当日成交净买额（百万）：当日成交净买额=买入成交额-卖出成交额。, 买入成交额（百万）, 卖出成交额（百万）, 历史累计净买额（百万）, 当日资金流入（百万）：当日资金流入额=当日限额-当日余额。当日资金流入额包含两部分：当日成交净买额，当日申报但未成交的买单金额。, 当日余额（百万）, 领涨股代码, 领涨股名称, 领涨股涨跌幅（%）, 上证指数点位, 指数涨跌幅（%）
