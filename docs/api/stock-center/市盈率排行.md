|------|------|
| 数据名称 | 沪深数据中心-数据中心-市场表现-市盈率排行 |

| 本地路径 | `数据存放目录/all/syl` |

## 功能描述

沪深京A股静态市盈率、动态市盈率排名，静态市盈率以最近一个年度收益进行计算，动态市盈率以最近四个季度的单季收益进行计算

## 更新机制

- **更新频率**：每天20:00
- **完成耗时**：约10分钟

## 数据格式

```
[{}...]
```

## 字段说明

日期yyyy-MM-dd, 代码, 名称, 收盘价, 涨跌幅（%）, 成交量（股）, 换手率（%）, 静态市盈率：总市值除以上年度净利润, 市盈率(TTM)：最新价除以最近4个季度的每股收益
