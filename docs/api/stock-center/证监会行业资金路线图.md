## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 证监会行业资金路线图 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/zjlx/zjhhyzjlx` |

## 功能描述

统计近3、5、10天证监会行业资金流入情况。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 服务器更新时间（yyyy-MM-ddHH:mm:ss） |
| mc | string | 行业名 |
| dm | string | 行业代码 |
| ac3 | number | 近三日涨跌幅（%） |
| net3 | number | 近三日净流入（元） |
| ra3 | number | 近三日净流入率（%） |
| ac5 | number | 近五日涨跌幅（%） |
| net5 | number | 近五日净流入（元） |
| ra5 | number | 近五日净流入率（%） |
| ac10 | number | 近十日涨跌幅（%） |
| net10 | number | 近十日净流入（元） |
| ra10 | number | 近十日净流入率（%） |
