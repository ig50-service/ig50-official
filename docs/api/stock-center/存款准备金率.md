# 存款准备金率

> 沪深数据中心 / 宏观数据 / 金融货币 / 存款准备金率

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 存款准备金率 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/ckzbj` |

## 功能描述

获取存款准备金率历次调整，按公布时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 生效时间（yyyy-MM-dd） |
| gbsj | string | 公布时间（yyyy-MM-dd） |
| dxq | number | 大型金融机构存款准备金率调整前（%） |
| dxh | number | 大型金融机构存款准备金率调整后（%） |
| dxfd | number | 大型金融机构存款准备金率调整幅度（%） |
| zxq | number | 中小金融机构存款准备金率调整前（%） |
| zxh | number | 中小金融机构存款准备金率调整后（%） |
| zxfd | number | 中小金融机构存款准备金率调整幅度（%） |
| shtz | number | 消息公布次日上证指数涨跌（%） |
| sztz | number | 消息公布次日深证指数涨跌（%） |
| bz | string | 备注（央行公告说明，早年调整为null） |
