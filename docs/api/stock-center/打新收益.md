# 打新收益

> 沪深数据中心 / 数据中心 / 投资参考 / 打新收益

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 打新收益 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/ne` |

## 功能描述

近几年（四年左右）的打新收益数据。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 证券代码 |
| sgdm | string | 申购代码 |
| mc | string | 股票名称 |
| pdate | string | 上市日期（yyyy-MM-dd） |
| ndate | String | 网签日期（yyyy-MM-dd） |
| pe | number | 市盈率 |
| zql | number | 中签率（%） |
| zdf | number | 涨跌幅（%） |
| sy | number | 收益 |
| p | number | 发行价格 |
| amount | number | 发行数量 |

## 示例

```json
[{"dm":"601963","sgdm":"780963","mc":"重庆银行","pdate":"-","ndate":"2021-01-21","pe":8.97,"zql":0.00,"zdf":0.00,"sy":0,"p":10.83,"amount":34745}]
```
