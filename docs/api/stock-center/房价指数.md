# 房价指数

> 沪深数据中心 / 宏观数据 / 宏观经济 / 房价指数

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 房价指数 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/newhouse/｛年份-月份｝` |

## 功能描述

获取70城新建商品住宅与二手住宅价格指数，传入年月参数（最早为2011-01），一般为每月1号更新数据。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| cs | string | 城市（70城） |
| xftb | number | 新建商品住宅价格指数同比 |
| xfhb | number | 新建商品住宅价格指数环比 |
| estb | number | 二手住宅价格指数同比 |
| eshb | number | 二手住宅价格指数环比 |

## 示例

```json
[{"cs":"北京","xftb":97.70,"xfhb":99.80,"estb":96.50,"eshb":99.90},{"cs":"天津","xftb":95.90,"xfhb":99.80,"estb":94.40,"eshb":99.50}]
```
