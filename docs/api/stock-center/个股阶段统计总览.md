## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 个股阶段统计总览 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/zjlx/ggjdtjzl` |

## 功能描述

个股阶段净流入资金统计总览，根据股票代码升序排列。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 服务器更新时间（yyyy-MM-ddHH:mm:ss） |
| mc | string | 名称 |
| dm | string | 代码 |
| zxj | number | 最新价（元） |
| zdf | number | 涨跌幅（%） |
| hsl | number | 换手率（%） |
| jlrl3 | number | 3日净流入率（%） |
| jlrl5 | number | 5日净流入率（%） |
| jlrl10 | number | 10日净流入率（%） |
| jlrl20 | number | 20日净流入率（%） |
| jlrl60 | number | 60日净流入率（%） |
