# 成长能力

> 沪深数据中心 / 数据中心 / 财务分析 / 成长能力

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 成长能力 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/fincznl/{年份_季度}` |

## 功能描述

个股成长能力汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| mc | string | 名称 |
| zyzzl | number | 主营业务收入增长率（%） |
| jlrzzl | number | 净利润增长率（%） |
| jzczzl | number | 净资产增长率（%） |
| zzczzl | number | 总资产增长率（%） |
| mgzzl | number | 每股收益增长率（%） |
| gdzzl | number | 股东权益增长率（%） |
| y | number | 报告年份（如2021） |
| q | number | 报告季度（1:一季报，2：中报，3：三季报，4：年报） |
| yq | string | 报告年份季度含义（如“2021年一季报”） |
