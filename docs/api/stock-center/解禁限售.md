# 解禁限售

> 沪深数据中心 / 数据中心 / 投资参考 / 解禁限售

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 解禁限售 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/rb` |

## 功能描述

以当前交易日的前后15天左右为时间范围，已经进行或者即将进行的解禁限售行为。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 股票代码 |
| mc | string | 股票名称 |
| rdate | string | 解禁日期（yyyy-MM-dd） |
| ramount | number | 解禁数量（万股） |
| rprice | number | 解禁股流通市值（亿元） |
| batch | number | 上市批次 |
| pdate | string | 公告日期（yyyy-MM-dd） |

## 示例

```json
[{"dm":"600745","mc":"闻泰科技","rdate":"2021-01-27","ramount":4458.11,"rprice":47.2560,"batch":14,"pdate":"2020-07-29"}]
```
