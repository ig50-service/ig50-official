# 利率调整

> 沪深数据中心 / 宏观数据 / 金融货币 / 利率调整

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 利率调整 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/yhll` |

## 功能描述

获取存贷款基准利率历次调整，按生效时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 生效时间（yyyy-MM-dd） |
| gbsj | string | 公布时间（yyyy-MM-dd） |
| ckq | number | 存款基准利率调整前（%） |
| ckh | number | 存款基准利率调整后（%） |
| ckfd | number | 存款基准利率调整幅度（%，个别调整未动存款利率为null） |
| dkq | number | 贷款基准利率调整前（%） |
| dkh | number | 贷款基准利率调整后（%） |
| dkfd | number | 贷款基准利率调整幅度（%） |
| shtz | number | 消息公布次日上证指数涨跌（%） |
| sztz | number | 消息公布次日深证指数涨跌（%） |

## 示例

```json
[{"tjsj":"2015-10-24","gbsj":"2015-10-23","ckq":1.75,"ckh":1.50,"ckfd":-0.25,"dkq":4.60,"dkh":4.35,"dkfd":-0.25,"shtz":0.50,"sztz":0.73},{"tjsj":"2015-08-26","gbsj":"2015-08-25","ckq":2.00,"ckh":1.75,"ckfd":-0.25,"dkq":4.85,"dkh":4.60,"dkfd":-0.25,"shtz":-1.27,"sztz":-2.92}]
```
