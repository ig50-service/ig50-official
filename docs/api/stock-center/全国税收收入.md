## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 全国税收收入 |

## 功能描述

获取全国税收收入，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计季度（如"2026年第1-2季度"） |
| ss | number | 税收收入合计（亿元） |
| tb | number | 较上年同期增长（%） |
| hb | number | 季度环比增长（%） |

## 示例

```json
[{"tjsj":"2026-06-01","tjyf":"2026年第1-2季度","ss":97865.000,"tb":5.30,"hb":0.02},{"tjsj":"2026-03-01","tjyf":"2026年第1季度","ss":48505.000,"tb":2.20,"hb":0.11}]
```
