# 每日详情

> 沪深数据中心 / 数据中心 / 龙虎榜 / 每日详情

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 每日详情 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/ld` |

## 功能描述

今日龙虎榜概览。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约1分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 日期（yyyy-MM-dd） |
| dpl7 | string | 跌幅偏离值达7%的证券（LhbDetail对象数组） |
| z20 | string | 连续三个交易日内，涨幅偏离值累计达20%的证券（LhbDetail对象数组） |
| zpl7 | string | 涨幅偏离值达7%的证券（LhbDetail对象数组） |
| h20 | string | 换手率达20%的证券（LhbDetail对象数组） |
| st15 | string | 连续三个交易日内，涨幅偏离值累计达到15%的ST证券、*ST证券和未完成股改证券（LhbDetail对象数组） |
| st12 | string | 连续三个交易日内，涨幅偏离值累计达到12%的ST证券、*ST证券和未完成股改证券（LhbDetail对象数组） |
| std15 | string | 连续三个交易日内，跌幅偏离值累计达到15%的ST证券、*ST证券和未完成股改证券（LhbDetail对象数组） |
| std12 | string | 连续三个交易日内，跌幅偏离值累计达到12%的ST证券、*ST证券和未完成股改证券（LhbDetail对象数组） |
| zf15 | string | 振幅值达15%的证券（LhbDetail对象数组） |
| df15 | string | 连续三个交易日内，跌幅偏离值累计达20%的证券（LhbDetail对象数组） |
| wxz | string | 无价格涨跌幅限制的证券（LhbDetail对象数组） |
| wxztp | string | 当日无价格涨跌幅限制的A股，出现异常波动停牌的股票（LhbDetail对象数组） |
| dm | string | 股票代码 |
| mc | string | 股票名称 |
| c | number | 收盘价（元） |
| val | number | 对应值（%） |
| v | number | 成交量（万股） |
| e | number | 成交额（万元） |
