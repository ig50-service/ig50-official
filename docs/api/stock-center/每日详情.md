## 字段说明

日期yyyy-MM-dd, 跌幅偏离值达7%的证券，格式："dpl7":[LhbDetail,...]，LhbDetail对象说明见下表。, 连续三个交易日内，涨幅偏离值累计达20%的证券，格式："z20":[LhbDetail,...]，LhbDetail对象说明见下表。, 涨幅偏离值达7%的证券，格式："zpl7":[LhbDetail,...]，LhbDetail对象说明见下表。, 换手率达20%的证券，格式："h20":[LhbDetail,...]，LhbDetail对象说明见下表。, 连续三个交易日内，涨幅偏离值累计达到15%的ST证券、*ST证券和未完成股改证券，格式："st15":[LhbDetail,...]，LhbDetail对象说明见下表。, 连续三个交易日内，涨幅偏离值累计达到12%的ST证券、*ST证券和未完成股改证券，格式："st12":[LhbDetail,...]，LhbDetail对象说明见下表。, 连续三个交易日内，跌幅偏离值累计达到15%的ST证券、*ST证券和未完成股改证券，格式："std15":[LhbDetail,...]，LhbDetail对象说明见下表。, 连续三个交易日内，跌幅偏离值累计达到12%的ST证券、*ST证券和未完成股改证券，格式："std12":[LhbDetail,...]，LhbDetail对象说明见下表。, 振幅值达15%的证券，格式："zf15":[LhbDetail,...]，LhbDetail对象说明见下表。, 连续三个交易日内，跌幅偏离值累计达20%的证券，格式："df15":[LhbDetail,...]，LhbDetail对象说明见下表。, 无价格涨跌幅限制的证券，格式："wxz":[LhbDetail,...]，LhbDetail对象说明见下表。, 当日无价格涨跌幅限制的A股，出现异常波动停牌的股票，格式："wxztp":[LhbDetail,...]，LhbDetail对象说明见下表。, 股票代码, 股票名称, 收盘价(元), 对应值(%), 成交量(万股), 成交额(万元)
