> 沪深数据中心 / 数据中心 / 投资参考 / 今日交易提示

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 今日交易提示 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/tt` |

## 功能描述

今日股票、基金公告事项以及交易异动概览。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

{}
