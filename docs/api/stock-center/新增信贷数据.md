# 新增信贷数据

> 沪深数据中心 / 宏观数据 / 金融货币 / 新增信贷数据

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 新增信贷数据 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/xzxd` |

## 功能描述

获取新增信贷数据，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| dy | number | 当月新增人民币贷款（亿元） |
| tb | number | 当月同比增长（%） |
| hb | number | 当月环比增长（%） |
| lj | number | 累计新增人民币贷款（亿元） |
| ljtb | number | 累计同比增长（%） |

## 示例

```json
[{"tjsj":"2026-08-01","tjyf":"2026年08月份","dy":552.000,"tb":-91.17,"hb":109.36,"lj":102261.000,"ljtb":-20.92},{"tjsj":"2026-07-01","tjyf":"2026年07月份","dy":-5896.000,"tb":-37.24,"hb":-133.41,"lj":101709.000,"ljtb":-17.35}]
```
