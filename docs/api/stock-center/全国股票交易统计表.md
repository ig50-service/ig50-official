## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 全国股票交易统计表 |

## 功能描述

获取全国股票交易统计表，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| shgb | number | 上海发行总股本（亿股，当月未走完为null） |
| shsz | number | 上海市价总值（亿元，当月未走完为null） |
| shje | number | 上海成交金额（亿元，当月未走完为null） |
| shcl | number | 上海成交量（亿股，当月未走完为null） |
| shzg | number | 上海A股最高综合股价指数 |
| shzd | number | 上海A股最低综合股价指数 |
| szgb | number | 深圳发行总股本（亿股，当月未走完为null） |
| szsz | number | 深圳市价总值（亿元，当月未走完为null） |
| szje | number | 深圳成交金额（亿元，当月未走完为null） |
| szcl | number | 深圳成交量（亿股，当月未走完为null） |
| szzg | number | 深圳A股最高综合股价指数 |
| szzd | number | 深圳A股最低综合股价指数 |
