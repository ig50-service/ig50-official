## 功能描述

获取企业商品价格指数，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| zzzs | number | 总指数（定基指数值） |
| zztb | number | 总指数同比增长（%） |
| zzhb | number | 总指数环比增长（%） |
| ncp | number | 农产品指数（定基指数值） |
| nctb | number | 农产品指数同比增长（%） |
| nchb | number | 农产品指数环比增长（%） |
| kcp | number | 矿产品指数（定基指数值） |
| kctb | number | 矿产品指数同比增长（%） |
| kchb | number | 矿产品指数环比增长（%） |
| kyd | number | 煤油电指数（定基指数值） |
| kytb | number | 煤油电指数同比增长（%） |
| kyhb | number | 煤油电指数环比增长（%） |
