# 流通市值排行

> 沪深数据中心 / 数据中心 / 市场表现 / 流通市值排行

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 流通市值排行 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/ltsz` |

## 功能描述

沪深京A股流通市值排名。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 日期（yyyy-MM-dd） |
| dm | string | 代码 |
| mc | string | 名称 |
| c | number | 收盘价 |
| zdf | number | 涨跌幅（%） |
| v | number | 成交量（股） |
| hs | number | 换手率（%） |
| ltsz | number | 流通市值（万元） |
| zsz | number | 总市值（万元） |

## 示例

```json
[{"t":"2021-01-18","dm":"sh600000","mc":"浦发银行","c":10.080,"zdf":161.30,"v":96389498,"hs":0,"ltsz":29586958.020144,"zsz":29586958.020144}]
```
