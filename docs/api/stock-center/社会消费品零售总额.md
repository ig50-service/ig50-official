# 社会消费品零售总额

> 沪深数据中心 / 宏观数据 / 宏观经济 / 社会消费品零售总额

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 社会消费品零售总额 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/xfp` |

## 功能描述

获取社会消费品零售总额，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| dy | number | 当月零售总额（亿元） |
| tb | number | 当月同比增长（%） |
| hb | number | 当月环比增长（%） |
| lj | number | 累计零售总额（亿元） |
| ljtb | number | 累计同比增长（%） |

## 示例

```json
[{"tjsj":"2026-08-01","tjyf":"2026年08月份","dy":39824.400,"tb":0.40,"hb":2.06,"lj":327568.800,"ljtb":1.10},{"tjsj":"2026-07-01","tjyf":"2026年07月份","dy":39022.300,"tb":0.60,"hb":-8.59,"lj":287744.400,"ljtb":1.20}]
```
