## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 外商直接投资（实际利用外资金额） |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/fdi` |

## 功能描述

获取外商直接投资实际利用外资金额，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计年份（如"2025年"） |
| wz | number | 实际利用外资金额（亿美元，当年） |
| tb | number | 同比增长（%） |

## 示例

```json
[{"tjsj":"2025-12-01","tjyf":"2025年","wz":1046.600,"tb":-0.10},{"tjsj":"2024-12-01","tjyf":"2024年","wz":1162.377,"tb":-0.29}]
```
