# 连续放量个股

> 沪深数据中心 / 数据中心 / 市场表现 / 连续放量个股

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 连续放量个股 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/lxfl` |

## 功能描述

沪深京A股中成交量连续放大的股票。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 日期（yyyy-MM-dd） |
| dm | string | 代码 |
| mc | string | 名称 |
| c | number | 收盘价 |
| zdf | number | 涨跌幅（%） |
| iscq | number | 当天是否除权除息（0否/1是） |
| v | number | 成交量（股） |
| pv | number | 前一交易日成交量（股） |
| flday | number | 放量天数 |
| pzdf | number | 阶段涨跌幅（%） |
| ispcq | number | 阶段是否除权除息（0否/1是） |
| phs | number | 阶段换手率（%） |

## 示例

```json
[{"t":"2021-01-15","dm":"sz000611","mc":"ST天首","c":2.7400,"zdf":0.00,"v":1186350,"pv":1137750,"flday":3,"pzdf":1.11,"phs":1.35,"iscq":0,"ispcq":0}]
```
