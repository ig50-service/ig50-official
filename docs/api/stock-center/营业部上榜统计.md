# 营业部上榜统计

> 沪深数据中心 / 数据中心 / 龙虎榜 / 营业部上榜统计

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 营业部上榜统计 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/yyb/{近n日}` |

## 功能描述

近n日营业部上榜统计，其中近n日中的n可以是5、10、30、60。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| yybmc | string | 营业部名称 |
| count | number | 上榜次数 |
| totalb | number | 累积获取额（万元） |
| bcount | number | 买入席位 |
| totals | number | 累积卖出额（万元） |
| scount | number | 卖出席位 |
| top3 | string | 买入前三股票 |

## 示例

```json
[{"yybmc":"方正证券股份有限公司杭州中河中路证券营业部","count":2,"totalb":4658.87,"bcount":2,"totals":0,"scount":0,"top3":"宁波港,中远海发"}]
```
