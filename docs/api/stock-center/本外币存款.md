## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 本外币存款 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/wbck` |

## 功能描述

获取本外币存款，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| dy | number | 当月新增本外币存款（亿元） |
| tb | number | 当月同比增长（%） |
| hb | number | 当月环比增长（%） |
| lj | number | 累计本外币存款（亿元） |

## 示例

```json
[{"tjsj":"2026-08-01","tjyf":"2026年08月份","dy":12800.140,"tb":-39.82,"hb":687.83,"lj":3557702.700},{"tjsj":"2026-07-01","tjyf":"2026年07月份","dy":1624.740,"tb":-55.89,"hb":-91.64,"lj":3544902.560}]
```
