## 功能描述

获取工业增加值增长，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| tb | number | 同比增长（%） |
| lj | number | 累计同比增长（%） |

## 示例

```json
[{"tjsj":"2026-08-01","tjyf":"2026年08月份","tb":5.20,"lj":5.30},{"tjsj":"2026-07-01","tjyf":"2026年07月份","tb":4.50,"lj":5.30}]
```
