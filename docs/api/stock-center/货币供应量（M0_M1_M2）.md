## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 货币供应量（M0/M1/M2） |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/hbgyl` |

## 功能描述

获取货币供应量，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| m2 | number | 货币和准货币M2（亿元） |
| m2tb | number | M2同比增长（%） |
| m2hb | number | M2环比增长（%） |
| m1 | number | 货币M1（亿元） |
| m1tb | number | M1同比增长（%） |
| m1hb | number | M1环比增长（%） |
| m0 | number | 流通中的现金M0（亿元） |
| m0tb | number | M0同比增长（%） |
| m0hb | number | M0环比增长（%） |
