| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深数据中心-数据中心-财务分析-业绩预告 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/finyjyg/{年份_季度}` |

## 功能描述

个股业绩预告汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据

## 更新机制

- **更新频率**：每天20:00
- **完成耗时**：约10分钟

## 数据格式

```
[{}...]
```

## 字段说明

代码, 名称, 类型, 公告日期, 报告期, 业绩预告摘要, 上年同期每股收益(元), 业绩增幅, 报告年份，如2021, 报告季度，1:一季报，2：中报，3：三季报，4：年报, 报告年份季度含义，如“2021年一季报”
