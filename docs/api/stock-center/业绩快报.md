# 业绩快报

> 沪深数据中心 / 数据中心 / 财务分析 / 业绩快报

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 业绩快报 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/finyjkb/{年份_季度}` |

## 功能描述

个股业绩快报汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| mc | string | 名称 |
| mgsy | number | 每股收益（元） |
| yysr | number | 营业收入（万元） |
| yysrtb | number | 营业收入同比（%） |
| jlr | number | 净利润（万元） |
| jlrtb | number | 净利润同比（%） |
| mgjzc | number | 每股净资产（元） |
| jzcsyl | number | 净资产收益率（%） |
| zzc | number | 总资产（万元） |
| rdate | string | 公告日期 |
| y | number | 报告年份（如2021） |
| q | number | 报告季度（1:一季报，2：中报，3：三季报，4：年报） |
| yq | string | 报告年份季度含义（如“2021年一季报”） |
