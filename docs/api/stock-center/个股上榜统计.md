# 个股上榜统计

> 沪深数据中心 / 数据中心 / 龙虎榜 / 个股上榜统计

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深数据中心-数据中心-龙虎榜-个股上榜统计 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/gg/{近n日}` |

## 功能描述

近n日上榜个股，其中近n日中的n可以是5、10、30、60

## 更新机制

- **更新频率**：每天15:30
- **完成耗时**：约10分钟

## 数据格式

```
[{},...]
```

## 字段说明

股票代码, 股票名称, 上榜次数, 累积获取额(万), 累积卖出额(万), 净额(万), 买入席位数, 卖出席位
