# 净流入率排名

> 沪深数据中心 / 资金流向 / 个股资金流向 / 净流入率排名

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 净流入率排名 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/zjlx/jlrlpm` |

## 功能描述

个股净流入率倒序排列。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 服务器更新时间（yyyy-MM-ddHH:mm:ss） |
| mc | string | 名称 |
| dm | string | 代码 |
| zxj | number | 最新价（元） |
| zdf | number | 涨跌幅（%） |
| hsl | number | 换手率（%） |
| cje | number | 成交额（元） |
| lczj | number | 流出资金（元） |
| lrzj | number | 流入资金（元） |
| jlr | string | 净流入（元） |
| jlrl | string | 净流入率（%） |

## 示例

```json
[{"t":"2021-06-17 20:59:17","dm":"sz002594","mc":"比亚迪","zxj":232.10,"zdf":10.00,"hsl":4.49,"cje":11568705616.0000,"lczj":4402724667.9500,"lrzj":6287337003.2100,"jlr":1884612335.2600,"jlrl":16.29}]
```
