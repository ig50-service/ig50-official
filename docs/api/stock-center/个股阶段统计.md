# 个股阶段统计

> 沪深数据中心 / 资金流向 / 资金路线图 / 个股阶段统计

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 个股阶段统计 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/zjlx/{ggjdtj_阶段}` |

## 功能描述

个股阶段净流入资金统计，根据股票代码升序排列。支持“阶段”查询，阶段可选“3、5、10、20”，分别表示“近3日、近5日、近10日、近20日”，如“ggjdtj_3”，表示查询近3日个股阶段净流入资金统计。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 服务器更新时间（yyyy-MM-ddHH:mm:ss） |
| mc | string | 名称 |
| dm | string | 代码 |
| jdjsj | number | 阶段结束价（元） |
| jdzdf | number | 阶段涨跌幅（%） |
| jdhsl | number | 阶段换手率（%） |
| jdjlr | number | 阶段净流入（元） |
| jdjlrl | number | 阶段净流入率（%） |
| jdzljlr | number | 阶段主力净流入（元） |
| jdzljlrl | number | 阶段主力净流入率（%） |

## 示例

```json
[{"t":"2021-06-17 20:59:28","dm":"sh600000","mc":"浦发银行","jdjsj":10.04,"jdzdf":-1.28,"jdhsl":0.3646,"jdjlr":null,"jdjlrl":-6.34,"jdzljlr":-49319801.5700,"jdzljlrl":-4.58}]
```
