# 机构席位成交明细

> 沪深数据中心 / 数据中心 / 龙虎榜 / 机构席位成交明细

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 机构席位成交明细 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/jgcj` |

## 功能描述

近五个交易日（按交易日期倒序）上榜个股被机构交易的总额，以及个股上榜原因。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 股票代码 |
| mc | string | 股票名称 |
| t | string | 交易日期（yyyy-MM-dd） |
| buy | number | 机构席位买入额（万元） |
| sell | number | 机构席位卖出额（万元） |
| type | number | 类型 |

## 示例

```json
[{"dm":"002541","mc":"鸿路钢构","t":"2021-01-12","buy":12241.85,"sell":5333.26,"type":"连续三个交易日内，涨幅偏离值累计达20%的证券"}]
```
