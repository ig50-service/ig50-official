# 融资融券交易明细

> 沪深数据中心 / 数据中心 / 投资参考 / 融资融券交易明细

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 融资融券交易明细 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/rzrqdt` |

## 功能描述

上一个交易日（当前交易日的数据要到第二天才出）的两市各股票融资融券明细。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 日期（yyyy-MM-dd） |
| dm | string | 股票代码 |
| mc | string | 股票名称 |
| rzye | number | 融资余额（元） |
| rzmre | number | 融资买入额（元） |
| rzche | number | 融资偿还额（元） |
| rqyl | number | 融券余量（股） |
| rqmcl | number | 融券卖出量（股） |
| rqchl | number | 偿还量（股） |

## 示例

```json
[{"t":"2021-01-11","dm":"000001","mc":"平安银行","rzye":3002350474.00,"rzmre":159484890.00,"rzche":0,"rqyl":99193780,"rqmcl":387000,"rqchl":0}]
```
