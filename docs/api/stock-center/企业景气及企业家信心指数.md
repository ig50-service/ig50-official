## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 企业景气及企业家信心指数 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/qyjqzs` |

## 功能描述

获取企业景气及企业家信心指数，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计季度（如"2026年第1-2季度"） |
| jqzs | number | 企业景气指数 |
| jqtb | number | 企业景气指数同比（%） |
| jqhb | number | 企业景气指数环比（%） |
| xxzs | number | 企业家信心指数（部分季度停发为null） |
| xxtb | number | 企业家信心指数同比（%，部分季度停发为null） |
| xxhb | number | 企业家信心指数环比（%，部分季度停发为null） |
