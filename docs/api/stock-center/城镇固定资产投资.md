| 项目 | 内容 |

| 数据名称 | 城镇固定资产投资 |

## 功能描述

获取城镇固定资产投资，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| dy | number | 当月投资额（亿元） |
| tb | number | 当月同比增长（%） |
| hb | number | 当月环比增长（%） |
| lj | number | 自年初累计投资额（亿元） |

## 示例

```json
[{"tjsj":"2026-08-01","tjyf":"2026年08月份","dy":32764.000,"tb":-13.51,"hb":-3.52,"lj":293092.000},{"tjsj":"2026-07-01","tjyf":"2026年07月份","dy":33958.000,"tb":-14.19,"hb":-29.04,"lj":260328.000}]
```
