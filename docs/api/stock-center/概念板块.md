# 概念板块

> 沪深数据中心 / 资金流向 / 板块资金流向 / 概念板块

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 概念板块 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/zjlx/gnbk` |

## 功能描述

概念板块资金流向，根据流入资金倒序排列。

## 更新机制

- **更新频率**：每天15:30。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 服务器更新时间（yyyy-MM-ddHH:mm:ss） |
| mc | string | 概念板块名称 |
| dm | string | 概念板块代码 |
| jj | number | 均价（元） |
| zdf | number | 涨跌幅（%） |
| lrzj | number | 流入资金（元） |
| lczj | number | 流出资金（元） |
| jlr | number | 净流入（元） |
| jlrl | number | 净流入率（%） |
| lzgmc | string | 领涨股名称 |
| lzgdm | string | 领涨股代码 |
| lzgjlrl | number | 领涨股净流入率（%） |
