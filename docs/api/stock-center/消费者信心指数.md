## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 消费者信心指数 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/xfzxx` |

## 功能描述

获取消费者信心指数，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| xxzs | number | 消费者信心指数 |
| xxtb | number | 消费者信心指数同比增长（%） |
| xxhb | number | 消费者信心指数环比增长（%） |
| myzs | number | 消费者满意指数 |
| mytb | number | 消费者满意指数同比增长（%） |
| myhb | number | 消费者满意指数环比增长（%） |
| yqzs | number | 消费者预期指数 |
| yqtb | number | 消费者预期指数同比增长（%） |
| yqhb | number | 消费者预期指数环比增长（%） |
