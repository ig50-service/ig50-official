# 运营能力

> 沪深数据中心 / 数据中心 / 财务分析 / 运营能力

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 运营能力 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/finyynl/{年份_季度}` |

## 功能描述

个股运营能力汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| mc | string | 名称 |
| yszzzl | number | 应收账款周转率（次） |
| yszts | number | 应收账款周转天数（天） |
| chzzl | number | 存货周转率（次） |
| chzzts | number | 存货周转天数（天） |
| ldzczzl | number | 流动资产周转率（次） |
| ldzczzts | number | 流动资产周转天数（天） |
| y | number | 报告年份（如2021） |
| q | number | 报告季度（1:一季报，2：中报，3：三季报，4：年报） |
| yq | string | 报告年份季度含义（如“2021年一季报”） |
