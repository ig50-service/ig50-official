> 沪深数据中心 / 宏观数据 / 宏观经济 / 财政收入

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 财政收入 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/czsr` |

## 功能描述

获取财政收入，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| dy | number | 当月财政收入（亿元） |
| tb | number | 当月同比增长（%） |
| hb | number | 当月环比增长（%） |
| lj | number | 累计财政收入（亿元） |
| ljtb | number | 累计同比增长（%） |

## 示例

```json
[{"tjsj":"2026-08-01","tjyf":"2026年08月份","dy":12937.000,"tb":4.68,"hb":-42.88,"lj":156633.000,"ljtb":5.70},{"tjsj":"2026-07-01","tjyf":"2026年07月份","dy":22649.000,"tb":11.72,"hb":10.04,"lj":143696.000,"ljtb":5.80}]
```
