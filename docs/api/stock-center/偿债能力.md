# 偿债能力

> 沪深数据中心 / 数据中心 / 财务分析 / 偿债能力

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 偿债能力 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/finchzhainl/{年份_季度}` |

## 功能描述

个股偿债能力汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| mc | string | 名称 |
| ldbl | number | 流动比率（%） |
| sdbl | number | 速动比率（%） |
| xjbl | number | 现金比率（%） |
| lxbs | number | 利息支付倍数 |
| gdbl | number | 股东权益比率（%） |
| zcfzl | number | 资产负债率（%） |
| y | number | 报告年份（如2021） |
| q | number | 报告季度（1:一季报，2：中报，3：三季报，4：年报） |
| yq | string | 报告年份季度含义（如“2021年一季报”） |

## 示例

```json
[{"dm":"000401","mc":"冀东水泥","ldbl":1.1602,"sdbl":0.9635,"xjbl":42.8409,"lxbs":862.4235,"gdbl":54.5392,"zcfzl":45.4608,"y":2021,"q":1,"yq":"2021年一季报"}]
```
