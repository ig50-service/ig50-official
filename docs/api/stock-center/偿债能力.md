## 功能描述

个股偿债能力汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据

## 更新机制

- **完成耗时**：约10分钟
