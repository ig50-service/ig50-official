## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 交易结算资金（银证转账） |
| 所属市场 | 沪深数据中心 |

## 功能描述

获取交易结算资金（银证转账），按统计周期截至日期倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| kssj | string | 统计周期开始日期（yyyy-MM-dd） |
| jssj | string | 统计周期截至日期（yyyy-MM-dd） |
| qmye | number | 交易结算资金期末余额（亿元） |
| rjye | number | 交易结算资金日均余额（亿元） |
| zje | number | 银证转账增加额（亿元） |
| jse | number | 银证转账减少额（亿元） |
| bdje | number | 银证转账变动净额（亿元） |
| szzs | number | 上证指数收盘 |
| szzf | number | 上证指数涨跌幅（%） |
