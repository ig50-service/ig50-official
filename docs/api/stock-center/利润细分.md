# 利润细分

> 沪深数据中心 / 数据中心 / 财务分析 / 利润细分

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 利润细分 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/finlrxf` |

## 功能描述

个股利润细分汇总。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| mc | string | 名称 |
| sshy | string | 所属行业 |
| sshysr | number | 所属行业收入（万元） |
| ckcb | number | 所属行业参考成本（万元） |
| cklr | number | 参考利润（万元） |
| lrms | string | 利润描述 |
| rdate | string | 报告日期 |

## 示例

```json
[{"dm":"601857","mc":"中国石油","sshy":"商贸业","sshysr":73754000.00,"ckcb":72212000.00,"cklr":1542000.00,"lrms":"销售","rdate":"2020-06-30"}]
```
