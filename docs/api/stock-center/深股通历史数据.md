# 深股通历史数据

> 沪深数据中心 / 资金流向 / 南向、北向资金 / 深股通历史数据

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 深股通历史数据 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/nxbx/sgtlssj` |

## 功能描述

深股通（港→深）历史数据，按日期倒序。

## 更新机制

- **更新频率**：每天20:00。
- **完成耗时**：约10分钟。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 日期 |
| jme | number | 当日成交净买额（百万）：当日成交净买额=买入成交额-卖出成交额。 |
| mr | number | 买入成交额（百万） |
| mc | number | 卖出成交额（百万） |
| lj | number | 历史累计净买额（百万） |
| drlr | number | 当日资金流入（百万）：当日资金流入额=当日限额-当日余额。当日资金流入额包含两部分：当日成交净买额，当日申报但未成交的买单金额。 |
| drye | number | 当日余额（百万） |
| lzgdm | string | 领涨股代码 |
| lzgmc | string | 领涨股名称 |
| lzgzdf | number | 领涨股涨跌幅（%） |
| zs | number | 深证指数点位 |
| zszdf | number | 指数涨跌幅（%） |

## 示例

```json
[{"lzgzdf":11.75,"jme":-2448.00,"t":"2022-05-05","mr":29431.00,"drye":53002.00,"lzgmc":"图南股份","mc":31879.00,"lzgdm":"300855.SZ","zs":11046.38,"drlr":-1002.00,"lj":786793.88,"zszdf":0.23}]
```
