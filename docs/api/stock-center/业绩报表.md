## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深数据中心-数据中心-财务分析-业绩报表 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/finyjbb/{年份_季度}` |

## 功能描述

个股业绩报表汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据

## 更新机制

- **更新频率**：每天20:00
- **完成耗时**：约10分钟

## 数据格式

```
[{}...]
```

## 字段说明

代码, 名称, 每股收益(元), 每股收益同比(%), 每股净资产(元), 净资产收益率(%), 每股现金流量(元), 净利润(万元), 净利润同比(%), 分配方案, 发布日期, 报告年份，如2021, 报告季度，1:一季报，2：中报，3：三季报，4：年报, 报告年份季度含义，如“2021年一季报”
