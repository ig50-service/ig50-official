| 项目 | 内容 |

## 功能描述

获取国内成品油价格，按调整时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 调整日期（yyyy-MM-dd） |
| qyjg | number | 汽油价格（元/吨） |
| qyfd | number | 汽油涨跌（元/吨，序列首条为null） |
| cyjg | number | 柴油价格（元/吨） |
| cyfd | number | 柴油涨跌（元/吨，序列首条为null） |

## 示例

```json
[{"tjsj":"2026-09-12","qyjg":9565.000,"qyfd":260.000,"cyjg":8505.000,"cyfd":250.000},{"tjsj":"2026-08-29","qyjg":9305.000,"qyfd":375.000,"cyjg":8255.000,"cyfd":360.000}]
```
