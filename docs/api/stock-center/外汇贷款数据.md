> 沪深数据中心 / 宏观数据 / 金融货币 / 外汇贷款数据

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 外汇贷款数据 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/time/hongguan/whxd` |

## 功能描述

获取外汇贷款数据，按统计时间倒序。

## 更新机制

- **更新频率**：每天21:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（如"2026年08月份"） |
| dy | number | 当月新增外汇贷款（亿美元） |
| tb | number | 当月同比增长（%） |
| hb | number | 当月环比增长（%） |
| lj | number | 累计外汇贷款（亿美元） |

## 示例

```json
[{"tjsj":"2026-08-01","tjyf":"2026年08月份","dy":33.000,"tb":180.49,"hb":512.50,"lj":5602.000},{"tjsj":"2026-07-01","tjyf":"2026年07月份","dy":-8.000,"tb":84.31,"hb":-117.78,"lj":5569.000}]
```
