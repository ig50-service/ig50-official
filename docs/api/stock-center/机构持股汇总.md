# 机构持股汇总

> 沪深数据中心 / 数据中心 / 机构持股 / 机构持股汇总

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 机构持股汇总 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/orgcghz/{年份_季度}` |

## 功能描述

机构持股汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据。

## 更新机制

- **更新频率**：每周六上午9点。
- **完成耗时**：约5小时。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 股票代码 |
| mc | string | 股票名称 |
| oc | number | 机构数 |
| occ | number | 机构变化数 |
| gbl | number | 持股比例（%） |
| gblz | number | 持股比例增幅（%） |
| lbl | number | 占流通股比例（%） |
| ltz | number | 占流通股比例增幅（%） |
| dt | array<object> | 机构明细（object对象属性详见下方） |
| y | number | 报告年份（如2021） |
| q | number | 报告季度（1:一季报，2：中报，3：三季报，4：年报） |
| yq | string | 报告年份季度含义（如“2021年一季报”） |
| c | string | 机构代码 |
| n | string | 机构全名 |
| gs | string | 当前持股数（万股） |
| sgs | string | 上季度持股数（万股） |
| bl | string | 当前占流通股比例（%） |
| blz | string | 当前占流通股比例增幅（%） |
| sbl | string | 上季度占流通股比例（%） |
| sblz | string | 当前持股比例（%） |
| gz | string | 当前持股比例增幅（%） |
| sgb | string | 上季度持股比例（%） |
