## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深数据中心-数据中心-机构持股-机构持股汇总 |
| 所属市场 | 沪深数据中心 |
| 本地路径 | `数据存放目录/all/orgcghz/{年份_季度}` |

## 功能描述

机构持股汇总，支持“年份_季度”查询，年份可选（1989~当前年份），季度可选（1:一季报，2：中报，3：三季报，4：年报），如“2021_1”，表示查询2021年一季度数据

## 更新机制

- **更新频率**：每周六上午9点
- **完成耗时**：约5小时

## 数据格式

```
[{}...]
```

## 字段说明

股票代码, 股票名称, 机构数, 机构变化数, 持股比例(%), 持股比例增幅(%), 占流通股比例(%), 占流通股比例增幅(%), 机构明细，OrgDetail对象属性详见下方, 报告年份，如2021, 报告季度，1:一季报，2：中报，3：三季报，4：年报, 报告年份季度含义，如“2021年一季报”, 机构代码, 机构全名, 当前持股数（万股）, 上季度持股数（万股）, 当前占流通股比例（%）, 当前占流通股比例增幅（%）, 上季度占流通股比例（%）, 当前持股比例（%）, 当前持股比例增幅（%）, 上季度持股比例（%）
