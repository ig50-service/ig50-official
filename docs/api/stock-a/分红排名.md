# 分红排名

> 沪深京A股 / 股票基础信息 / 分红融资 / 分红排名

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 分红排名 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/dividendrank/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取当前股票在所属行业中的股息率排名（含同行业对比股票、行业排名、行业总数）。按排名升序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| mode | number | 排名模式（4=股息率/2=股利支付率） |
| pm | number | 排名（1-5） |
| code | string | 同行股票代码 |
| name | string | 同行股票简称 |
| rate | number | 股息率/股利支付率（%） |
| hydm | string | 行业代码 |
| hymc | string | 行业名称 |
| hygs | number | 行业内股票数 |
| sfzs | number | 是否自身（1=自身，0=同行） |
| txdm | string | 同行股票代码（含市场后缀） |
| gxrq | string | 数据更新日期（yyyy-MM-dd） |

## 示例

```json
[{"mode":4,"pm":35,"code":"002475","name":"立讯精密","rate":0.53,"hydm":"1037","hymc":"消费电子","hygs":99,"sfzs":1,"txdm":"002475.SZ","gxrq":"2026-08-28"},{"mode":4,"pm":1,"code":"920005","name":"鼎佳精密","rate":4.33,"hydm":"1037","hymc":"消费电子","hygs":99,"sfzs":0,"txdm":"920005.BJ","gxrq":"2026-08-28"}]
```
