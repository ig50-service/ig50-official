# 财务指标

> 沪深京A股 / 股票基础信息 / 财务与预测 / 财务指标

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 财务指标 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/fi/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司近四个季度的主要财务指标。按报告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```
