# 客户及供应商

> 沪深京A股 / 股票基础信息 / 概况与经营 / 客户及供应商

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 客户及供应商 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/custsupp/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的前五大客户和前五大供应商。按报告期倒序、类型升序、排名升序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqmc | string | 报告期名称 |
| bgnd | string | 报告年度（yyyy） |
| lx | string | 类型（"客户"/"供应商"） |
| lxdm | string | 类型代码（"1"=客户，"2"=供应商） |
| xmmc | string | 项目名称（如"客户1"/"供应商3"/"其余客户"/"其余供应商"） |
| pm | number | 排名（1-5为前五大，6为其余） |
| je | number | 项目金额（元） |
| zb | number | 占总额比例（%） |
| hje | number | 当年同类总额（元） |
