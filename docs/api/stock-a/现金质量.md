# 现金质量

> 沪深京A股 / 股票基础信息 / 财务与预测 / 现金质量

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 现金质量 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/mainindexquality/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的现金质量指标（预收/营业收入、销售净现金流/营业收入、经营净现金流/营业收入、实际税率）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqlx | string | 报告类型（如"中报"/"年报"/"一季报"/"三季报"等） |
| bqmc | string | 报告期名称 |
| yszyysr | number | 预收账款/营业收入 |
| xsjxyysr | number | 销售净现金流/营业收入 |
| jyxjyysr | number | 经营净现金流/营业收入 |
| sjshl | number | 实际税率（%） |

## 示例

```json
[{"bgrq":"2026-06-30","bqlx":"中报","bqmc":"2026中报","yszyysr":0,"xsjxyysr":0.1,"jyxjyysr":-0.01,"sjshl":9.9},{"bgrq":"2026-03-31","bqlx":"一季报","bqmc":"2026一季报","yszyysr":0,"xsjxyysr":0.03,"jyxjyysr":-0.08,"sjshl":7.53}]
```
