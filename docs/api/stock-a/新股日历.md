# 新股日历

> 沪深京A股 / 股票基础信息 / 股票板块概念 / 新股日历

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 新股日历 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/all/xgrl` |

## 功能描述

新股日历，按申购日期倒序。

## 更新机制

- **更新频率**：每天16点更新。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```
