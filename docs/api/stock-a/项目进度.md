| 项目 | 内容 |

| 数据名称 | 项目进度 |

| 本地路径 | `数据存放目录/time/f10/zbyzxmjd/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的项目进度。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| xmmc | string | 项目名称 |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| jhtz | number | 计划投资（元） |
| ytrje | number | 已投入募集资金（元） |
| jsqj | number | 建设期（年） |
| syl | number | 收益率（税后，%） |
| hsq | number | 投资回收期（年） |
