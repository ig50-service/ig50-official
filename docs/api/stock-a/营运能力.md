# 营运能力

> 沪深京A股 / 股票基础信息 / 财务与预测 / 营运能力

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 营运能力 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/mainindexop/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的营运能力指标（总资产/存货/应收账款周转天数及周转率）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqlx | string | 报告类型（如"中报"/"年报"/"一季报"/"三季报"等） |
| bqmc | string | 报告期名称 |
| zczzts | number | 总资产周转天数（天） |
| chzzts | number | 存货周转天数（天） |
| yszkzzts | number | 应收账款周转天数（天） |
| zzzzl | number | 总资产周转率（次） |
| chzzl | number | 存货周转率（次） |
| yszkzzl | number | 应收账款周转率（次） |
