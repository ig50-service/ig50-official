# 业务竞争力

> 沪深京A股 / 股票基础信息 / 概况与经营 / 业务竞争力

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 业务竞争力 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/businesscomp/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的业务竞争力。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| nd | string | 报告年度（yyyy） |
| bqmc | string | 报告期名称 |
| zycp | string | 主营产品 |
| cpdm | string | 产品代码 |
| cpxje | number | 产品金额（元） |
| hzje | number | 汇总金额（元） |
| mll | number | 毛利率（%） |
| zzl | number | 增长率（%） |
| sczbl | number | 产品占比（%） |
| jglx | string | 类型（如"营业收入"/"营业利润"） |
| jglxdm | string | 类型代码（"1"=营业收入，"2"=营业利润） |
| sfgx | string | 是否更新（"1"=已更新，"0"=未更新） |
