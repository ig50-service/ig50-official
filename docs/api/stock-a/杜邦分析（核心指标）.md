# 杜邦分析（核心指标）

> 沪深京A股 / 股票基础信息 / 财务与预测 / 杜邦分析（核心指标）

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 杜邦分析（核心指标） |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/dupontcore/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取杜邦分析的核心分解指标（ROE、销售净利率、总资产周转率、权益乘数、总资产净利率、归属净利润率、资产负债率）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqmc | string | 报告期名称 |
| bqlx | string | 报告类型 |
| roe | number | 净资产收益率（%） |
| xsjlr | number | 销售净利率（%） |
| zzzzl | number | 总资产周转率（次） |
| zzclr | number | 总资产净利率（%） |
| gmjlrbl | number | 归属净利润率（%） |
| qycs | number | 权益乘数（倍） |
| zcfzl | number | 资产负债率（%） |
