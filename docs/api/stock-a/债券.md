# 债券

> 沪深京A股 / 股票基础信息 / 分红融资 / 债券

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 债券 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/zqmx/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司发行的各类债券明细（债券代码/简称/类型、公告/起息/到期日期、面值/发行价格/利率/期限/规模、可转债转股相关参数、用途说明）。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| zqdm | string | 债券代码 |
| zqjc | string | 债券简称 |
| zqlx | string | 债券类型（如"证券公司债"/"可转换公司债"等） |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| qxrq | string | 起息日（债券计息开始日期）（yyyy-MM-dd） |
| dqrq | string | 到期日（债券到期偿付日期）（yyyy-MM-dd） |
| mzjz | number | 面值（元） |
| fxjg | number | 发行价格（元） |
| fxll | number | 票面利率（%） |
| zqqx | string | 债券期限（年） |
| fxgm | number | 发行规模（亿元） |
| syqx | string | 剩余期限状态（如"已到期"/"存续中"等） |
| zgsr | string | 转股开始日（可转债允许转股起始日期，非可转债为空）（yyyy-MM-dd） |
| zgjs | string | 转股结束日（可转债允许转股截止日期，非可转债为空）（yyyy-MM-dd） |
| cszgjg | number | 初始转股价格（元，可转债特有） |
| cszgbl | string | 初始转股比例 |
| ytsm | string | 用途说明 |
