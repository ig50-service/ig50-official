# 资金走势对照

> 沪深京A股 / 股票基础信息 / 资金与公告 / 资金走势对照

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 资金走势对照 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/zijin/zlzjzs/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取每分钟资金走势对照。按时间倒序。

## 更新机制

- **更新频率**：每天20:00更新。
- **完成耗时**：约8小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 时间（yyyy-MM-ddHH:mm:ss） |
| zdf | number | 涨跌幅（%） |
| lrzj | number | 总流入资金（元） |
| lczj | number | 总流出资金（元） |
| jlr | number | 净流入（元） |
| jlrl | number | 净流入率（%） |
| lrl | number | 主力流入率（%） |
| shlrl | number | 散户流入率（%） |

