# 炸板股池

> 沪深京A股 / 股票基础信息 / 股票板块概念 / 炸板股池

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 炸板股池 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/zdtgc/zbgc/{日期}` |

## 功能描述

根据日期（格式yyyy-MM-dd，最近15个交易日）作为参数，得到每天的炸板股票列表，根据首次封板时间升序。

## 更新机制

- **更新频率**：交易时间段每10分钟更新。
- **完成耗时**：约1分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| mc | string | 名称 |
| p | number | 价格（元） |
| ztp | number | 涨停价（元） |
| zf | number | 涨跌幅（%） |
| cje | number | 成交额（元） |
| lt | number | 流通市值（元） |
| zsz | number | 总市值（元） |
| zs | number | 涨速（%） |
| hs | number | 转手率（%） |
| tj | string | 涨停统计（x天/y板） |
| fbt | string | 首次封板时间（HH:mm:ss） |
| zbc | number | 炸板次数 |

## 示例

```json
[{"dm":"sz002165","mc":"红 宝 丽","p":9.45,"ztp":10.05,"zf":3.39,"cje":2417475344.00,"lt":5614147844.55,"zsz":6948299988.00,"hs":40.83,"zs":-0.21,"tj":"11/6","fbt":"09:25:00","zbc":24}]
```
