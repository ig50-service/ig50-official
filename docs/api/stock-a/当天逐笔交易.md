## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深京A股-股票交易数据-股票行情-当天逐笔交易 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/trace/onebyone/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取当天逐笔交易数据，按时间升序

## 更新机制

- **更新频率**：交易时间段每2分钟
- **完成耗时**：约10秒

## 数据格式

```
[{},..]
```

## 字段说明

数据更新时间（yyyy-MM-dd HH:mm:ss）, 成交时间（HH:mm:dd）, 成交量（股）, 成交价, 交易方向（0：中性盘，1：买入，2：卖出）
