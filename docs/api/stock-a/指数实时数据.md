| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深京A股-指数相关-指数行情-指数实时数据 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/{指数代码（包含sh/sz前缀，如：sh000001）}` |

## 功能描述

根据《指数列表》得到的指数代码（包含sh/sz前缀，如：sh000001）获取实时交易数据，您可以理解为日线的最新数据

## 更新机制

- **更新频率**：交易时间段每1分钟
- **完成耗时**：约10秒

## 数据格式

```
{}
```

## 字段说明

五分钟涨跌幅（%）, 最高价, 换手（%）, 量比（%）, 最低价, 流通市值（元）, 开盘价, 市盈率, 涨跌幅（%）, 当前价格, 总市值（元）, 成交额（元）, 涨跌额, 成交量（股）, 昨日收盘价, 振幅（%）, 涨速（%）, 市净率, 60日涨跌幅（%）, 年初至今涨跌幅（%）, 更新时间yyyy-MM-dd HH:mm:ss
