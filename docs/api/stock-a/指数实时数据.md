# 指数实时数据

> 沪深京A股 / 指数相关 / 指数行情 / 指数实时数据

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 指数实时数据 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/{指数代码（包含sh/sz前缀，如：sh000001）}` |

## 功能描述

根据《指数列表》得到的指数代码（包含sh/sz前缀，如：sh000001）获取实时交易数据，您可以理解为日线的最新数据。

## 更新机制

- **更新频率**：交易时间段每1分钟。
- **完成耗时**：约10秒。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| fm | number | 五分钟涨跌幅（%） |
| h | number | 最高价 |
| hs | number | 换手（%） |
| lb | number | 量比（%） |
| l | number | 最低价 |
| lt | number | 流通市值（元） |
| o | number | 开盘价 |
| pe | number | 市盈率 |
| pc | number | 涨跌幅（%） |
| p | number | 当前价格 |
| sz | number | 总市值（元） |
| cje | number | 成交额（元） |
| ud | number | 涨跌额 |
| v | number | 成交量（股） |
| yc | number | 昨日收盘价 |
| zf | number | 振幅（%） |
| zs | number | 涨速（%） |
| sjl | number | 市净率 |
| zdf60 | number | 60日涨跌幅（%） |
| zdfnc | number | 年初至今涨跌幅（%） |
| t | string | 更新时间（yyyy-MM-ddHH:mm:ss） |
