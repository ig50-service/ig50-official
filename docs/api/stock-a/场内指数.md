> 沪深京A股 / 指数 / 指数相关 / 场内指数

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 场内指数 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/base/hsjzs` |

## 功能描述

获取沪深京三所挂牌的全部指数代码和名称，用于以下接口的参数传入。

## 更新机制

- **更新频率**：每天23:00。
- **完成耗时**：约30秒。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 指数代码（如：sh000001） |
| mc | string | 指数名称（如：上证指数） |
| jys | string | 市场（"sh"表示上证，"sz"表示深证，"bj"表示北证） |

## 示例

```json
[{"dm":"sh000993","mc":"全指信息","jys":"sh"},{"dm":"sh000992","mc":"全指金融","jys":"sh"}]
```
