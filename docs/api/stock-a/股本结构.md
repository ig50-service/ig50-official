# 股本结构

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 股本结构

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 股本结构 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/gbjg/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司历年股份变动及各股本口径的构成与占比。按截止日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jzrq | string | 截止日期（yyyy-MM-dd） |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| bdyy | string | 变动原因 |
| zgb | number | 总股本（股） |
| sxgf | number | 流通受限股份（股） |
| ltgf | number | 已流通股份（股） |
| ltag | number | 已上市流通A股（股） |
| ltbg | number | 已上市流通B股（股） |
| lthg | number | 境外上市流通股/H股（股） |
| qtls | number | 其它已流通股份（股） |
| wltgf | number | 未流通股份（股） |
| sxbl | number | 流通受限占比（%） |
| ltbl | number | 已流通占比（%） |
| agbl | number | A股流通占比（%） |
| bgbl | number | B股流通占比（%） |
| hgbl | number | H股流通占比（%） |
| qtbl | number | 其他流通占比（%） |
