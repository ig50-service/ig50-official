# 经营评述

> 沪深京A股 / 股票基础信息 / 概况与经营 / 经营评述

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 经营评述 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/bizreview/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的经营评述。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqmc | string | 报告期名称 |
| jyps | string | 经营评述正文（年报含主营业务分析/核心竞争力/未来展望片段，季报仅简要概述） |
| wlzw | string | 未来展望正文（仅年报有内容，中报/季报为空） |

## 示例

```json
{"bgrq":"2026-06-30","bqmc":"2026中报","jyps":"公司从事的主要业务在报告期内无重大变化。(一)公司整体经营情况2026年上半年,公司在行业技术迭代加速以及市场复杂变化的外部环境下,始终坚持长期主义,持续深化消费电子、通信与数据中心、汽车电子三大核心业务布局,充分发挥全球化产能配置、垂直一体化整合以及精密智造平台优势,实现经营规...","wlzw":""}
```
