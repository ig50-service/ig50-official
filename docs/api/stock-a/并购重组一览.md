# 并购重组一览

> 沪深京A股 / 股票基础信息 / 分红融资 / 并购重组一览

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 并购重组一览 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/bgcz/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取股票的并购重组一览。

## 更新机制

- **更新频率**：每天20:30更新。
- **完成耗时**：约30分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jybd | string | 交易标的 |
| bf | string | 买方 |
| sf | string | 卖方 |
| jyje | number | 交易金额（万） |
| bz | string | 币种 |
| gqzrbl | number | 股权转让比例（%） |
| bdlx | string | 标的类型 |
| bgfs | string | 并购方式 |
| zxjz | string | 最新进展 |
| plrq | string | 披露日期（yyyy-MM-dd） |
| zxggr | string | 最新公告日（yyyy-MM-dd） |
