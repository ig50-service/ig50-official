## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 中证系列指数 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/base/zzzs` |

## 功能描述

获取中证系列指数代码和名称，用于后续接口的参数传入。

## 更新机制

- **更新频率**：每天15:35点。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 指数代码（如：zz930601） |
| mc | string | 股票名称（如：中证软件） |
| jys | string | 交易所，固定：zz，表示中证指数（同时含有沪深两市成分股的指数） |
