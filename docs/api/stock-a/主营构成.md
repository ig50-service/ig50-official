# 主营构成

> 沪深京A股 / 股票基础信息 / 概况与经营 / 主营构成

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 主营构成 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/maincompose/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的主营构成，按行业、产品、地区三个维度分别披露营业收入、营业成本、毛利率及对应金额和贡献比例。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqmc | string | 报告期名称 |
| lx | string | 类型（"1"=按行业分类，"2"=按产品分类，"3"=按地区分类） |
| mc | string | 名称 |
| dm | string | 代码 |
| pm | number | 排名 |
| zysr | number | 主营业务收入（元） |
| zycb | number | 主营业务成本（元） |
| zylr | number | 主营业务利润（元） |
| srbz | number | 收入比例（%） |
| lrbz | number | 利润比例 |
| cbbz | number | 成本比例 |
| mllv | number | 毛利率 |
