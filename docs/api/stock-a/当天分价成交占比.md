## 功能描述

根据《股票列表》得到的股票代码获取当天每个价格成交的数量占总成交数量的百分比

## 更新机制

- **更新频率**：每天20:00
- **完成耗时**：约8小时

## 数据格式

```
[{},..]
```

## 字段说明

数据归属日期（yyyy-MM-dd）, 成交量（股）, 成交价, 占比（%）
