# 沪深两市上涨下跌数概览

> 沪深京A股 / 指数相关 / 指数行情 / 沪深两市上涨下跌数概览

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深两市上涨下跌数概览 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/shszzdbl` |

## 功能描述

获取沪深两市的股票上涨、下跌总数以及各比例区间的上涨下跌数。

## 更新机制

- **更新频率**：交易时间段每1分钟。
- **完成耗时**：约10秒。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| totalUp | number | 上涨总数 |
| totalDown | number | 下跌总数 |
| zt | number | 涨停总数 |
| dt | number | 跌停总数 |
| up8ToZt | number | 上涨8%~涨停的数量 |
| up6To8 | number | 上涨6%~8%的数量 |
| up4To6 | number | 上涨4%~6%的数量 |
| up2To4 | number | 上涨2%~4%的数量 |
| up0To2 | number | 上涨0%~2%的数量 |
| down0To2 | number | 下跌0%~-2%的数量 |
| down2To4 | number | 下跌-2%~-4%的数量 |
| down4To6 | number | 下跌-4%~-6%的数量 |
| down6To8 | number | 下跌-6%~-8%的数量 |
| down8ToDt | number | 下跌-8%~跌停的数量 |
