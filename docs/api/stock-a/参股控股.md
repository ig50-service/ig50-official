## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 参股控股 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/cgkg/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的参股控股企业清单。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| cgqy | string | 参股控股企业 |
| ckgx | string | 参控股关系（如"全资子公司"/"间接全资子公司"/"联营企业"/"合营企业"等） |
| zczb | string | 注册资本（带单位文本） |
| jtcgbl | string | 集团持股比例 |
| sjtze | string | 实际投资金额（可空：间接持股未单独披露） |
| jly | string | 净利润（可空：未单独披露或亏损未披露） |
| zyzy | string | 主营业务 |
| bgq | string | 报告期（yyyy-MM-dd） |
