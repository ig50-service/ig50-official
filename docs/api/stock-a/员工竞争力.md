> 沪深京A股 / 股票基础信息 / 概况与经营 / 员工竞争力

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 员工竞争力 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/employee/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的员工竞争力。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

[{}]
