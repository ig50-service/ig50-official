# 十大流通股东（详）

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 十大流通股东（详）

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 十大流通股东（详） |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/sdhltgd/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的十大流通股东详情记录（含股东性质、持股市值、变动比例等完整字段）。按报告期倒序+名次升序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| pm | number | 名次 |
| gdmc | string | 股东名称 |
| gdxz | string | 股东性质（"1"=机构，其他=非机构） |
| cgs | number | 持股数（股） |
| zltgb | number | 总流通股本（股） |
| cgsz | number | 持股市值（元） |
| cgbl | number | 占总流通股本持股比例（%） |
| bdbl | number | 变动比例（%） |
| zj | string | 增减（如"不变"/"新进"/"减持"等） |
