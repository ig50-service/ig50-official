# 增发明细

> 沪深京A股 / 股票基础信息 / 分红融资 / 增发明细

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 增发明细 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/dividendseo/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司所有增发明细（发行时间/价格/数量/募足金额/净额/方式/上市登记日期/用途说明）。按增发时间倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| zfsj | string | 增发时间（yyyy-MM-dd） |
| zfsl | number | 实际增发数量 |
| mzzj | number | 实际募资总额 |
| mzje | number | 实际募资净额（扣除发行费后净额） |
| zfjg | number | 增发价格（元/股） |
| fxfsmc | string | 发行方式（如"非公开发行"等） |
| djrq | string | 股权登记日（yyyy-MM-dd） |
| ssrq | string | 增发上市日（yyyy-MM-dd） |
| dzrq | string | 资金到账日（无值为空串）（yyyy-MM-dd） |
| ytsm | string | 用途说明（无值为空串） |
