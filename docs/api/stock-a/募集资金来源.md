# 募集资金来源

> 沪深京A股 / 股票基础信息 / 分红融资 / 募集资金来源

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 募集资金来源 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/zbyzcjsjly/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司募集资金来源明细（公告日期、发行类别、项目金额、发行起始日期）。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| fxlb | string | 发行类别（如"增发新股"/"配股"/"IPO首发"等） |
| xmje | number | 实际募集资金净额（元） |
| fzqs | string | 发行起始日（yyyy-MM-dd） |

## 示例

```json
[{"ggrq":"2016-10-21","fxlb":"增发新股","xmje":4589446035.54,"fzqs":"2016-09-30"},{"ggrq":"2014-10-15","fxlb":"增发新股","xmje":2009775974.99,"fzqs":"2014-09-24"}]
```
