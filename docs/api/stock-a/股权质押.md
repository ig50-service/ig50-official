# 股权质押

> 沪深京A股 / 股票基础信息 / 大事与市场 / 股权质押

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 股权质押 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/gqzy/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的股权质押。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggq | string | 公告日期（yyyy-MM-dd） |
| gdmc | string | 股东名称 |
| zyf | string | 质押方 |
| sfzshg | string | 是否质押式回购（"是"/"否"） |
| zygs | number | 质押股数（股） |
| zzgbbl | number | 占总股本比例（%） |
| zgdcgbl | number | 占股东持股比例（%） |
| zyqsr | string | 质押起始日（yyyy-MM-dd） |
| zyjzrq | string | 质押截止日（计划解冻日，所有记录均有值）（yyyy-MM-dd） |
| jyrq | string | 解押日期（实际解押日，已解押时有值）（yyyy-MM-dd） |
| zyzt | string | 质押状态（"已解押"/"未解押"） |
