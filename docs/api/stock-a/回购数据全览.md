# 回购数据全览

> 沪深京A股 / 股票基础信息 / 分红融资 / 回购数据全览

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 回购数据全览 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/hgzl/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取股票的回购数据全览。

## 更新机制

- **更新频率**：每天20:30更新。
- **完成耗时**：约30分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| pp | number | 公告前一日收盘价（元） |
| lp | number | 计划回购价格下限（元） |
| hp | number | 计划回购价格上限（元） |
| lv | number | 计划回购数量下限（股） |
| hv | number | 计划回购数量上限（股） |
| lm | number | 计划回购金额下限（元） |
| hm | number | 计划回购金额上限（元） |
| ggd | string | 回购公告日（yyyy-MM-dd） |
| gft | string | 回购股份类型 |
| ltbl | string | 占公告前一日流通市值比例（%） |
| zbl | string | 占公告前一日总股本比例（%） |
| jyd | string | 股东大会决议公告日期（yyyy-MM-dd） |
| tar | string | 回购目的 |
| tips | string | 特别提示 |
| jd | string | 实施进度（001:董事会预案，002:股东大会通过，003:股东大会否决，004:实施中，005:停止实施，006:完成实施） |
| stad | string | 状态更新日期（yyyy-MM-dd） |
| sd | string | 回购起始日期（yyyy-MM-dd） |
| ed | string | 回购截止日期（yyyy-MM-dd） |
| ypm | number | 已回购股份价格下限（元） |
| yhm | number | 已回购股份价格上限（元） |
| ytg | number | 已回购股份数量（股） |
| ytm | number | 已回购金额（元） |
| ispe | string | 回购是否提前完成 |
| ped | string | 提前完成日期（yyyy-MM-dd） |
| ggp20 | number | 公告前20日涨跌幅（%） |
| ggh20 | number | 公告后20日涨跌幅（%） |
| hgp20 | number | 回购完成前20日涨跌幅（%） |
| hgh20 | number | 回购完成后20日涨跌幅（%） |
