## 功能描述

根据《股票列表》得到的股票代码获取L2行情指标数据

## 更新机制

- **更新频率**：交易时间段每10秒
- **完成耗时**：约3秒

## 数据格式

```
{}
```

## 字段说明

今日主力净流入（元，正值=净流入，负值=净流出）, 主力净比（%，主力净流入/成交额*100）, 散户净比（%，散户净流入/成交额*100）, 5分钟主力净额（元，最近5分钟主力净流入）, 近三日主力净额（元）, 近五日主力净额（元）, 近十日主力净额（元）, 今日主买净额（元，主力主动买入净额）, DDX（大单动向指标）, DDY（大单动量指标）, DDZ（大单强度指标）, DDF（大单频率指标）, 更新时间yyyy-MM-dd HH:mm:ss, 数据时间yyyy-MM-dd HH:mm:ss
