# L2行情指标（3秒落盘）

> 沪深京A股 / 股票交易数据 / 股票行情 / L2行情指标（3秒落盘）

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | L2行情指标（3秒落盘） |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/trace/l2sign/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取L2行情指标数据。

## 更新机制

- **更新频率**：交易时间段每10秒。
- **完成耗时**：约3秒。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| mna | number | 今日主力净流入（元，正值=净流入，负值=净流出） |
| mnr | number | 主力净比（%，主力净流入/成交额*100） |
| rna | number | 散户净比（%，散户净流入/成交额*100） |
| m5a | number | 5分钟主力净额（元，最近5分钟主力净流入） |
| m3da | number | 近三日主力净额（元） |
| m5da | number | 近五日主力净额（元） |
| m10da | number | 近十日主力净额（元） |
| mbna | number | 今日主买净额（元，主力主动买入净额） |
| ddx | number | DDX（大单动向指标） |
| ddy | number | DDY（大单动量指标） |
| ddz | number | DDZ（大单强度指标） |
| ddf | number | DDF（大单频率指标） |
| t | string | 更新时间（yyyy-MM-ddHH:mm:ss） |
| sud | string | 数据时间（yyyy-MM-ddHH:mm:ss） |

## 示例

```json
{"mna":-6914693.500,"mnr":-18.00,"rna":39.48,"m5ma":-233691.594,"m3da":-21356364.000,"m5da":-31506400.000,"m10da":-26153152.000,"mbna":-13865702.000,"ddx":-0.11,"ddy":-18.15,"ddz":-0.52,"ddf":0.55,"t":"2026-06-25 10:43:28","sud":"2026-06-25 10:43:27"}
```
