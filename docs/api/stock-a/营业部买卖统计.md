# 营业部买卖统计

> 沪深京A股 / 股票基础信息 / 大事与市场 / 营业部买卖统计

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 营业部买卖统计 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/lhbyyb/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的营业部买卖统计。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jyrq | string | 上榜交易日（yyyy-MM-dd） |
| smyy | string | 上榜原因（中文说明）（如"日涨幅偏离值达到7%的前5只证券"） |
| zdf | number | 当日涨跌幅 |
| sp | number | 当日收盘价 |
| h1zdf | number | 后1日涨跌幅 |
| h2zdf | number | 后2日涨跌幅 |
| h3zdf | number | 后3日涨跌幅（可负） |
| h5zdf | number | 后5日涨跌幅（可负） |
| h10zdf | number | 后10日涨跌幅（可负） |
| h20zdf | number | 后20日涨跌幅（可负） |
| h30zdf | number | 后30日涨跌幅（可负） |
| mrhj | number | 营业部买入合计（当日龙虎榜前5家买入总额） |
| mchj | number | 营业部卖出合计（当日龙虎榜前5家卖出总额） |
| jme | number | 营业部买卖净额（=mrhj-mchj，可负） |
