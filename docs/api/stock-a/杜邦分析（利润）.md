| 项目 | 内容 |
|------|------|

## 功能描述

根据《股票列表》得到的股票代码获取杜邦分析下的利润表明细科目（金额列，平铺列存储）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。
