# 估值比较

> 沪深京A股 / 股票基础信息 / 大事与市场 / 估值比较

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 估值比较 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/gz/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的估值比较。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dgsjmc | string | 对比对象简称（如"行业平均"/"行业中值"等） |
| pm | number | 排名 |
| zs | number | 行业总股票数 |
| bgq | string | 报告期 |
| peg | number | PEG（市盈率/盈利增长率） |
| pe | number | 市盈率-25A |
| pe_ttm | number | 市盈率-TTM |
| pe_26e | number | 市盈率-26E |
| pe_27e | number | 市盈率-27E |
| pe_28e | number | 市盈率-28E |
| ps | number | 市销率-25A |
| ps_ttm | number | 市销率-TTM |
| ps_26e | number | 市销率-26E |
| ps_27e | number | 市销率-27E |
| ps_28e | number | 市销率-28E |
| pb | number | 市净率-25A |
| pb_mrq | number | 市净率-MRQ |
| pce | number | 市现率1-25A |
| pce_ttm | number | 市现率1-TTM |
| pcf | number | 市现率2-25A |
| pcf_ttm | number | 市现率2-TTM |
