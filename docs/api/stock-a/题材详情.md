# 题材详情

> 沪深京A股 / 股票基础信息 / 概况与经营 / 题材详情

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 题材详情 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/tcxq/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的题材详情。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jyfw | string | 经营范围 |
| zyyw | string | 主营业务 |
| qtbd | string | 其他变动 |
| hybj | array | 行业背景（每条含：bt（标题）、bw（正文）） |
| hxjzl | array | 核心竞争力（每条含：bt（标题）、bw（正文）） |
| ssbk | array | 所属板块（字符串数组） |
