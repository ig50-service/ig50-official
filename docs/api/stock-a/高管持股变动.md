# 高管持股变动

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 高管持股变动

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 高管持股变动 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/ggcgbd/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司董监高及关联人的持股变动记录。按变动日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| gxrq | string | 变动日期（yyyy-MM-dd） |
| gxr | string | 变动人 |
| bdsl | number | 变动数量（股） |
| jcsl | number | 结存数量（股） |
| jyjj | number | 交易均价（元） |
| djgg | string | 董监高管/职位 |
| ygggx | string | 与高管关系 |
| gfbdtj | string | 股份变动途径 |
