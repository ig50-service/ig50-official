# 同地域个股排名

> 沪深京A股 / 股票基础信息 / 大事与市场 / 同地域个股排名

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 同地域个股排名 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/glggtdyggpm/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的同地域个股排名。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| gpdm | string | 股票代码（6位） |
| gpmc | string | 股票名称 |
| zsz | number | 总市值（元） |
| ltsz | number | 流通市值（亿元） |
| yysr | number | 营业收入（元） |
| gsjlr | number | 归属净利润（元） |
| yysrtb | number | 营业收入同比增长（%） |
| gsjlrtb | number | 归属净利润同比增长（%） |
| bglx | string | 报告类型 |
