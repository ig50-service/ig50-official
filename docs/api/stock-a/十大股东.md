# 十大股东

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 十大股东

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 十大股东 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/zygd/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的十大股东数据。按截止日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jzrq | string | 截止日期（yyyy-MM-dd） |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| gdsm | string | 股东说明 |
| gdzs | number | 股东总数 |
| pjcg | number | 平均持股（单位：股，按总股本计算） |
| sdgd | array<object> | 十大股东（其中object对象见下方说明） |
| pm | number | 排名（1-10） |
| gdmc | string | 股东名称 |
| cgsl | number | 持股数量（股） |
| cgbl | number | 持股比例（%） |
| gbxz | string | 股本性质 |
