# 对外担保

> 沪深京A股 / 股票基础信息 / 大事与市场 / 对外担保

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 对外担保 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/wdb/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的对外担保。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggq | string | 公告日期（yyyy-MM-dd） |
| dbf | string | 担保方名称 |
| bdbf | string | 被担保方名称 |
| dbfs | string | 担保方式 |
| dbje | number | 担保金额（万元） |
| bz | string | 币种 |
| dbdqqk | string | 担保到期情况 |
| dbqsr | string | 担保起始日（yyyy-MM-dd） |
| dbjsr | string | 担保结束日（yyyy-MM-dd） |
| sflx | string | 是否履行（"是"/"否"） |
| sfgljy | string | 是否关联交易（"是"/"否"） |
| jyrq | string | 交易日期（yyyy-MM-dd） |
| dbsxsm | string | 担保事项说明 |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bglx | string | 报告类型名称（如"中报"/"年报"等） |
