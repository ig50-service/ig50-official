## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 概念题材板块 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/hxtc/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的概念题材板块列表。按排名升序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bkdm | string | 板块代码 |
| bkmc | string | 板块名称 |
| pm | number | 板块排名 |
| zdf | number | 板块涨跌幅 |
| nblb | string | 纳入板块理由 |
