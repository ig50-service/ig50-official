## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深京A股-股票交易数据-股票行情-集合竞价 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/trace/jhjj/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取集合竞价数据，按时间升序

## 更新机制

- **更新频率**：集合竞价时间段（时间段：9:15~9:30，14:47~15:30）每1分钟
- **完成耗时**：约10秒

## 数据格式

```
[{},..]
```

## 字段说明

申报时间（yyyy-MM-dd HH:mm:ss）, 匹配量（股）, 未匹配量（股）, 标志（1：买单，-1：卖单）, 成交价
