# 集合竞价

> 沪深京A股 / 股票交易数据 / 股票行情 / 集合竞价

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 集合竞价 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/trace/jhjj/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取集合竞价数据，按时间升序。

## 更新机制

- **更新频率**：集合竞价时间段（时间段：9:15~9:30，14:47~15:30）每1分钟。
- **完成耗时**：约10秒。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 申报时间（yyyy-MM-ddHH:mm:ss） |
| m | number | 匹配量（股） |
| um | number | 未匹配量（股） |
| f | number | 标志（1：买单，-1：卖单） |
| p | number | 成交价 |

## 示例

```json
[{"t":"2026-05-12 09:15:00","p":11.29,"m":9600,"um":600,"f":1},{"t":"2026-05-12 09:15:00","p":11.28,"m":54500,"um":42400,"f":-1},{"t":"2026-05-12 09:15:00","p":11.28,"m":54700,"um":42400,"f":-1}]
```
