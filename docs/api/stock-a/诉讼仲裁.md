# 诉讼仲裁

> 沪深京A股 / 股票基础信息 / 大事与市场 / 诉讼仲裁

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 诉讼仲裁 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/sszc/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的诉讼仲裁。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggq | string | 公告日期（yyyy-MM-dd） |
| ajmc | string | 案件名称 |
| ajjj | string | 案件简介 |
| yg | string | 原告 |
| bg | string | 被告 |
| sslx | string | 诉讼类型 |
| saje | number | 涉案金额（万元） |
| bz | string | 币种 |
| ysqsrq | string | 一审起诉日期（yyyy-MM-dd） |
| ysslfy | string | 一审受理法院 |
| yspjrq | string | 一审判决日期（yyyy-MM-dd） |
| yspjnr | string | 一审判决内容 |
| sfss | string | 是否上诉（"是"/"否"） |
| esbssr | string | 二审被上诉人（未上诉时为空） |
| essslfy | string | 二审受理法院（未上诉时为空） |
| espjrq | string | 二审判决日期（未上诉时为空）（yyyy-MM-dd） |
| espjnr | string | 二审判决内容（未上诉时为空） |
| zxqk | string | 执行情况 |
