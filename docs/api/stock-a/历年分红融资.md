# 历年分红融资

> 沪深京A股 / 股票基础信息 / 分红融资 / 历年分红融资

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历年分红融资 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/dividendcompre/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司历年分红与融资汇总（分红总额、增发、配股、新股发行等每年一列，含汇总行）。按年度倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| nd | string | 年度（yyyy） |
| fhze | number | 分红总额（元） |
| zfg | number | 增发（万股） |
| pg | number | 配股（万股） |
| xgfxg | number | 新股发行（万股） |

## 示例

```json
[{"nd":"2026","fhze":0,"zfg":0,"pg":0,"xgfxg":0},{"nd":"2025","fhze":2183788136.4,"zfg":0,"pg":0,"xgfxg":0}]
```
