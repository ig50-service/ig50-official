# 配股

> 沪深京A股 / 股票基础信息 / 分红融资 / 配股

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 配股 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/pgmx/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司历次配股明细（公告日期、配股数量、募集资金、配股价格、登记日期、除权日期、配股说明）。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| pgsl | number | 配股数量（股） |
| mzzj | number | 募资总额（元） |
| pgjg | number | 配股价格（元/股） |
| djrq | string | 股权登记日（yyyy-MM-dd） |
| cqrq | string | 除权除息日（yyyy-MM-dd） |
| pgms | string | 配股说明（如"每10股配3股"） |

## 示例

```json
[{"ggrq":"2000-10-21","pgsl":393975057,"mzzj":3151800456,"pgjg":8,"djrq":"2000-11-03","cqrq":"2000-11-06","pgms":"每10股配3股"},{"ggrq":"1994-01-09","pgsl":26941789,"mzzj":134708945,"pgjg":5,"djrq":"1994-07-08","cqrq":"1994-07-09","pgms":"每10股配1股"}]
```
