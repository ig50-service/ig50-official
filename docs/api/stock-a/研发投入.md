# 研发投入

> 沪深京A股 / 股票基础信息 / 概况与经营 / 研发投入

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 研发投入 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/rdinput/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的研发投入情况。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqmc | string | 报告期名称 |
| bglx | string | 报告类型（如"中报"/"一季报"/"年报"/"三季报"等） |
| yftr | number | 研发投入金额（元） |
| yffy | number | 研发投入费用化金额（元） |
| yfzbh | number | 研发投入资本化金额（元） |
| yftrzb | number | 研发投入占营收比（%） |
