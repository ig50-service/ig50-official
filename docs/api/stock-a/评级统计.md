# 评级统计

> 沪深京A股 / 股票基础信息 / 财务与预测 / 评级统计

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 评级统计 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/pjtj/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取各研究机构的综合评级统计（买入/增持/中性/减持/卖出家数，按近1月内~近1年内5个时间段）。按时间段升序（1月内→1年内）。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| sjd | string | 时间段（如"1月内"/"2月内"/"3月内"/"6月内"/"1年内"等） |
| xjs | number | 评级系数（加权评分，>4=买入/>3=增持/>2=中性/>1=减持/>0=卖出） |
| zhpj | string | 综合评级（如"买入"/"增持"/"中性"/"减持"/"卖出"等） |
| mr | number | 买入家数 |
| zzc | number | 增持家数 |
| zx | number | 中性家数 |
| jch | number | 减持家数 |
| mc | number | 卖出家数 |
| zjs | number | 总家数（参与评级的机构总数） |

## 示例

```json
[{"sjd":"1月内","xjs":4.83,"zhpj":"买入","mr":5,"zzc":1,"zx":0,"jch":0,"mc":0,"zjs":6},{"sjd":"2月内","xjs":4.83,"zhpj":"买入","mr":5,"zzc":1,"zx":0,"jch":0,"mc":0,"zjs":6}]
```
