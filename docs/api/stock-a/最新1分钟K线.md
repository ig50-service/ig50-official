# 最新1分钟K线

> 沪深京A股 / 股票交易数据 / 股票K线 / 最新1分钟K线

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 最新1分钟K线 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/time/{股票代码}/{分时级别}` |

## 功能描述

根据《股票列表》得到的股票代码和分时级别获取最新1分钟k线数据。注意：1分钟K线（包括历史）为高频数据，需独立服务器部署+单独授权（授权随A股授权附赠）。

## 更新机制

- **更新频率**：盘中每5秒更新。
- **完成耗时**：5秒内。

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| d | string | 交易时间（yyyy-MM-ddHH:mm） |
| o | number | 开盘价（元） |
| h | number | 最高价（元） |
| l | number | 最低价（元） |
| c | number | 收盘价（元） |
| v | number | 成交量（股） |
| e | number | 成交额（元） |
| zf | number | 振幅（%） |
| hs | number | 换手率（%） |
| zd | number | 涨跌幅（%） |
| zde | number | 涨跌额（元） |
| zs | number | 昨收价（元） |
| ud | string | 更新时间（yyyy-MM-ddHH:mm:ss） |
