# 并购重组

> 沪深京A股 / 股票基础信息 / 概况与经营 / 并购重组

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 并购重组 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/bgcz/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的并购重组历史记录。按首次公告日倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| zxgg | string | 最新公告日（yyyy-MM-dd） |
| scgg | string | 首次公告日（yyyy-MM-dd） |
| ztjd | string | 重组进度 |
| bgfs | string | 并购方式 |
| jybd | string | 交易标的（多标的用"，"分隔） |
| zafa | string | 重组方案简介 |
