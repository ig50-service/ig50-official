## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 管理层简介 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/glcjj/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司当前在任高管的任职时间与简历详情。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| xm | string | 姓名 |
| xb | string | 性别 |
| xl | string | 学历 |
| nl | number | 年龄 |
| zw | string | 职务 |
| rzsj | string | 任职时间 |
| jl | string | 简历 |
