# 预测明细

> 沪深京A股 / 股票基础信息 / 财务与预测 / 预测明细

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 预测明细 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/ycmx/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取各研究机构研报明细（每股收益/净利润两条分别统计，含未来4年预测值）。按发布日期倒序（每股收益在前、净利润在后）。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jgmc | string | 机构简称 |
| fbrq | string | 发布日期（yyyy-MM-dd） |
| yjy | string | 研究员（逗号分隔多人） |
| pj | string | 评级（"买入"/"增持"/"中性"/"减持"/"卖出"） |
| zblx | string | 指标类型（"每股收益"/"净利润"） |
| nf1 | number | 第1年年份 |
| mark1 | string | 第1年标记（"A"=实际值/"E"=预测值） |
| val1 | number | 第1年指标值 |
| nf2 | number | 第2年年份 |
| mark2 | string | 第2年标记 |
| val2 | number | 第2年指标值 |
| nf3 | number | 第3年年份 |
| mark3 | string | 第3年标记 |
| val3 | number | 第3年指标值 |
| nf4 | number | 第4年年份 |
| mark4 | string | 第4年标记 |
| val4 | number | 第4年指标值（部分机构无第4年预测） |
