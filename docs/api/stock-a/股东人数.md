# 股东人数

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 股东人数

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 股东人数 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/gdrs/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司各报告期的股东人数与人均持股情况汇总。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| gdrs | number | 股东人数（户） |
| rjltg | number | 人均流通股（股） |
| gjj | number | 股价（元） |
| rjcgje | number | 人均持股金额（元） |
| jsbh | number | 股东人数较上期变化（%） |
| rjbh | number | 人均流通股较上期变化（%） |
| sdgdzh | number | 十大股东持股合计（%） |
| sdltzh | number | 十大流通股东持股合计（%） |
| cmd | string | 筹码集中度 |
