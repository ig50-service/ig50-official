# 指数、行业、概念树

> 沪深京A股 / 股票基础信息 / 股票板块概念 / 指数、行业、概念树

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 指数、行业、概念树 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/base/it` |

## 功能描述

获取指数、行业、概念。其中isleaf为1（叶子节点）的记录的code（代码）可以作为下方接口的参数传入，从而得到某个指数、行业、概念下的相关股票。

## 更新机制

- **更新频率**：每周六凌晨3点更新。
- **完成耗时**：约1分钟。

## 数据格式

```
[{},...]
```
