# 机构买卖统计

> 沪深京A股 / 股票基础信息 / 大事与市场 / 机构买卖统计

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 机构买卖统计 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/lhbjg/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的机构买卖统计。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jyrq | string | 上榜交易日（yyyy-MM-dd） |
| sp | number | 当日收盘价 |
| zdf | number | 当日涨跌幅 |
| mrcs | number | 买入次数（机构买入交易次数） |
| mccs | number | 卖出次数（机构卖出交易次数） |
| mrje | number | 买入金额（机构买入总额） |
| mcje | number | 卖出金额（机构卖出总额） |
| jme | number | 净买额（=mrje-mcje，可负） |
| cje | number | 成交额（市场总成交额） |
| zb | number | 净额占比（净买额/成交额×100） |
| hsl | number | 换手率 |
| ltsz | number | 流通市值 |
| smyy | string | 上榜原因（中文说明）（如"日涨幅偏离值达到7%的前5只证券"） |
| h1zdf | number | 后1日涨跌幅 |
| h2zdf | number | 后2日涨跌幅 |
| h3zdf | number | 后3日涨跌幅 |
| h5zdf | number | 后5日涨跌幅 |
| h10zdf | number | 后10日涨跌幅 |
| sc | string | 市场（中文）（如"深市"/"沪市"） |
| mrjs | number | 买入家数（买方机构数） |
| mcjs | number | 卖出家数（卖方机构数） |
