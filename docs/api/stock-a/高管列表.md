# 高管列表

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 高管列表

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 高管列表 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/gsgg/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司当前在任高管的基本信息快照（姓名、性别、年龄、学历、持股、薪酬、职务）。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| xm | string | 姓名 |
| xb | string | 性别 |
| nl | number | 年龄 |
| xl | string | 学历 |
| cgs | number | 持股数（股） |
| xc | number | 薪酬（元） |
| zw | string | 职务 |

