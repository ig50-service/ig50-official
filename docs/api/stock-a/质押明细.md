# 质押明细

> 沪深京A股 / 股票基础信息 / 分红融资 / 质押明细

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 质押明细 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/zhiya/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取股票的质押明细。

## 更新机制

- **更新频率**：每天20:30更新。
- **完成耗时**：约30分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| gdmc | string | 股东名称 |
| zygfsl | number | 质押股份数量（股） |
| zygfsz | number | 质押股份市值（元） |
| zscgfbl | number | 占所持股份比例（%） |
| zyjg | string | 质押机构 |
| zyyy | string | 质押原因 |
| zymd | number | 质押目的 |
| zyrspj | number | 质押日收盘价（元） |
| yjxgs | number | 预警线估算（元，算法：冻结起始日收盘价前复权*质押率*预警线比例） |
| pcxgs | number | 平仓线估算（元，算法：冻结起始日收盘价前复权*质押率*平仓线比例） |
| zysd | string | 质押开始日期（yyyy-MM-dd） |
| zyed | string | 质押结束日期（yyyy-MM-dd） |
| zyzt | string | 质押状态 |
| pubd | string | 公告日期（yyyy-MM-dd） |

## 示例

```json
[{"gdmc":"吴","zygfsl":1200000,"zygfsz":76238746.16484,"zscgfbl":59.65,"zyjg":"浙江xx有限责任公司","zyyy":"吴质押股份给浙江xx有限责任公司用于股权性投资","zymd":null,"zyrspj":59.65,"yjxgs":40.660664621248,"pcxgs":35.578081543592,"zysd":"2021-08-24","zyed":"2022-08-25","zyzt":"已解押","pubd":"2022-08-27"}]
```
