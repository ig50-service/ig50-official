## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深京A股-股票基础信息-融资融券-质押明细 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/zhiya/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码作为参数，得到股票的质押明细

## 更新机制

- **更新频率**：每天20:30
- **完成耗时**：约30分钟

## 数据格式

```
[{},...]
```

## 字段说明

股东名称, 质押股份数量（股）, 质押股份市值（元）, 占所持股份比例（%）, 质押机构, 质押原因, 质押目的, 质押日收盘价（元）, 预警线估算（元）。预警线算法：冻结起始日收盘价前复权*质押率*预警线比例。, 平仓线估算（元）。平仓线算法：冻结起始日收盘价前复权*质押率*平仓线比例。, 质押开始日期（yyyy-MM-dd）, 质押结束日期（yyyy-MM-dd）, 质押状态, 公告日期（yyyy-MM-dd）
