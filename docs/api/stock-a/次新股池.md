# 次新股池

> 沪深京A股 / 股票基础信息 / 股票板块概念 / 次新股池

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 次新股池 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/zdtgc/cxgc/{日期}` |

## 功能描述

根据日期（格式yyyy-MM-dd，最近15个交易日）作为参数，得到每天的次新股票列表，根据开板几日升序。

## 更新机制

- **更新频率**：交易时间段每10分钟更新。
- **完成耗时**：约1分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| mc | string | 名称 |
| p | number | 价格（元） |
| ztp | number | 涨停价（元） |
| zf | number | 涨跌幅（%） |
| cje | number | 成交额（元） |
| lt | number | 流通市值（元） |
| zsz | number | 总市值（元） |
| nh | number | 是否新高（0否/1是） |
| hs | number | 转手率（%） |
| tj | string | 涨停统计（x天/y板） |
| kb | number | 开板几日 |
| od | string | 开板日期（yyyyMMdd） |
| ipod | string | 上市日期（yyyyMMdd） |

## 示例

```json
[{"dm":"sz301070","mc":"N开勒","p":46.85,"ztp":null,"zf":70.05,"cje":438701840.00,"lt":758033000.00,"zsz":3024411120.00,"nh":0,"hs":54.90,"tj":"0/0","kb":1,"od":"20210923","ipod":"20210923"}]
```
