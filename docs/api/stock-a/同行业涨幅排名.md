# 同行业涨幅排名

> 沪深京A股 / 股票基础信息 / 大事与市场 / 同行业涨幅排名

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 同行业涨幅排名 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/glgghyzfpm/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的同行业涨幅排名。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| gpdm | string | 股票代码（6位） |
| gpmc | string | 股票名称 |
| j3yzf | number | 近3月涨幅（%） |
| j6yzf | number | 近6月涨幅（%） |
| j12yzf | number | 近12月涨幅（%） |

## 示例

```json
[{"gpdm":"601998","gpmc":"中信银行","j3yzf":2.47,"j6yzf":4.81,"j12yzf":14.74},{"gpdm":"002948","gpmc":"青岛银行","j3yzf":2.2,"j6yzf":1,"j12yzf":5.78}]
```
