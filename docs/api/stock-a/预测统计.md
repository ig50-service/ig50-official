# 预测统计

> 沪深京A股 / 股票基础信息 / 财务与预测 / 预测统计

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 预测统计 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/yctj/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取6个年度（实际+预测）的每股收益/ROE/归母净利润/营业总收入/营业利润及对应预测机构家数统计。按年度升序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| nf | number | 年度 |
| mark | string | 年度标记（"A"=实际值/"E"=预测值） |
| eps | number | 每股收益（元/股） |
| epsLm | number | 近六月每股收益（元/股） |
| bvps | number | 每股净资产（元/股） |
| roe | number | 净资产收益率（%） |
| netProfit | number | 归母净利润（元） |
| income | number | 营业总收入（元） |
| opProfit | number | 营业利润（元） |
| epsCnt | number | EPS预测机构家数 |
| epsLmCnt | number | 近六月EPS机构家数 |
| bvpsCnt | number | 每股净资产机构家数 |
| roeCnt | number | ROE机构家数 |
| netProfitCnt | number | 归母净利润机构家数 |
| incomeCnt | number | 营业总收入机构家数 |
| opProfitCnt | number | 营业利润机构家数 |
| rank | number | 排名（1-6，按年份升序） |
