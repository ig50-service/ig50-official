## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 行业背景 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/hybj/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的行业背景。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}...]
```
