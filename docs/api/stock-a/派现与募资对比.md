# 派现与募资对比

> 沪深京A股 / 股票基础信息 / 分红融资 / 派现与募资对比

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 派现与募资对比 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/pxymz/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取股票的派现与募资对比。

## 更新机制

- **更新频率**：每天20:30更新。
- **完成耗时**：约30分钟。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| pxcs | number | 派现次数 |
| pxze | number | 派现总额（元） |
| rzcs | number | 融资次数 |
| rzze | number | 融资总额（元） |
| fhl | number | 分红率（%） |
| gxzfl | number | 股息支付率（%） |
| pxrzb | number | 派现融资比（%） |
| sfrze | number | 首发融资额（元） |
| sfrzcs | number | 首发融资次数 |
| zfrzcs | number | 增发融资次数 |
| zqrzcs | number | 债券融资次数 |
