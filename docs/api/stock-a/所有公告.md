# 所有公告

> 沪深京A股 / 股票基础信息 / 资金与公告 / 所有公告

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 所有公告 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/history/gonggao/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取个股历史所有公告。按公告日期倒序。

## 更新机制

- **更新频率**：每天20:00更新。
- **完成耗时**：约30分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 公告日期（yyyy-MM-dd） |
| title | string | 公告标题 |
| type | string | 公告类型 |
| file | string | 原文件（http://xxx.pdf格式） |

## 示例

```json
[{"t":"2023-03-09","title":"平安银行:2022年年度报告","type":"年度报告全文","file":"https://xxx.com/pdf/H2_AN202303081584126176_1.pdf"}]
```
