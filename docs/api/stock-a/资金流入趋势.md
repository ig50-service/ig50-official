# 资金流入趋势

> 沪深京A股 / 股票基础信息 / 资金与公告 / 资金流入趋势

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 资金流入趋势 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/zijin/zjlrqs/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取近十年每天资金流入趋势。按时间倒序。

## 更新机制

- **更新频率**：每天20:00更新。
- **完成耗时**：约8小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 时间（yyyy-MM-dd） |
| zdf | number | 涨跌幅（%） |
| hsl | number | 换手率（%） |
| jlr | number | 净流入（元） |
| jlrl | number | 净流入率（%） |
| zljlr | number | 主力净流入（元） |
| zljlrl | number | 主力净流入率（%） |
| hyjlr | number | 行业净流入（元） |
| hyjlrl | number | 行业净流入率（%） |
