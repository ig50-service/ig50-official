# 场内指数行情

> 沪深京A股 / 指数 / 指数相关 / 场内指数行情

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 场内指数行情 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/{指数代码（包含sh/sz/bj前缀，如：sh000001）}` |

## 功能描述

根据《场内指数》得到的指数代码获取实时交易数据。

## 更新机制

- **更新频率**：交易时间段每1分钟。
- **完成耗时**：约15秒。

{}
