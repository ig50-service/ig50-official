> 沪深京A股 / 指数相关 / 指数列表 / 指数成分

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 指数成分 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/base/zscf` |

## 功能描述

获取指数成分代码和名称，用于后续接口的参数传入。注意：同样是"沪深300"，会出现sz399300和sh000300两个代码，它们是不同交易所的行情代码，其实指向同一只指数。

## 更新机制

- **更新频率**：每天15:35点。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 指数代码（如：sz399300） |
| mc | string | 股票名称（如：沪深300） |
| jys | string | 交易所（"sh"表示上证，"sz"表示深证） |
