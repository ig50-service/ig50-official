# 盘中异动

> 沪深京A股 / 股票交易数据 / 股票行情 / 盘中异动

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 盘中异动 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/all/pzyd` |

## 功能描述

获取最新1000条盘中异动信息，按异动时间倒序。

## 更新机制

- **更新频率**：交易时间段每1分钟。
- **完成耗时**：约10秒。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 股票代码 |
| mc | string | 股票名称 |
| t | string | 异动时间（yyyy-MM-ddHH:mm:ss） |
| type | string | 异动类型（火箭发射/加速下跌/快速反弹/高台跳水/大笔买入/大笔卖出/封涨停板/封跌停板/打开跌停板/打开涨停板/有大买盘/有大卖盘/竞价上涨/竞价下跌/高开5日线/低开5日线/向上缺口/向下缺口/60日新高/60日新低/60日大幅上涨/60日大幅下跌） |
| xx | string | 相关信息：返回结果：xxx%（对应异动类型：火箭发射/加速下跌/快速反弹/高台跳水/竞价上涨/竞价下跌/高开5日线/低开5日线/向上缺口/向下缺口/60日大幅上涨/60日大幅下跌）返回结果：xxx股（对应异动类型：大笔买入/大笔卖出/有大买盘/有大卖盘）返回结果：xxx元（对应异动类型：封涨停板/封跌停板/打开跌停板/打开涨停板/60日新高/60日新低） |
