## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深京A股-股票基础信息-上市公司详情-公司简介 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/info/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的简介。包括公司基本信息，概念以及发行信息等

## 更新机制

- **更新频率**：每天15:30（更新完成约12小时）
- **完成耗时**：

## 数据格式

```
{}
```

## 字段说明

公司名称, 公司英文名称, 上市市场, 概念及板块，多个概念由英文逗号分隔, 上市日期，格式yyyy-MM-dd, 发行价格（元）, 主承销商, 成立日期, 注册资本, 机构类型, 组织形式, 董事会秘书, 公司电话, 董秘电话, 公司传真, 董秘传真, 公司电子邮箱, 董秘电子邮箱, 公司网站, 邮政编码, 信息披露网址, 证券简称更名历史, 注册地址, 办公地址, 公司简介, 经营范围, 承销方式, 上市推荐人, 发行方式, 发行市盈率（按发行后总股本）, 首发前总股本（万股）, 首发后总股本（万股）, 实际发行量（万股）, 预计募集资金（万元）, 实际募集资金合计（万元）, 发行费用总额（万元）, 募集资金净额（万元）, 承销费用（万元）, 招股公告日
