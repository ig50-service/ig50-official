# 成长性比较

> 沪深京A股 / 股票基础信息 / 大事与市场 / 成长性比较

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 成长性比较 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/cz/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的成长性比较。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。
