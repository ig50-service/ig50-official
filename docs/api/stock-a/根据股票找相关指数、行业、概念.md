## 更新机制

- **更新频率**：每周六凌晨3点
- **完成耗时**：约8小时

## 数据格式

```
[{},...]
```

## 字段说明

指数、行业、概念代码，如：sw2_650300, 指数、行业、概念名称，如：沪深股市-申万二级-国防军工-地面兵装
