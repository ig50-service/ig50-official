## 功能描述

获取沪深两市主要的指数代码和名称，用于后续接口的参数传入。

## 更新机制

- **更新频率**：每天15:35点。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 指数代码（如：sh000001） |
| mc | string | 股票名称（如：上证指数） |
| jys | string | 交易所，"sh"表示上证，"sz"表示深证，"zz"表示中证指数（同时含有沪深两市成分股的指数） |
