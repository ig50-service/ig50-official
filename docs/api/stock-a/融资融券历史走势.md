# 融资融券历史走势

> 沪深京A股 / 股票基础信息 / 分红融资 / 融资融券历史走势

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 融资融券历史走势 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/rzrq/{股票代码}` |

## 功能描述

根据《融资融券标的股》接口获取的股票代码得到近两年股票的融资融券变化走势，根据时间倒序。特殊的，如果想获取沪深两市（沪深300）的数据传入"zz"参数，上证数据传入"sh"参数，深证数据传入"sz"参数。由于融资融券数据为次日上午更新，因此最新的数据是上一个交易日的数据。

## 更新机制

- **更新频率**：每天上午8:50更新。
- **完成耗时**：约20分钟。
