# 股价表现

> 沪深京A股 / 股票基础信息 / 大事与市场 / 股价表现

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 股价表现 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/gjbx/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的股价表现。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码（当前股票/沪深300/行业板块） |
| jmc | string | 简称（当前股票/沪深300/行业板块） |
| zdf1 | number | 最近1个月累计涨跌幅（%） |
| zdf2 | number | 最近3个月累计涨跌幅（%） |
| zdf3 | number | 最近6个月累计涨跌幅（%） |
| zdf4 | number | 今年以来累计涨跌幅（%） |

## 示例

```json
[{"dm":"000001","jmc":null,"zdf1":0.17,"zdf2":11.21,"zdf3":11.21,"zdf4":5.46},{"dm":"000300","jmc":"沪深300","zdf1":0.46,"zdf2":-6.03,"zdf3":-1.1,"zdf4":-0.45}]
```
