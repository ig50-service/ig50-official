# 解禁限售

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 解禁限售

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 解禁限售 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/jjxs/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的解禁限售情况。按解禁日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| rdate | string | 解禁日期（yyyy-MM-dd） |
| ramount | number | 解禁数量（万股） |
| rprice | number | 解禁股流通市值（亿元） |
| batch | number | 上市批次 |
| pdate | string | 公告日期（yyyy-MM-dd） |

## 示例

```json
[{"rdate":"2018-05-21","ramount":25224.80,"rprice":27.2932,"batch":15,"pdate":"2015-05-20"}]
```
