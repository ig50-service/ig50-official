# 现金流量表

> 沪深京A股 / 股票基础信息 / 财务与预测 / 现金流量表

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 现金流量表 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/cashflow/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的现金流量表（按科目行存储，支持银行/通用等多行业）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| date | string | 报告日期（yyyy-MM-dd） |
| dcode | string | 报告类型（年报/中报/三季报/一季报） |
| org | string | 行业路由标记（如"通用"/"银行"等） |
| code | string | 科目代码 |
| name | string | 科目名称 |
| amount | number | 金额（元） |

## 示例

```json
[{"date":"2026-06-30","dcode":"中报","org":"通用","code":"SALES_SERVICES","name":"销售商品、提供劳务收到的现金","amount":174668550740.76},{"date":"2026-06-30","dcode":"中报","org":"通用","code":"RECEIVE_TAX_REFUND","name":"收到的税收返还","amount":3519384421.9}]
```
