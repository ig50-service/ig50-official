# 盈利能力

> 沪深京A股 / 股票基础信息 / 财务与预测 / 盈利能力

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 盈利能力 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/mainindexprofit/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的盈利能力指标（加权/扣非加权ROE、总资产净利率、毛利率、净利率）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqlx | string | 报告类型（如"中报"/"年报"/"一季报"/"三季报"等） |
| bqmc | string | 报告期名称 |
| roejq | number | 净资产收益率（加权，%） |
| roekc | number | 净资产收益率（扣非/加权，%） |
| zzclr | number | 总资产收益率（加权，%） |
| xsmlr | number | 毛利率（%） |
| xsjlr | number | 净利率（%） |

