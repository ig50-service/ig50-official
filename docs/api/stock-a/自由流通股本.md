# 自由流通股本

> 沪深京A股 / 股票交易数据 / 股票行情 / 自由流通股本

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 自由流通股本 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/dxsj/zyltgb` |

## 功能描述

获取上一个交易日沪深京全市场自由流通股本（更符合实际的可交易股本），按代码升序。

## 更新机制

- **更新频率**：每天20:0更新。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| zyltgb | number | 自由流通股本（万股） |
| tjrq | string | 统计日期（yyyy-MM-dd） |

## 示例

```json
[{"dm":"000001","zyltgb":816056.56,"tjrq":"2026-09-04"},{"dm":"000002","zyltgb":647230.24,"tjrq":"2026-09-04"}]
```
