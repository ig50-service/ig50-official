# 上证系列指数

> 沪深京A股 / 指数相关 / 指数列表 / 上证系列指数

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 上证系列指数 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/base/sh` |

## 功能描述

获取沪市下的所有指数代码和名称，用于后续接口的参数传入。

## 更新机制

- **更新频率**：每天15:35点。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 指数代码（如：sh000001） |
| mc | string | 股票名称（如：上证指数） |
| jys | string | 交易所（固定：sh，表示上交所） |

## 示例

```json
[{"dm":"sh000916","mc":"300通信","jys":"sh","isIndex":1,"isCyb":0,"isKcb":0,"isSt":0,"isNew":0,"pureDm":"000916","wholeDm":"sh000916"},{"dm":"sh000171","mc":"新兴成指","jys":"sh","isIndex":1,"isCyb":0,"isKcb":0,"isSt":0,"isNew":0,"pureDm":"000171","wholeDm":"sh000171"}]
```
