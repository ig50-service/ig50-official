# 其他指数行情

> 沪深京A股 / 指数 / 指数相关 / 其他指数行情

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 其他指数行情 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/{指数代码（包含zz/gz/hz前缀，如：zz931250）}` |

## 功能描述

根据《其他指数》得到的指数代码获取实时交易数据。

## 更新机制

- **更新频率**：交易时间段每1分钟。
- **完成耗时**：约30秒。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 指数代码（如：000001） |
| mc | string | 指数名称（如：上证指数） |
| t | string | 更新时间（yyyy-MM-ddHH:mm:ss） |
| sud | string | 数据时间（yyyy-MM-ddHH:mm:ss） |
| p | number | 当前价格（元） |
| yc | number | 昨日收盘价（元） |
| o | number | 开盘价（元） |
| h | number | 最高价（元） |
| l | number | 最低价（元） |
| jp | number | 均价（元） |
| ud | number | 涨跌额（元） |
| pc | number | 涨跌幅（%） |
| zf | number | 振幅（%） |
| v | number | 成交量（股） |
| cje | number | 成交额（元） |
| lb | number | 量比 |
| zs | number | 涨速（%） |
| np | number | 内盘（股） |
| wp | number | 外盘（股） |
| lzds | number | 连涨天数（负数表示连跌天数） |
| z20 | number | 20日涨跌幅（%） |
| ytd | number | 年初至今涨跌幅（%） |
