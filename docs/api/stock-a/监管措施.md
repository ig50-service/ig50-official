# 监管措施

> 沪深京A股 / 股票基础信息 / 大事与市场 / 监管措施

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 监管措施 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/jgcs/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的监管措施。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggq | string | 公告日期（yyyy-MM-dd） |
| ggnf | number | 公告年份 |
| bz | string | 币种 |
| cfjg | string | 处理人 |
| wflx | string | 违规类型 |
| cflx | string | 处理类型 |
| cfje | number | 处罚金额（万元） |
| cfxd | string | 涉及对象 |
| wfxw | string | 处理事由（含文号、案由、处罚依据、处罚决定等） |
| cfjz | string | 处理措施 |
