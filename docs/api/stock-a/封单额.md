# 封单额

> 沪深京A股 / 股票交易数据 / 股票行情 / 封单额

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 封单额 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/dxsj/fde` |

## 功能描述

获取上一个交易日沪深京全市场封单额，按代码升序。

## 更新机制

- **更新频率**：每天20:0更新。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| fde | number | 数据日当日封单额（万元） |
| qrfde | number | 数据日前一个交易日封单额（万元） |
| qefde | number | 数据日前两个交易日封单额（万元） |
| tjrq | string | 统计日期（yyyy-MM-dd） |

## 示例

```json
[{"dm":"000017","fde":-6166.490,"qrfde":-51078.760,"qefde":0.000,"tjrq":"2026-09-04"},{"dm":"000428","fde":3129.780,"qrfde":0.000,"qefde":0.000,"tjrq":"2026-09-04"}]
```
