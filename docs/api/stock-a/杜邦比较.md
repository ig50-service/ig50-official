# 杜邦比较

> 沪深京A股 / 股票基础信息 / 财务与预测 / 杜邦比较

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 杜邦比较 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/dbfx/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取杜邦核心指标与行业平均/中值/排名股票的3年对比数据。按排名升序（行业汇总在前、当前股票在后）。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dgsjmc | string | 对比对象简称（如"行业平均"/"行业中值"等） |
| pm | number | 排名 |
| zs | number | 行业总股票数 |
| bgq | string | 报告期（yyyy-MM-dd） |
| roe_23a | number | 净资产收益率（加权，2023年） |
| roe_24a | number | 净资产收益率（加权，2024年） |
| roe_25a | number | 净资产收益率（加权，2025年） |
| roe_avg | number | 净资产收益率（加权，3年平均） |
| xll_23a | number | 销售净利率（2023年） |
| xll_24a | number | 销售净利率（2024年） |
| xll_25a | number | 销售净利率（2025年） |
| xll_avg | number | 销售净利率（3年平均） |
| zzz_23a | number | 总资产周转率（2023年） |
| zzz_24a | number | 总资产周转率（2024年） |
| zzz_25a | number | 总资产周转率（2025年） |
| zzz_avg | number | 总资产周转率（3年平均） |
| qys_23a | number | 权益乘数（2023年） |

| qys_25a | number | 权益乘数（2025年） |
| qys_avg | number | 权益乘数（3年平均） |
