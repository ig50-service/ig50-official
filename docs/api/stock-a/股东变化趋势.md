# 股东变化趋势

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 股东变化趋势

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 股东变化趋势 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/gdbh/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的股东变化趋势数据。按截止日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jzrq | string | 截止日期（yyyy-MM-dd） |
| gdhs | string | 股东户数 |
| bh | string | 比上期变化情况 |

## 示例

```json
[{"jzrq":"2026-03-31","gdhs":"457610","bh":"减少5214"},{"jzrq":"2026-02-28","gdhs":"462824","bh":"新增21682"},{"jzrq":"2025-12-31","gdhs":"441142","bh":"减少12373"}]
```
