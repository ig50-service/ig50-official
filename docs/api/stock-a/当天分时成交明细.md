# 当天分时成交明细

> 沪深京A股 / 股票交易数据 / 股票行情 / 当天分时成交明细

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 当天分时成交明细 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/trace/onebyone/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取当天3秒为粒度聚合的成交数据，按成交时间升序。

## 更新机制

- **更新频率**：交易时间段每2分钟。
- **完成耗时**：约10秒。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| d | string | 数据更新时间（yyyy-MM-ddHH:mm:ss） |
| t | string | 成交时间（HH:mm） |
| v | number | 成交量（股） |
| p | number | 成交价 |
| ts | number | 交易方向（0：中性盘，1：买入，2：卖出） |
| n | number | 成交笔数 |

## 示例

```json
[{"d":"2026-09-05 04:34:37","t":"09:25","v":509400,"p":11.86,"ts":0,"n":248},{"d":"2026-09-05 04:34:37","t":"09:30","v":365100,"p":11.86,"ts":2,"n":197},{"d":"2026-09-05 04:34:37","t":"09:30","v":603400,"p":11.87,"ts":1,"n":384}]
```
