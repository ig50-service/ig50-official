# 机构评级

> 沪深京A股 / 股票基础信息 / 大事与市场 / 机构评级

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 机构评级 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/jgpj/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的机构评级。按评级日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jgrq | string | 发布日期（yyyy-MM-dd） |
| bgmc | string | 报告名称 |
| fileUrl | string | 原始报告PDF地址 |
| jgjc | string | 机构简称 |
| yzy | string | 研究员（逗号分隔多作者） |
| pj | string | 评级（如"买入"/"增持"/"中性"/"减持"等） |
| pjbh | number | 评级变动（1=首次，2=上调，3=维持，4=下调） |
| spj | string | 上次评级 |
| mbjg | number | 目标价（元） |
| eps1 | number | 今年预测EPS（元/股） |
| pe1 | number | 今年预测PE（倍） |
| eps2 | number | 明年预测EPS（元/股） |
| pe2 | number | 明年预测PE（倍） |
| eps3 | number | 后年预测EPS（元/股） |
| pe3 | number | 后年预测PE（倍） |
