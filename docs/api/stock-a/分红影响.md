# 分红影响

> 沪深京A股 / 股票基础信息 / 分红融资 / 分红影响

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 分红影响 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/dividend/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司历次分红方案及实施进度（含公告日期、股权登记日、除权除息日、派息日、方案进度、公告PDF等）。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期 |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| fhfa | string | 分红方案 |
| gqrq | string | 股权登记日（未实施时空）（yyyy-MM-dd） |
| cqrq | string | 除权除息日（yyyy-MM-dd） |
| pxrq | string | 派息日（yyyy-MM-dd） |
| faJd | string | 方案进度（如"董事会预案"/"实施方案"等） |
| fpDx | string | 分配对象 |
| fileUrl | string | 原始报告PDF地址 |

