# 阶段主力动向

> 沪深京A股 / 股票基础信息 / 资金与公告 / 阶段主力动向

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 阶段主力动向 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/zijin/jdzldx/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取近十年每天阶段主力动向。按时间倒序。

## 更新机制

- **更新频率**：每天20:00更新。
- **完成耗时**：约8小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 时间（yyyy-MM-dd） |
| jlr3 | number | 近3日主力净流入（元） |
| jlr5 | number | 近5日主力净流入（元） |
| jlr10 | number | 近10日主力净流入（元） |
| jlrl3 | number | 近3日主力净流入率（%） |
| jlrl5 | number | 近5日主力净流入率（%） |
| jlrl10 | number | 近10日主力净流入率（%） |
