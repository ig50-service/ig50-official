# 筹码分布

> 沪深京A股 / 股票交易数据 / 股票行情 / 筹码分布

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 筹码分布 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/cmfb/{代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取近期筹码分布（数据历史深度随程序安装时间每日累积），按日期升序。

## 更新机制

- **更新频率**：每天20:00更新。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| d | string | 日期（yyyy-MM-dd） |
| hlbl | number | 获利比例（%） |
| jd90 | number | 90%成本集中度（数值越小筹码越集中） |
| qj90 | string | 90%成本区间（低~高，元） |
| jd70 | number | 70%成本集中度（数值越小核心筹码越集中） |
| qj70 | string | 70%成本区间（低~高，元） |

## 示例

```json
[{"d":"2026-09-02","hlbl":30.23,"jd90":27.60,"qj90":"19.22~29.54","jd70":12.98,"qj70":"23.94~28.79"},{"d":"2026-09-03","hlbl":58.02,"jd90":26.93,"qj90":"19.43~29.50","jd70":11.94,"qj70":"24.24~28.70"},{"d":"2026-09-04","hlbl":23.81,"jd90":26.26,"qj90":"19.64~29.46","jd70":10.92,"qj70":"24.55~28.63"}]
```
