| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深京A股-股票交易数据-股票行情-当天大单交易 |

| 本地路径 | `数据存放目录/time/real/trace/bigdeal/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取当天大于100w单笔的成交单，按时间倒序

## 更新机制

- **更新频率**：每天20:00
- **完成耗时**：约8小时

## 数据格式

```
[{},..]
```

## 字段说明

数据归属日期（yyyy-MM-dd）, 时间（HH:mm:dd）, 成交量（股）, 成交价, 交易方向（0：中性盘，1：买入，2：卖出）
