## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 杜邦分析（资产负债） |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/dupontbs/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取杜邦分析下的资产负债表明细科目（金额列，平铺列存储）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。
