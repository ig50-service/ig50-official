# 十大股东（详）

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 十大股东（详）

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 十大股东（详） |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/sdgd/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的十大股东详情记录（含机构类型、管理人、基金信息、变动类型等完整字段）。按报告期倒序+持股数降序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| jglx | string | 机构类型代码（如"01"=基金/"05"=保险/"07"=一般法人等） |
| jglxmc | string | 机构类型名称 |
| gdmc | string | 股东/机构名称 |
| jjglr | string | 机构管理人/基金管理公司 |
| cgs | number | 持股数（股） |
| ltcgs | number | 流通股数（股） |
| bdcgs | number | 变动股数（股） |
| cgsz | number | 持股市值（元） |
| ltsz | number | 流通市值（元） |
| cgbl | number | 占总股本持股比例（%） |
| ltcgbl | number | 占流通股本持股比例（%） |
| jzbl | number | 净值比例（%） |
| bd | string | 变动类型（如"增持"/"减持"/"不变"/"新进"等） |
| jjdm | string | 基金代码 |
| jjysdm | string | 基金衍生代码 |
| jjjl | string | 基金经理 |
| jjlx | string | 基金类型 |
