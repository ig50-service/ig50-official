# 研发人员

> 沪深京A股 / 股票基础信息 / 概况与经营 / 研发人员

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 研发人员 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/rdstaff/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的研发人员情况。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqmc | string | 报告期名称 |
| bglx | string | 报告类型（仅年报） |
| yfrys | number | 研发人员数（人） |
| yfrysst | number | 研发人员同比变动人数（人） |
| yfrybd | number | 研发人员环比变动人数（人） |
| yfrysyb | number | 研发人员占总员工比例（%） |
| yfrybdhb | number | 研发人员变动环比（%） |
| yfrybdtbb | number | 研发人员变动同比（%） |
