# 当天分钟分时成交

> 沪深京A股 / 股票交易数据 / 股票行情 / 当天分钟分时成交

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 当天分钟分时成交 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/real/trace/timedeal/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取当天盘中以分钟为单位统计的成交总量以及平均价格，按时间升序。

## 更新机制

- **更新频率**：交易时间段每2分钟。
- **完成耗时**：约10秒。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 分时时间（HH:mm） |
| p | number | 当前价 |
| avg | number | 均价 |
| v | number | 成交量（股） |
| d | string | 数据更新时间（yyyy-MM-ddHH:mm:ss） |

## 示例

```json
[{"t":"09:31","p":11.9,"avg":11.88,"v":2712600,"d":"2026-09-05 04:21:41"},{"t":"09:32","p":11.89,"avg":11.88,"v":1440800,"d":"2026-09-05 04:21:41"},{"t":"09:33","p":11.91,"avg":11.88,"v":745700,"d":"2026-09-05 04:21:41"}]
```
