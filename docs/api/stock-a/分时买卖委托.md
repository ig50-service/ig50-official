# 分时买卖委托

> 沪深京A股 / 股票交易数据 / 股票行情 / 分时买卖委托

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 分时买卖委托 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/dxsj/mmld/{代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上一个交易日以分钟聚合的委买量与委卖量，按时间升序。

## 更新机制

- **更新频率**：每天20:0更新。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 时间（HH:mm） |
| wb | number | 委买量（手，该分钟时点，盘口上委托买入的挂单总量） |
| ws | number | 委卖量（手，该分钟时点，盘口上委托卖出的挂单总量） |

## 示例

```json
[{"t":"09:31","wb":7943,"ws":4361},{"t":"09:32","wb":5129,"ws":6266},{"t":"09:33","wb":4610,"ws":6883}]
```
