# 根据指数、行业、概念找相关股票

> 沪深京A股 / 股票基础信息 / 指数、行业、概念 / 根据指数、行业、概念找相关股票

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深京A股-股票基础信息-指数、行业、概念-根据指数、行业、概念找相关股票 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/indextree/{指数、行业、概念代码}` |

## 功能描述

根据"指数、行业、概念树"接口得到的代码作为参数，得到相关的股票

## 更新机制

- **更新频率**：每周六凌晨3点
- **完成耗时**：约8小时

## 数据格式

```
[{},...]
```

## 字段说明

代码（根据接口参数可能是A股股票代码，也可能是其他指数、行业、概念的股票代码）, 名称（根据接口参数可能是A股股票代码，也可能是其他指数、行业、概念的股票名称）, 交易所，"sh"表示上证，"sz"表示深证（如果返回的是A股的股票，那么有值，否则是null）
