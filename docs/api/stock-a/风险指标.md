# 风险指标

> 沪深京A股 / 股票基础信息 / 财务与预测 / 风险指标

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 风险指标 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/mainindexrisk/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的风险指标（流动/速动/现金流量比率、资产负债率、权益系数、产权比率）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqlx | string | 报告类型（如"中报"/"年报"/"一季报"/"三季报"等） |
| bqmc | string | 报告期名称 |
| ldbl | number | 流动比率 |
| sdbl | number | 速动比率 |
| xjllb | number | 现金流量比率 |
| zcfzl | number | 资产负债率（%） |
| qycs | number | 权益系数 |
| cqbl | number | 产权比率 |

## 示例

