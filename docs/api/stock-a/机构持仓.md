# 机构持仓

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 机构持仓

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 机构持仓 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/jgcc/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司按机构类型分组的每期持仓汇总。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| jglx | string | 机构类型代码（如"01"=基金/"05"=保险/"04"=券商/"07"=其他/"00"=合计） |
| jglxmc | string | 机构类型名称 |
| jgjs | number | 持仓家数 |
| ltcgs | number | 流通股持仓股数（股） |
| zcgs | number | 总持仓股数（股） |
| cgsz | number | 持股市值（元） |
| zgfbl | number | 占总股本比（%） |
| qbfbl | number | 全部占比（%） |
| ltgbbh | number | 流通股变化（%） |
| bdbl | number | 变动比例（%） |
| ltcgbh | number | 流通股变动股数（股） |
| spj | number | 收盘价（元） |
