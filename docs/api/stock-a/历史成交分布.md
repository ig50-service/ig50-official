# 历史成交分布

> 沪深京A股 / 股票基础信息 / 资金与公告 / 历史成交分布

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历史成交分布 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/zijin/lscjfb/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取近十年每天历史成交分布。按时间倒序。

## 更新机制

- **更新频率**：每天20:00更新。
- **完成耗时**：约8小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 时间（yyyy-MM-dd） |
| c | number | 收盘价（元） |
| zdf | number | 涨跌幅（%） |
| jlrl | number | 净流入率（%） |
| hsl | number | 换手率（%） |
| qbjlr | number | 全部净流入（元） |
| cddlr | number | 超大单流入（元） |
| cddjlr | number | 超大单净流入（元） |
| ddlr | number | 大单流入（元） |
| ddjlr | number | 大单净流入（元） |
| xdlr | number | 小单流入（元） |
| xdjlr | number | 小单净流入（元） |
| sdlr | number | 散单流入（元） |
| sdjlr | number | 散单净流入（元） |
