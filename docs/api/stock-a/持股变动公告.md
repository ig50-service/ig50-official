# 持股变动公告

> 沪深京A股 / 股票基础信息 / 资金与公告 / 持股变动公告

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 持股变动公告 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/gonggao/cgbd/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取个股历史所有持股变动公告。按公告日期倒序。

## 更新机制

- **更新频率**：每天20:00更新。
- **完成耗时**：约30分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 公告日期（yyyy-MM-dd） |
| title | string | 公告标题 |
| type | string | 公告类型 |
| file | string | 原文件（http://xxx.pdf格式） |

## 示例

```json
[{"t":"2022-09-29","title":"万科A:关于董事、监事和高级管理人员股份增持计划完成的公告","type":"股东/实际控制人股份增持","file":"https://xxx.com/pdf/H2_AN202209281578748173_1.pdf"}]
```
