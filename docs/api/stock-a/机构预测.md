# 机构预测

> 沪深京A股 / 股票基础信息 / 财务与预测 / 机构预测

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 机构预测 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/jgyc/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取各研究机构对未来4年的每股收益与市盈率预测（含近六月平均聚合行）。按发布日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jgmc | string | 机构简称 |
| fbrq | string | 发布日期（yyyy-MM-dd） |
| nf1 | number | 第1年年份 |
| mark1 | string | 第1年标记（"A"=实际值/"E"=预测值） |
| nf2 | number | 第2年年份 |
| mark2 | string | 第2年标记 |
| nf3 | number | 第3年年份 |
| mark3 | string | 第3年标记 |
| nf4 | number | 第4年年份 |
| mark4 | string | 第4年标记 |
| eps1 | number | 第1年EPS（每股收益，元/股） |
| eps2 | number | 第2年EPS |
| eps3 | number | 第3年EPS |
| eps4 | number | 第4年EPS（部分机构无第4年预测） |
| pe1 | number | 第1年PE（市盈率，倍） |
| pe2 | number | 第2年PE |
| pe3 | number | 第3年PE |
| pe4 | number | 第4年PE（部分机构无第4年预测） |
