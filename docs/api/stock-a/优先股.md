# 优先股

> 沪深京A股 / 股票基础信息 / 分红融资 / 优先股

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 优先股 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/yxgxm/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司发行的优先股明细（代码/简称、起息日期、上市日期、发行数量/金额/价格、票面利率、用途说明）。按起息日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| yxgdm | string | 优先股代码（带后缀） |
| yxgbm | string | 优先股代码（纯代码） |
| yxgjc | string | 优先股简称 |
| qsrq | string | 发行起始日（优先股发行公告开始日）（yyyy-MM-dd） |
| shrq | string | 过户日（优先股发行后过户/挂牌上市日期）（yyyy-MM-dd） |
| fxsl | number | 实际发行数量（股） |
| mzzj | number | 实际募资总额（元） |
| fxjg | number | 发行价格（元/股） |
| pmll | number | 票面股息率（%） |
| ytsm | string | 用途说明 |

## 示例

```json
[{"yxgdm":"140002.SZ","yxgbm":"140002","yxgjc":"平银优01","qsrq":"2016-03-07","shrq":"2016-03-25","fxsl":200000000,"mzzj":20000000000,"fxjg":100,"pmll":4.37,"ytsm":"用途：拟投入2000000万元用于补充公司其他一级资本"}]
```
