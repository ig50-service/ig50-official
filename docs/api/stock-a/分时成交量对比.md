# 分时成交量对比

> 沪深京A股 / 股票交易数据 / 股票行情 / 分时成交量对比

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 分时成交量对比 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/dxsj/cjdb/{代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上一个交易日以分钟聚合的成交量对比，按时间升序。

## 更新机制

- **更新频率**：每天20:0更新。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| t | string | 时间（HH:mm） |
| qrlj | number | 数据日前一个交易日同期累计量（手） |
| drlj | number | 数据日累计量（手） |

## 示例

```json
[{"t":"09:31","qrlj":26724.00,"drlj":27126.00},{"t":"09:32","qrlj":38299.00,"drlj":41534.00},{"t":"09:33","qrlj":54071.00,"drlj":48991.00}]
```
