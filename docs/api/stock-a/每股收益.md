# 每股收益

> 沪深京A股 / 股票基础信息 / 财务与预测 / 每股收益

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 每股收益 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/mainindexps/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的每股收益类主要指标（基本/扣非/稀释每股收益、每股净资产、公积金、未分配利润、每股经营现金流）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqlx | string | 报告类型（如"中报"/"年报"/"一季报"/"三季报"等） |
| bqmc | string | 报告期名称 |
| jbps | number | 基本每股收益（元） |
| kfps | number | 扣非每股收益（元） |
| xsps | number | 稀释每股收益（元） |
| mgjzc | number | 每股净资产（元） |
| mggjj | number | 每股公积金（元） |
| mgwfp | number | 每股未分配利润（元） |
| mgjyj | number | 每股经营现金流（元） |
