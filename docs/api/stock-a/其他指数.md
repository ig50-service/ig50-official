# 其他指数

> 沪深京A股 / 指数 / 指数相关 / 其他指数

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 其他指数 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/base/otzs` |

## 功能描述

获取中证、国证、华证三家指数公司编制的全部指数代码和名称，用于后续接口的参数传入。

## 更新机制

- **更新频率**：每天23:00。
- **完成耗时**：约30秒。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 指数代码（如：zz931250） |
| mc | string | 指数名称（如：港股通创新药） |
| jys | string | 指数公司（"zz"表示中证，"gz"表示国证，"hz"表示华证） |

## 示例

```json
[{"dm":"hz992006","mc":"华证红利质量","jys":"hz"},{"dm":"hz992007","mc":"华证低波成长","jys":"hz"}]
```
