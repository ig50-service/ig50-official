# 历史K线（数据范围：短分时两年，日线及以上所有）

> 沪深京A股 / 股票交易数据 / 股票K线 / 历史K线（数据范围：短分时两年，日线及以上所有）

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历史K线（数据范围：短分时两年，日线及以上所有） |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/history/trade/{股票代码}/{分时级别}` |

## 功能描述

根据《股票列表》得到的股票代码和分时级别获取历史K线数据，交易时间升序。

## 更新机制

- **更新频率**：分钟级别盘中每5分钟更新，日线及以上级别盘后15:35更新。
- **完成耗时**：分钟级别更新耗时约30秒，日线及以上级别耗时约15分钟。

## 数据格式

```
[{},..]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| d | string | 交易时间（短分时级别格式为yyyy-MM-ddHH:mm:ss，日线及以上级别为yyyy-MM-dd） |
| ud | string | 更新时间（短分时级别格式为yyyy-MM-ddHH:mm:ss） |
| o | number | 开盘价（元） |
| h | number | 最高价（元） |
| l | number | 最低价（元） |
| c | number | 收盘价（元） |
| v | number | 成交量（股） |
| e | number | 成交额（元） |
| zf | number | 振幅（%） |
| hs | number | 换手率（%） |
| zd | number | 涨跌幅（%） |
| zde | number | 涨跌额（元） |
| sz | number | 昨收价（元） |
