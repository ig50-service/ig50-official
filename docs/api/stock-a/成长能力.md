# 成长能力

> 沪深京A股 / 股票基础信息 / 财务与预测 / 成长能力

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 成长能力 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/mainindexgrowth/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的成长能力指标（营业总收入/毛利润/归属/扣非净利润及同比增长、滚动环比增长率）。按报告期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告期（yyyy-MM-dd） |
| bqlx | string | 报告类型（如"中报"/"年报"/"一季报"/"三季报"等） |
| bqmc | string | 报告期名称 |
| yyzsr | number | 营业总收入（元） |
| mlr | number | 毛利润（元） |
| gmjlr | number | 归属净利润（元） |
| kfjlr | number | 扣非净利润（元） |
| yyzrtb | number | 营业总收入同比增长（%） |
| gmjlrtb | number | 归属净利润同比增长（%） |
| kfjlrtb | number | 扣非净利润同比增长（%） |
| yyzrhb | number | 营业总收入滚动环比增长（%） |
| gmjlrhb | number | 归属净利润滚动环比增长（%） |
| kfjlrhb | number | 扣非净利润滚动环比增长（%） |
