> 沪深京A股 / 股票基础信息 / 涨跌股池 / 跌停股池

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 沪深京A股-股票基础信息-涨跌股池-跌停股池 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/zdtgc/dtgc/{日期}` |

## 功能描述

根据日期（格式yyyy-MM-dd，最近15个交易日）作为参数，得到每天的跌停股票列表，根据封单资金升序

## 更新机制

- **更新频率**：交易时间段每10分钟
- **完成耗时**：约1分钟

## 数据格式

```
[{},...]
```

## 字段说明

代码, 名称, 价格（元）, 跌幅（%）, 成交额（元）, 流通市值（元）, 总市值（元）, 动态市盈率, 换手率（%）, 连续跌停次数, 最后封板时间（HH:mm:ss）, 封单资金（元）, 板上成交额（元）, 开板次数
