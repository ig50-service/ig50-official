# 根据指数、行业、概念找股票

> 沪深京A股 / 股票基础信息 / 股票板块概念 / 根据指数、行业、概念找股票

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 根据指数、行业、概念找股票 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/indextree/{指数、行业、概念代码}` |

## 功能描述

根据"指数、行业、概念树"接口得到的代码作为参数，得到相关的股票。

## 更新机制

- **更新频率**：每周六凌晨3点更新。
- **完成耗时**：约8小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 股票代码（如：000001） |
| mc | string | 股票名称（如：平安银行） |
| jys | string | 交易所（"sh"表示上证/"sz"表示深证/"bj"表示北证） |
| isCyb | number | 是否属于创业板（0否/1是） |
| isKcb | number | 是否属于科创板（0否/1是） |
| isSt | number | 是否ST（0否/1是） |
| isNew | number | 是否是新股（0否/1是） |

## 示例

```json
[{"dm":"920014","mc":"特瑞斯","jys":"bj","isIndex":0,"isCyb":0,"isKcb":0,"isSt":0,"isNew":0},{"dm":"920010","mc":"凯添燃气","jys":"bj","isIndex":0,"isCyb":0,"isKcb":0,"isSt":0,"isNew":0}]
```
