# 名称变动

> 沪深京A股 / 股票基础信息 / 概况与经营 / 名称变动

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 名称变动 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/mcbg/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的历次证券简称变动记录。按变动日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 变动日期（yyyy-MM-dd） |
| jmc | string | 旧名称 |
| xmc | string | 新名称 |
| bdyy | string | 变动原因 |
| bdsm | string | 变动说明 |

## 示例

```json
[{"bgrq":"2012-08-02","jmc":"深发展A","xmc":"平安银行","bdyy":"吸收合并","bdsm":"2012-08-02 深发展A → 平安银行，吸收合并"},{"bgrq":"2007-06-20","jmc":"S深发展A","xmc":"深发展A","bdyy":"股权分置","bdsm":"2007-06-20 S深发展A → 深发展A，股权分置"},{"bgrq":"2006-10-09","jmc":"深发展A","xmc":"S深发展A","bdyy":"未完成股改公司冠以“S”标记","bdsm":"2006-10-09 深发展A → S深发展A，未完成股改公司冠以“S”标记"}]
```
