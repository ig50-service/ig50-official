# 历届监事会成员

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 历届监事会成员

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历届监事会成员 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/js/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的历届监事会成员名单。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 姓名 |
| title | string | 职务 |
| sdate | string | 起始日期（yyyy-MM-dd） |
| edate | string | 终止日期（yyyy-MM-dd） |

## 示例

```json
[{"name":"谢永林","title":"非执行董事","sdate":"2025-12-16","edate":"2028-12-15"},{"name":"谢永林","title":"董事长","sdate":"2025-12-16","edate":"2028-12-15"}]
```
