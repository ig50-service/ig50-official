# 开盘量额

> 沪深京A股 / 股票交易数据 / 股票行情 / 开盘量额

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 开盘量额 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/dxsj/kple` |

## 功能描述

获取上一个交易日沪深京全市场开盘（集合竞价结束）量额，按代码升序。

## 更新机制

- **更新频率**：每天20:0更新。
- **完成耗时**：约60分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| kpl | number | 数据日当日开盘量（手） |
| kpe | number | 数据日当日开盘额（万元） |
| qrkpl | number | 数据日前一个交易日开盘量（手） |
| qrkpe | number | 数据日前一个交易日开盘额（万元） |
| tjrq | string | 统计日期（yyyy-MM-dd） |

## 示例

```json
[{"dm":"000001","kpl":5094,"kpe":604.150,"qrkpl":2245,"qrkpe":266.710,"tjrq":"2026-09-04"},{"dm":"000002","kpl":34391,"kpe":1079.880,"qrkpl":8427,"qrkpe":258.710,"tjrq":"2026-09-04"}]
```
