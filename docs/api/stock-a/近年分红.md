# 近年分红

> 沪深京A股 / 股票基础信息 / 分红融资 / 近年分红

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 近年分红 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/share/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司的近年来的分红实施结果。按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| sdate | string | 公告日期（yyyy-MM-dd） |
| give | string | 每10股送股（单位：股） |
| change | string | 每10股转增（单位：股） |
| send | string | 每10股派息（税前，单位：元） |
| line | string | 进度 |
| cdate | string | 除权除息日（yyyy-MM-dd） |
| edate | string | 股权登记日（yyyy-MM-dd） |
| hdate | string | 红股上市日（yyyy-MM-dd） |

## 示例

```json
[{"sdate":"2026-08-15","give":"0","change":"0","send":"2.49","line":"预案","cdate":"--","edate":"--","hdate":"--"},{"sdate":"2026-06-05","give":"0","change":"0","send":"3.6","line":"实施","cdate":"2026-06-12","edate":"2026-06-11","hdate":"--"}]
```
