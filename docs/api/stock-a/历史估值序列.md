# 历史估值序列

> 沪深京A股 / 股票交易数据 / 股票行情 / 历史估值序列

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历史估值序列 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/gzxl/{代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取最近5年每天估值指标，按日期升序。

## 更新机制

- **更新频率**：每天20:00更新。
- **完成耗时**：约6小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| d | string | 日期（yyyy-MM-dd） |
| pettm | number | 市盈率TTM |
| pebfw | number | 市盈率TTM历史百分位（%，超过历史x%的交易日；市盈率为正时越大越贵，为负即亏损期，低百分位不代表便宜） |
| pbmrq | number | 市净率MRQ |
| pbbfw | number | 市净率历史百分位（%，超过历史x%的交易日；市净率为正时越大越贵，为负即资不抵债，低百分位不代表便宜） |
| pcfttm | number | 市现率TTM（经营现金流口径） |
| pcfbfw | number | 市现率TTM历史百分位（%，超过历史x%的交易日；市现率为正时越大越贵，为负即经营现金流为负，低百分位不代表便宜） |
| psttm | number | 市销率TTM |
| psbfw | number | 市销率TTM历史百分位（%，超过历史x%的交易日，越大越贵） |
| peg | number | 市盈率相对盈利增长比率PEG（%） |
| lt | number | 流通市值（元） |
| sz | number | 总市值（元） |
