## 功能描述

根据《股票列表》得到的股票代码获取上市公司沪深港通（北向资金）各机构的持股及增持明细。按交易日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jyrq | string | 交易日期（yyyy-MM-dd） |
| jgmc | string | 机构名称 |
| cgs | number | 持股数量（股） |
| zzgs | number | 增持数量（股） |
| cgsz | number | 持股市值（元） |
| zzsz | number | 增持市值（元） |
| zdfd | number | 增持幅度（%） |
| ltcgbl | number | 占流通股比（%） |
| zgfbl | number | 占总股本比（%） |
