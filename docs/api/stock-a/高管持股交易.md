# 高管持股交易

> 沪深京A股 / 股票基础信息 / 股东股本高管 / 高管持股交易

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 高管持股交易 |
| 所属市场 | 沪深京A股 |
| 本地路径 | `数据存放目录/time/f10/ggcgbdtrade/{股票代码}` |

## 功能描述

根据《股票列表》得到的股票代码获取上市公司高管及相关人员持股交易明细（含交易方式、董监高管关联关系等完整字段）。按变动日期倒序。

## 更新机制

- **更新频率**：每天17:30更新。
- **完成耗时**：约10小时。

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bdrq | string | 变动日期（yyyy-MM-dd） |
| bdr | string | 变动人 |
| bdsl | number | 变动数量（股） |
| jjj | number | 交易均价（元） |
| jcg | number | 结存股票（股） |
| jyfs | string | 交易方式 |
| gjg | string | 董监高管姓名 |
| gjzw | string | 高管职位 |
| gjgx | string | 与高管关系 |
