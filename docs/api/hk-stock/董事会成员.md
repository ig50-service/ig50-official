# 董事会成员

> 港股 / 港股基础信息 / 公司详情 / 董事会成员

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 董事会成员 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/board/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取董事会成员。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| xm | string | 姓名 |
| zw | string | 职务 |
| rzqsr | string | 任职起始日（yyyy-MM-dd） |
| rzr | string | 任职终止日（在职时为空） |
| xb | string | 性别（"男"/"女"） |
| jl | string | 简历 |
| csnf | number | 出生年份（yyyy） |
