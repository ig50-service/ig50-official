# 董事及股东权益

> 港股 / 港股基础信息 / 股本股东 / 董事及股东权益

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 董事及股东权益 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/holder/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取董事及股东权益，按报告日期倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告日期（yyyy-MM-dd） |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| gdm | string | 股东/董事名称 |
| qygf | number | 权益股份（股） |
| zjcgf | number | 直接持股（股） |
| qyzb | number | 权益占比（%） |
| gfbd | number | 股份变动（%） |
| gflx | string | 股份类型 |
| qylx | string | 权益类型 |
| qyxz | string | 权益性质 |
| sfzj | string | 是否直接（1直接/0间接） |
