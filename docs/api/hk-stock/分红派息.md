# 分红派息

> 港股 / 港股基础信息 / 公司大事 / 分红派息

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 分红派息 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/dividend/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取分红派息，按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| cznf | string | 财政年度（yyyy） |
| fhfa | string | 分红方案 |
| fplx | string | 分配类型 |
| cjrq | string | 除净日期（yyyy/MM/dd） |
| ghrq | string | 截止过户日期（日期范围，yyyy/MM/dd-yyyy/MM/dd） |
| ffrq | string | 发放日期（yyyy/MM/dd） |

## 示例

```json
[{"ggrq":"2025-06-20","cznf":"2024","fhfa":"每股派人民币0.3元(相当于港币0.328元)","fplx":"年度分配","cjrq":"2025/06/25","ghrq":"2025/06/27-2025/07/02","ffrq":"2025/07/31"},{"ggrq":"2024-06-14","cznf":"2023","fhfa":"每股派人民币0.43元(相当于港币0.472元)","fplx":"年度分配","cjrq":"2024/06/19","ghrq":"2024/06/21-2024/06/25","ffrq":"2024/07/31"}]
```
