# 资产负债表

> 港股 / 港股基础信息 / 财务分析 / 资产负债表

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 资产负债表 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/balance/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取资产负债表，按报告日期倒序、科目代码升序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| date | string | 报告日期（yyyy-MM-dd） |
| dcode | string | 日期类型代码（001年报/002中报） |
| code | string | 科目代码 |
| name | string | 科目名称 |
| amount | number | 金额（元） |

## 示例

```json
[{"date":"2025-12-31","dcode":"001","code":"004036999","name":"总权益","amount":105714247000.000},{"date":"2025-12-31","dcode":"001","code":"004036001","name":"总资产","amount":510624059000.000},{"date":"2025-12-31","dcode":"001","code":"004035001","name":"总负债","amount":404909812000.000}]
```
