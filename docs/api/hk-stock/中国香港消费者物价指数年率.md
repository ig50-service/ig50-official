## 功能描述

获取中国香港消费者物价指数年率，按统计时间倒序。

## 更新机制

- **更新频率**：每天17:00。
- **完成耗时**：约1小时。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tjsj | string | 统计时间（yyyy-MM-dd） |
| tjyf | string | 统计月份（中文，如“2026年09月”） |
| qz | number | 前值（同比%） |
| xz | number | 现值（同比%，最新期未发布时为null） |
| gbsj | string | 发布日期（yyyy-MM-dd） |

## 示例

```json
[{"tjsj":"2026-09-01","tjyf":"2026年09月","qz":1.70,"xz":null,"gbsj":"2026-10-22"},{"tjsj":"2026-08-01","tjyf":"2026年08月","qz":1.70,"xz":1.70,"gbsj":"2026-09-23"}]
```
