## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 业务展望 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/businessexpectation/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取业务展望，按报告日期倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| date | string | 报告日期（yyyy-MM-dd） |
| ywhg | string | 业务回顾 |
| ywzw | string | 业务展望 |
