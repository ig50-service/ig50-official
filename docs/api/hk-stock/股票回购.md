# 股票回购

> 港股 / 港股基础信息 / 公司大事 / 股票回购

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 股票回购 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/repo/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取股票回购，按回购日期倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| hgrq | string | 回购日期（yyyy-MM-dd） |
| hgsl | number | 回购数量（股） |
| hgje | number | 回购金额（元） |
| zgj | number | 最高价（港元） |
| zdj | number | 最低价（港元） |
| hb | string | 货币 |

