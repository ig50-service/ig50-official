# 历史股本变化

> 港股 / 港股基础信息 / 股本股东 / 历史股本变化

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历史股本变化 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/equitychange/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取历史股本变化，按变动日期倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bdrq | string | 变动日期（yyyy-MM-dd） |
| gfs | number | 普通股（股） |
| bdyy | string | 变动原因 |
| ggrq | string | 公告日期（yyyy-MM-dd） |

## 示例

```json
[{"bdrq":"2025-03-31","gfs":2539598690,"bdyy":"股份期权","ggrq":"2025-04-07"},{"bdrq":"2024-11-08","gfs":2534269690,"bdyy":"股份期权","ggrq":"2024-11-08"},{"bdrq":"2024-11-07","gfs":2534267690,"bdyy":"股份期权","ggrq":"2024-11-08"}]
```
