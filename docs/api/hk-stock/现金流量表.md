# 现金流量表

> 港股 / 港股基础信息 / 财务分析 / 现金流量表

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 现金流量表 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/cashflow/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取现金流量表，按报告日期倒序、科目代码升序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| date | string | 报告日期（yyyy-MM-dd） |
| dcode | string | 日期类型代码（001年报/002中报） |
| code | string | 科目代码 |
| name | string | 科目名称 |
| amount | number | 金额（元） |

## 示例

```json
[{"date":"2025-12-31","dcode":"001","code":"005009","name":"收购附属公司","amount":5595486000.000},{"date":"2025-12-31","dcode":"001","code":"001999","name":"营运资金变动前经营溢利","amount":13290204000.000},{"date":"2025-12-31","dcode":"001","code":"010999","name":"现金净额","amount":-9613487000.000}]
```
