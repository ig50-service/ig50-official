# 历史股权变动（董事增减持）

> 港股 / 港股基础信息 / 股本股东 / 历史股权变动（董事增减持）

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 历史股权变动（董事增减持） |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/shequitychg/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取历史股权变动（董事增减持），按事件日期倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| sjrq | string | 事件日期（yyyy-MM-dd） |
| jg | string | 机构/人名 |
| cclx | string | 持仓类型（L好仓/S淡仓） |
| mrjgfs | number | 买入/卖出涉及的股数（股） |
| bdhsl | number | 变动后数量（股） |
| mgpj | number | 每股平均价（港元） |
| bdhcgl | number | 变动后持股率（%） |

