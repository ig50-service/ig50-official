## 功能描述

获取基础的股票或指数代码和名称，用于后续接口的参数传入。含港股指数，主板、创业板、港股通股票，不含已退市股票

## 更新机制

- **更新频率**：每天0点
- **完成耗时**：约10分钟

## 数据格式

```
[{},...]
```

## 字段说明

股票或指数代码，如：00001, 股票名称，如：长和, 是否是指数，0：否，1：是, 是否属于主板。0：否，1：是, 是否属于创业板。0：否，1：是, 是否属于港股通。0：否，1：是
