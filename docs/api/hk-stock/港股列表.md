## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 港股列表 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/base/gphk` |

## 功能描述

获取基础的股票或指数代码和名称，用于后续接口的参数传入。含港股指数，主板、创业板、港股通股票，不含已退市股票。

## 更新机制

- **更新频率**：每天0点。
- **完成耗时**：约10分钟。

## 数据格式

```
[{},...]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 股票或指数代码（如：00001） |
| mc | string | 股票名称（如：长和） |
| isIndex | number | 是否是指数（0否/1是） |
| isZb | number | 是否属于主板（0否/1是） |
| isCyb | number | 是否属于创业板（0否/1是） |
| isGgt | number | 是否属于港股通（0否/1是） |

## 示例

```json
[{"dm":"00001","mc":"长和","isIndex":0,"isZb":1,"isCyb":0,"isGgt":0}]
```
