# 利润表

> 港股 / 港股基础信息 / 财务分析 / 利润表

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 利润表 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/profit/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取利润表，按报告日期倒序、科目代码升序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| date | string | 报告日期（yyyy-MM-dd） |
| dcode | string | 日期类型代码（001年报/002中报） |
| code | string | 科目代码 |
| name | string | 科目名称 |
| amount | number | 金额（元） |

## 示例

```json
[{"date":"2025-12-31","dcode":"001","code":"004010002","name":"其他收益","amount":229025000.000},{"date":"2025-12-31","dcode":"001","code":"004005002","name":"销售成本","amount":136494953000.000},{"date":"2025-12-31","dcode":"001","code":"004025001","name":"少数股东损益","amount":2215343000.000}]
```
