# 相关公告

> 港股 / 港股基础信息 / 公司大事 / 相关公告

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 相关公告 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/notice/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取相关公告，按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggid | string | 公告ID |
| ggmc | string | 公告标题 |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| pfdlj | string | PDF下载链接 |
