# 最新K线

> 港股 / 港股交易数据 / K线数据 / 最新K线

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 最新K线 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/real/time/{股票或指数代码}/{分时级别}` |

## 功能描述

根据《港股列表》得到的股票或指数代码以及分时级别获取分时交易数据，交易时间升序（个股数据延迟15分钟，指数实时）。

## 更新机制

- **更新频率**：分钟级别盘中每5分钟更新，日线及以上级别盘后16:30更新。
- **完成耗时**：分钟级别数据耗时约30秒，日线及以上级别每天16:30更新，总耗时约30分钟。

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| d | string | 交易时间（短分时级别格式为yyyy-MM-ddHH:mm:ss，日线及以上级别为yyyy-MM-dd） |
| ud | string | 更新时间（格式为yyyy-MM-ddHH:mm:ss） |
| o | number | 开盘价（港元） |
| h | number | 最高价（港元） |
| l | number | 最低价（港元） |
| c | number | 收盘价（港元） |
| v | number | 成交量（股） |
| e | number | 成交额（港元） |
| zf | number | 振幅（%） |
| hs | number | 换手率（%）（仅个股） |
| zd | number | 涨跌幅（%） |
| zde | number | 涨跌额（港元） |
