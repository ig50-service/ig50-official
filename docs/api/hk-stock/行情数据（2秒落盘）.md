# 行情数据（2秒落盘）

> 港股 / 港股交易数据 / 行情数据 / 行情数据（2秒落盘）

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 港股-港股交易数据-行情数据-行情数据（2秒落盘） |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/real/{股票或指数代码}` |

## 功能描述

根据《港股列表》得到的股票或指数代码获取实时交易数据（个股数据延迟15分钟，指数实时）

## 更新机制

- **更新频率**：交易时间段每10秒
- **完成耗时**：约2秒

## 数据格式

```
{}
```

## 字段说明

代码, 名称, 更新时间yyyy-MM-dd HH:mm:ss, 数据时间yyyy-MM-dd HH:mm:ss, 当前价格（港元）, 昨收价（港元）, 开盘价（港元）, 最高价（港元）, 最低价（港元）, 均价（元，成交量加权平均价）, 涨跌额（港元）, 涨跌幅（%）, 振幅（%）, 成交量（股）, 现量（最新一笔成交量，股）（仅个股）, 成交额（港元）, 量比, 换手率（%）（仅个股）, 量涨速（%，成交量变化速率）, 涨速（%）, 短换手（%，短周期换手率）, 总市值（港元）（仅个股）, 流通市值（港元）（仅个股）, 总股本（万股）（仅个股）, 流通股本（万股）（仅个股）, 市盈率（动态）（仅个股）, 市盈率TTM（滚动市盈率）（仅个股）, 市盈率（静态）（仅个股）, 市净率（仅个股）, 每股收益（港元）（仅个股）, 每股净资产（港元）（仅个股）, 股息率（%）（仅个股）, 连续涨跌天数（正数=连涨，负数=连跌）, 内盘（主动卖成交量，股）, 外盘（主动买成交量，股）, AB股总市值（港元）（仅个股）, 20日涨幅（%）, 年初至今涨幅（%）, 月初至今涨幅（%）, AH股对应代码（H股对应A股代码）（仅个股）
