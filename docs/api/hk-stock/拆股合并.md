# 拆股合并

> 港股 / 港股基础信息 / 公司大事 / 拆股合并

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 拆股合并 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/splitmerge/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取拆股合并，按公告日期倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ggrq | string | 公告日期（yyyy-MM-dd） |
| fajd | string | 方案进度 |
| fascm | string | 方案说明（长文本） |
| cxbl | string | 拆细比例 |
| cxqmz | string | 拆细前面值（港元） |
| cxhmz | string | 拆细后面值（港元） |
| hlgprq | string | 换领股票日期（日期范围，yyyy/MM/dd-yyyy/MM/dd） |
| sxr | string | 生效日（yyyy-MM-dd） |

## 示例

```json
[{"ggrq":"2014-03-19","fajd":"实施","fascm":"建议股份拆细\r\n董事会建议将本公司股本中每股面值0.0001港元的现有已发行及未发行股份各自拆细为五(5)股每股面值0.00002港元的拆细股份。","cxbl":"1:5","cxqmz":"0.0001","cxhmz":"0.00002","hlgprq":"2014/05/15-2014/06/23","sxr":"2014-05-15"}]
```
