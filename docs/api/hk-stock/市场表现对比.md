# 市场表现对比

> 港股 / 港股基础信息 / 投资评级 / 市场表现对比

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 市场表现对比 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/industrymarket/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取市场表现对比。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jyrq | string | 行情日期（yyyy-MM-dd） |
| sjlx | number | 时间段类型（1最近1月/2最近3月/3最近6月/4今年以来） |
| zdf | number | 本股票累计涨跌幅（%） |
| hszdf | number | 恒生指数累计涨跌幅（%） |
| hsmc | string | 恒生指数简称 |
| hsdm | string | 恒生指数代码（如HSI.HI） |
