# 投资评级

> 港股 / 港股基础信息 / 投资评级 / 投资评级

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 投资评级 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/rating/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取投资评级，按发布日期倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| fbrq | string | 发布日期（yyyy-MM-dd） |
| jgmc | string | 机构名称 |
| zxpj | string | 最新评级 |
| sqpj | string | 上次评级 |
| mbjg | number | 目标价格（港元） |
| sqmbj | number | 上次目标价（港元） |
| mbjgbh | string | 目标价格变化 |

