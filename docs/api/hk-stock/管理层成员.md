## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 管理层成员 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/manager/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取管理层成员。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-
