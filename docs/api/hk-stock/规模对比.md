# 规模对比

> 港股 / 港股基础信息 / 投资评级 / 规模对比

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 规模对比 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/industryscale/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取规模对比。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| hymc | string | 行业中文名称 |
| hyywmc | string | 行业英文名称 |
| dbdm | string | 对比证券代码 |
| dbjc | string | 对比证券简称 |
| jzrq | string | 最近标准报告日/数据日期（yyyy-MM-dd） |
| ltsz | number | 流通市值（元） |
| zsz | number | 总市值（元） |
| yysr | number | 营业总收入（元） |
| jlr | number | 净利润（元） |
| ltszpm | number | 流通市值排名 |
| zszpm | number | 总市值排名 |
| yysrpm | number | 营业总收入排名 |
| jlrpm | number | 净利润排名 |
