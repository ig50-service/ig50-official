# 证券资料

> 港股 / 港股基础信息 / 公司详情 / 证券资料

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 证券资料 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/secinfo/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取证券资料。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
{}
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| ssrq | string | 上市日期（yyyy-MM-dd） |
| zqlx | string | 证券类型 |
| jys | string | 交易所 |
| bk | string | 板块 |
| njr | string | 年结日（MM-dd） |
| isin | string | ISIN国际证券识别编码 |
| shgtd | string | 是否沪港通标的（"是"/"否"） |
| sgtd | string | 是否深港通标的（"是"/"否"） |
| fxj | number | 发行价格（港元） |
| fxl | number | 发行量（股） |
| msgss | number | 每手股数（股） |
| mfmz | string | 每股面值 |

## 示例

```json
{"ssrq":"2006-07-13","zqlx":"非H股","jys":"香港交易所","bk":"主板","njr":"12-31","isin":"KYG4100M1050","shgtd":"是","sgtd":"是","fxj":8.220,"fxl":373376500,"msgss":500,"mfmz":"0.10 HKD"}
```
