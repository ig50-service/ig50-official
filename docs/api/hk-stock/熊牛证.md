# 熊牛证

> 港股 / 港股基础信息 / 公司详情 / 熊牛证

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/dataset-overview.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 熊牛证 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/cbbc/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取熊牛证，按存续截止日倒序。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dm | string | 代码 |
| mc | string | 名称 |
| lx | string | 类型（"Bear"熊证/"Bull"牛证） |
| xsj | number | 行使价（港元） |
| shj | number | 收回价（港元） |
| fxj | number | 发行价（港元） |
| hgbl | number | 换股比率 |
| cxjzr | string | 存续截止日（yyyy-MM-dd） |
| zfxe | number | 总发行额（份） |
