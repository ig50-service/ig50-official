# 首发资料

> 港股 / 港股基础信息 / 公司详情 / 首发资料

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 首发资料 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/ipo/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取首发资料。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-
