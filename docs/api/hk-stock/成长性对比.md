# 成长性对比

> 港股 / 港股基础信息 / 投资评级 / 成长性对比

> 本页为镜像文档，**最新接口、字段、路径以 [官网接口文档](https://ig50.com/index.html) 为准**。

## 接口说明

| 项目 | 内容 |
|------|------|
| 数据名称 | 成长性对比 |
| 所属市场 | 港股 |
| 本地路径 | `数据存放目录/time/hk/f10/industrygrowth/{股票代码}` |

## 功能描述

根据《港股列表》得到的股票代码获取成长性对比。

## 更新机制

- **更新频率**：每天17:30，耗时约10个小时。
- **完成耗时**：-

## 数据格式

```
[{}]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bgrq | string | 报告日期（yyyy-MM-dd） |
| hymc | string | 行业中文名称 |
| hyywmc | string | 行业英文名称 |
| dbdm | string | 对比证券代码 |
| dbjc | string | 对比证券简称 |
| jbmgsytb | number | 基本每股收益同比增长率（%） |
| yyszstb | number | 营业收入同比增长率（%） |
| yylrtb | number | 营业利润同比增长率（%） |
| zczctb | number | 总资产同比增长率（%） |
| jbmgpm | number | 基本每股收益同比增长率排名 |
| yyszpm | number | 营业收入同比增长率排名 |
| yylrpm | number | 营业利润同比增长率排名 |
| zzczpm | number | 总资产同比增长率排名 |
