## 功能描述

根据《所有基金列表》得到的基金代码作为参数得到该基金的历年投资股票组合，按截止时间降序

## 更新机制

- **更新频率**：每周六早上6点更新
- **完成耗时**：耗时约7小时

## 数据格式

```
[{}]
```

## 字段说明

季度, 截止时间, 股票代码, 股票名称, 占净值比例, 持股数（万股）, 持仓市值（万元）
