# 关于 IG50

> 专注于将股票等金融数据持续更新到您本地

## 序言

随着量化交易与程序化策略的发展，数据逐渐从"辅助工具"变成策略体系的基础设施。在实际使用中，真正消耗时间的往往不是策略本身，而是数据获取、清洗与维护过程的不确定性。

IG50 是一个本地运行的股票数据引擎，专注于将全市场行情数据稳定沉淀到用户本地，使数据可以直接用于读取、回测与策略开发。

## 目标

**高效 · 稳定 · 简单**

- **高效**：在更短的时间内获取完整可用的数据
- **稳定**：长期结构一致、可持续使用
- **简单**：尽量减少数据维护与系统搭建成本，让注意力回到策略本身

IG50 始终围绕此核心设计：提供一套可以长期依赖的股票数据基础工具。

## 使用方式

**模式简单：数据 → IG50 → 用户本地**

- 数据：全市场行情
- IG50：本地数据引擎
- 用户本地：JSON 文本落盘

IG50 是一个 24 小时永不停歇的本地股票数据更新软件，数据以 JSON 文本文件落盘。免值守，免维护，最新的数据总会如期到达。

## 为什么选择 IG50

IG50 以稳定的链路，极短的时间内将数据落盘到您本地，数据持续更新。策略随时、高效本地回测，无并发限制，无数据访问额度限制，无带宽牵绊，无策略泄露风险。对于希望专注策略本身、不想长期维护数据链路的用户，这是更合适的方式。

IG50 是 AI Agent 的理想数据底座，大模型熟读数据文档后，您可以用自然语言的方式让 Agent 编写回测脚本，本地回测，取代以往繁杂的策略编写工作。数据在本地，策略在本地，极高的回测效率，极低的长期成本。

## 关于隐私

- IG50 承诺：不要求注册，不采集用户个人信息、用户策略等内容。
- 所有数据处理均在本地完成，使用与停止完全由用户控制，不依赖持续在线服务。
